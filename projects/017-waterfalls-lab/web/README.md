## 启动与构建

完整理解、全部下载和共享站入口应使用仓库构建后的 `_site`。在仓库根目录运行：

```powershell
python scripts/build_site.py
python scripts/waterfalls_publish.py --check --site _site/projects/017-waterfalls-lab
python -m http.server 8992 --bind 127.0.0.1 --directory _site
```

打开 [完整理解页](http://127.0.0.1:8992/projects/017-waterfalls-lab/understanding.html) 或 [工作室](http://127.0.0.1:8992/projects/017-waterfalls-lab/)。端口可按本机占用情况调整。工作室需要 WebGPU、GPU 硬件加速和 localhost / HTTPS，理解页正文与图像不需要 WebGPU。不要通过 `file://` 打开。GPU 或编译错误会显示在加载页。构建为程序、Worker 与样式生成内容版本标识，避免更新后继续复用旧缓存。

仅调试工作室时，可执行 `python -m http.server 8987 --bind 127.0.0.1 --directory projects/017-waterfalls-lab/web` 并打开 <http://127.0.0.1:8987/>。直接服务源 `web/` 不包含发布器生成的 `downloads/`；示例作品和基础 ZIP 下载必须使用完整 `_site`，源目录预览不能作为全部入口验收。

修改源码后：

```powershell
cd projects/017-waterfalls-lab/tooling
npm ci
node build.mjs
node --test --test-concurrency=1 ../tests/*.test.mjs
```

## 操作

观察工具下左键拖动旋转、右键 / 中键平移、滚轮缩放。其他编辑工具下右键拖动旋转，中键平移，`Alt` 临时用左键旋转。双指用于缩放与平移；触屏短暂延迟雕刻起笔，避免快速双指手势误绘。

堆筑 / 挖掘工具下按住拖动连续雕刻，快速拖动也会按半径的 23% 均匀补齐采样，约每 45 ms 批量刷新，松开时刷新剩余样本；离开表面或单次距离超过 64 个采样间距会断开笔画。左侧可切换堆筑、挖掘、平滑、削平和恢复。平滑 / 削平有强度设置；削平以本次起笔位置的高度为目标。对称开关沿山谷中心 x=0 镜像笔刷；范围轮廓贴合当前表面。岩石工具点击放置，编辑工具按实际造景三角形选取最近对象，并检测地形遮挡；可用“已有造景”菜单选取小物体或被遮挡的物体。拖动保留抓取偏移，接近水平的视角使用备用移动面；`Shift` 临时升降，切换时重新建立起点。移动方向可选水平自由、仅 X、仅 Z 或仅 Y，Y 也供触屏使用；吸附提供 0.10 / 0.25 / 0.50 m 位移步长，保留原有坐标偏移，不会自动对齐绝对坐标网格。Ctrl / Command 点击或开启“点击追加 / 移除选择”可增减选取；编辑模式 Ctrl A 全选。开启追加选择后，点选已选对象移除，拖动已选对象直接移动整组，拖动受方向或边界约束时保持选择。多件对象可批量复制、镜像、贴地、删除或聚焦，整组位移受统一边界约束，保留间距。复制后选中新副本。单选时可调三轴大小、旋转和精确 XYZ；多选时隐藏单件属性。

水源工具显示水源标记和选择菜单，可以新增 / 删除、独立启停、镜像新增，在地形上点击移动当前水源；调整高度、半径、流量，展开精确位置与喷射方向设置 XYZ、朝向、俯仰角、速度。点击“瞄准落点”后选择地形，当前速度和重力允许到达时自动计算喷射方向；按 Esc 或再次点击按钮取消。预计轨迹和首次触地位置可以隐藏，轨迹只估算空中阶段，不考虑水体相互作用。坐标数值输入后回车或离开输入框生效。镜像沿 x=0 复制位置，同时反转水平朝向，保留启停与其他设置。`Ctrl D` 复制当前水源或选中物体，`F` 聚焦当前水源或选中物体，左侧编辑面板可收起。

造景没有原先 16 件的硬上限，历史记录最近 60 次操作。重置、场景切换、两种示例和作品载入 / 导入均可撤销，完整恢复名称、相机、画质和其他设置。雕刻撤销只恢复造景。`Ctrl Z` / `Ctrl Shift Z` 撤销 / 重做；`Space` 暂停；`R` 重置；`H` 进入 / 退出沉浸；`Esc` 退出沉浸或返回观察；`Delete` 删除当前对象或水源（至少保留一个水源，可关闭）。手机工具栏可横向滚动。


画质四档为 8,192 / 16,384 / 24,576 / 49,152 粒子；粒子体积和光学半径随粒子数调整。高画质同时提高渲染分辨率，画布保持纵横比并受 2200 × 1600 上限约束，DPR 上限 1.5。每帧等待 GPU 提交完成，显示实际完成帧率。最大子步数限制下，低性能设备可能以较慢物理时间运行。

“风景的呼吸”可选清透山泉、澄蓝冰川、深绿翡翠，并调节泡沫；水面柔化提供细节、平衡、柔和三档，切换时不重置水流。轻负载档使用一轮滤波，旧作品默认保留这档；新作品默认平衡。“水流性格与光感”可调时间速度、重力、黏性与曝光。水声需要主动点击启用。“保存画面”生成无界面的真实 PNG。“关于此作”可查看流速、厚度与粒子稳定性，诊断包含有限值、域范围和明显穿入固体的数量。

## 保存与恢复

展开“镜头收藏”，输入名称后点击“收藏当前镜头”。下拉菜单立即恢复对应角度，“更新此镜头”将当前相机和名称写回，“移除镜头”删除选中收藏。最多八个镜头；镜头随自动保存、命名作品和 JSON 文件保存。编辑镜头列表支持撤销 / 重做，不重置水粒子或切换当前相机。旧 version 2 文件没有镜头字段时使用空列表。

点击顶部“沉浸观看”或按 H，进入纯风景并保留“返回编辑”按钮。按钮、Esc 或 H 退出并恢复之前的工具；观看期间可旋转、缩放和按 Space 暂停水流。隐藏的造景快捷键暂停生效。

最近编辑自动保存于当前浏览器的 `waterfalls-lab:v2:autosave`，命名作品保存在 `waterfalls-lab:v2:library`。页面重新打开会自动恢复编辑。平时按 650 ms 合并保存，页面隐藏或 pagehide 时同步结束拖动并立即保存相机与最新造景；不保证系统强制结束进程时一定触发事件。保存失败显示提示、保留上一次文件并可重试；初始化失败不覆盖已有自动保存。保存包含地形笔刷、物体变换、全部水源及其喷射参数、水面外观、光照、物理设置与相机；水粒子重新初始化并逐渐稳定。

“我的作品”支持命名保存、加载、文件导入导出，并内置“体验：穿山溪流”和“体验：双瀑汇流”。JSON 文件严格校验版本、有限坐标和范围，最大 5 MB、2,000 件物体、256 处水源、16,384 次笔刷操作；导入失败保留当前场景。作品格式保持 version 2，缺少新增字段的旧文件会使用默认单水源配置；两个历史存储键也保持兼容。新增 / 批量复制在超出文件原有容量时提示，不生成无法重新导入的文件；导出名称进入自动保存，修改作品或名称后旧下载链接会隐藏，请重新生成。浏览器本地存储满时会提示导出文件。跨设备使用导出文件，不提供云同步。

## 共享站

仓库根目录运行 `python scripts/build_site.py`，打包到 `_site/projects/017-waterfalls-lab/`。主程序和工作线程使用相对路径。EA 的 `upstream/shaders/*.wgsl`、`upstream/scenes/*.json` 和许可文件按项目单独放行，其他 JSON 不会因此公开。

`upstream/` 是保留 EA BSD-3-Clause 声明的真实二维示例，与主页面的独立三维实现各自运行。模拟、雕刻和水源限制在当前山谷体素域，物体不模拟自由刚体动力学。

## 历史记录 · V6 编辑与验证 · 2026-10-03

造景三角形与渲染使用同一生成函数，拾取先检查包围盒，再进行双面三角形射线相交并选最近点；地形遮挡由体素场检测。拾取几何按需生成并缓存，变换后失效、删除后清理；这不包含装饰树木或水面遮挡。下拉菜单可选取被遮挡的造景。

选取与无位移拖动不增加历史；开始实际移动时保存一次状态。拖动更新最多每 32 ms 合并提交，结束时提交剩余位置；滑块和数值输入继续即时更新。物体 GPU 网格缓存包含对象变换、场景与选取状态，地形雕刻不再重复销毁未变的对象 buffer。切换作品、撤销与载入后同步隐藏旧对象控件。

44 项 Node 与 14 项 Python 检查通过，其中五项运行当前 `app.js` 的实际事件代码，使用最小 DOM 与 GPU 替身，覆盖不动的选取、最终拖动、单次撤销、作品切换、镜像与 Ctrl D、方向吸附和触屏升降。测试还覆盖最近三角形、旋转细长对象、真实体素遮挡与开洞、拾取缓存、拖动起点 / 丢失交点 / 方向切换、镜像碰撞与流向，以及实际引擎网格缓存。浏览器工具仍无法启动；没有新增真实指针、设备触屏、移动布局、着色器或 FPS 验证。


## 历史记录 · V7 批量造景与保存 · 2026-10-03

选取集合按对象 ID 保存，活动对象只用于拖动起点；数组移位后重新映射索引，切换作品与撤销时清空选择。分组移动限制统一的三轴位移，保留所有相对位置，旧导入对象的已有域外偏移可保留，但不能继续向外移动。复制使用共同偏移，靠边优先向内；镜像对每个对象反转 x 和旋转。聚焦包围全部对象实际几何。尺寸编辑仅单选显示，贴地对每件独立执行。

实际引擎支持数组选择并为全部成员着色，重复选择仍复用对象 mesh buffer。新选取状态不会写进作品文件，也没有加入自由刚体或多材料求解。

58 项 Node 与 14 项 Python 检查通过。六项分组数值检查、七项实际 app 事件检查与一项实际引擎高亮命令检查新增通过，覆盖追加选取、保形位移、共同复制、批量历史、最后一帧保存、错误重试、文本快捷键、容量与选取 / 拖动衔接。DOM 与 GPU 接口为替身；浏览器工具本轮进程退出，真实布局、指针、触屏和 GPU 验证仍待补。


## 历史记录 · V8 增量对象编辑 · 2026-10-03

移动组与属性控件只重算编辑对象的碰撞，未变对象与地形保留静态合并场。地形原地编辑使用版本使缓存失效；撤销、删除、改变移动组与预设切换均经过一致性检查。

对象缓冲区改为保留并局部上传，选中颜色也只更新涉及的范围，相邻范围合并。随机种子沿用原列表的颜色序列，局部与完整生成的顶点和颜色逐项一致；新增、删除、改类型和重排时重新分配布局。

在 tooling 运行 `node benchmark-editing.mjs` 可比较 300 件对象中移动 3 件的 40 次更新。本次独立 CPU 测量 4318.18 ms → 71.96 ms，顶点待上传字节减少 98.93%；这不测 GPU 时间或浏览器 FPS。67 项 Node、14 项 Python 检查通过，浏览器实机复核仍因运行环境初始化失败待补。作品文件 version 2 与存储键保留。
