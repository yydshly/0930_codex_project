# 同步讲解：从定义和原因到最终影像

当前体验先给出最终结果并指出黑洞、气体与影像的区别，再演示选定的恒星塌缩路线，随后解释周围气体的发光和成像。观众不需要先懂 shader 才能看懂。

## 观看流程

| 章 | 画面 | 同步解释 |
| --- | --- | --- |
| 00 最终影像 | 带部位说明的黑洞盘影像 | 暗区、外部热气体、弯光影像分别是什么 |
| 01 恒星平衡 | 内外箭头 | 引力和压力梯度的平衡 |
| 02 支撑不足 | 晚期核心 | 为什么会失稳，物质怎样向中心运动 |
| 03 自由落体 | 计算半径与自身/远方读数 | 有限自身时间和红移延迟并不矛盾 |
| 04 事件视界 | 计算的径向零曲线 | 内外信号可达性的区别 |
| 05 气体成盘 | 角动量与输运粒子示意 | 为什么绕行，为什么还能向内吸积 |
| 06 能量与温度 | 温度分布和峰值频段 | 亮的是外部气体，可见色与伪彩有区别 |
| 07 弯光与亮弧 | 计算单束光路和逐像素影像 | 为什么能看见盘背面，盘仍近似平面 |
| 08 频移与明暗 | 受控比较 | 运动和重力如何影响接收光谱 |
| 09 完整观察 | 综合结果与自由参数 | 把原因重新连接到所见结果 |

前半段的恒星和气体图不是同一套流体求解；每章显示所选模型与示意边界。定义、原因、过程、结果应始终跟随正在播放的画面，而不是把解释留在页面底部。

## 交互约定

一键开始完整讲解；播放 MiniMax 预生成的 30 段旁白，实际合计 13 分 3 秒。当前音频时间驱动画面进度，结束事件才允许换段。暂停后画面与讲解一起停下，继续保留原位置；回放、拖动当前段进度、倍速和选章会更新对应说明。页面滚动继续播放，浏览器标签隐藏时暂停。关闭旁白后仍可按实际音频时长观看字幕演示。

形成阶段的播放速度只是观看速度。显示的自身时间来自所选自由落体模型，不能把播放几秒当成真实恒星演化持续几秒。图中的恒星外层和放大核心没有同一比例尺。

受控对照用于比较气体角动量、直线投影、运动频移等原因。直线成像是明确标注的非物理对照。质量和吸积率改变实际单位与温度，颜色模式区分计算可见光与温度伪彩。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| web/model.js | SI 单位、解析自由落体、径向零曲线、RK4 光轨道、薄盘温度和偏折参考 |

| web/narration.js | 30 段完整原稿、真实音频时长、字幕时间块与本地地址 |
| web/audio/narration/ | MiniMax 生成的 30 段 MP3 与完整合并录音 |
| notes/narration-script.json | 10 章 × 3 段的完整科普旁白原稿 |
| tooling/generate-narration.py | 官方 MiniMax TTS 调用、缓存、解码和清单生成 |
| tooling/verify-audio.cjs | 实际媒体播放、解码、续播、字幕与错误恢复验收 |
| web/app.js | 渲染调度、画布切换、摄像机、参数、导出和错误恢复 |
| notes/SCIENCE.md | 面向观众的概念、因果、来源和边界 |
| notes/PRINCIPLES.md | 可核对的方程、实际算法与数值近似 |
| tooling/verify-model.cjs | 独立模型基准 |
| tooling/verify.cjs | 浏览器中的过程、画面、同步字幕与交互验收 |

前端不使用外部图片或源码生成最终盘面；背景、纹理和几何均实时计算。示意区在没有 WebGL 的设备上保留，逐像素成像区才提示图形能力限制。导出选择当前可见画布。

## 验证和记录

模型、浏览器与音频报告分别是 notes/model-validation.json、notes/validation.json、notes/audio-validation.json；以实际生成的时间和结果为准，不用旧报告替代新功能验收。浏览器检查采用 Chromium/SwiftShader，移动布局是视口模拟。

检查应同时回答：公式是否符合选定模型、数值误差有多大、画面与当前讲解是否对应、用户能否暂停并复现对照。截图好看不能代替这些问题。历史 construction-validation.json 和 construction-*.png 只记录早期着色器分层版本。
