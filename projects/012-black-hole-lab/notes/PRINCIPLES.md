# 计算模型、成像公式与可验证边界

研究日期：2026-10-02。实现：web/model.js、web/physics.js、web/shaders.js、web/course.js、web/app.js。观众需要的因果解释见 [SCIENCE.md](SCIENCE.md)。

## 模型范围和单位

选定背景是无自旋、无电荷的 Schwarzschild 外部时空。使用 Rₛ = 2GM/c² 为长度单位，Rₛ/c 为时间单位；默认 M = 10 M☉ 时分别约为 29.53 km 与 98.51 μs。相机是指定半径处的静止观察者；鼠标环绕用来比较不同位置，不模拟一艘实际运动的飞船。

归一化度规写为：

```text
f(r) = 1 - 1/r
ds² = -f dt² + dr²/f + r² dΩ²
```

符号约定与一些论文不同，但零测地线和可观测频率关系一致。页面没有解爱因斯坦方程来形成一个随时间改变的黑洞；它在选定背景和球对称边界模型中计算轨道。[Bruneton 2020，模型章节](https://arxiv.org/html/2010.08735v1#S3)

## 1. 径向自由落体与两种时间读数

model.js 的 collapse() 由解析摆线关系计算半径，而不是插值缩圆。r₀ = 4，自身时间从零推进至 r = 0.65：

```text
E = sqrt(1 - 1/r₀)
r = r₀/2 · (1 + cos η)
τ = r₀^(3/2)/2 · (η + sin η)
dr/dτ = -sqrt(E² - f)
dt/dτ = E/f                  # 只在 r > 1 积分此静态坐标表达
```

这是从静止开始、零压力球对称边界的最后一段径向自由落体。自身时间有限；恒星压力、内层运动和动态视界没有被求解。

模型还计算向外径向光在无穷远接收的频率比，以及去除共同传播路程后的相对到达时间：

```text
g_∞ = E - sqrt(E² - f)
    = f/[E + sqrt(E² - f)]
r* = r + ln(r - 1)           # 视界外
Δt_arrival = [t - r* - (t₀ - r*₀)] · Rₛ/c
```

g_∞ 趋零与延迟增大解释远方信号的红移、衰弱。模型不会为视界内发射事件返回可达远方的信号。这组读数对应远方接收者，和主成像的有限半径相机应区分。[Kunz，广义相对论讲义 3.5 节](https://fiteoweb.unige.ch/~kunzm/lectures/gr_2019.pdf)

## 2. 跨视界的径向光路

radialLight() 对入射 Eddington–Finkelstein 坐标中的朝外零曲线做 RK4 积分：

```text
v = t + r*
ds² = -f dv² + 2 dv dr + r² dΩ²
dr/dv = f/2
```

这种坐标在 r = 1 不发生 Schwarzschild t 的坐标发散。坐标图显示朝外分支在外部向外、视界上沿边界、内部向内；图中斜率不是当地测量的光速。图解用静态模型说明因果边界，不替代塌缩物质内部的动态解。

## 3. 从像素的局部方向到零测地线

片元着色器对每个像素构建相机局部单位视线 n。相机位置 p 的径向单位向量是 e_r，先按静止观察者的正交标架转换为空间坐标切向量：

```text
v = n + e_r · (n·e_r) · [sqrt(f_cam) - 1]
L² = |p × v|²
E² = f_cam
```

这一步使初值满足零条件。不能把欧氏单位视线直接作为该坐标系的光切向量。空间轨道随后满足：

```text
d²p/dλ² = -3L²p/(2r⁵)
|v|² - L²/r³ = E²
```

λ 是仿射参数；v 是坐标积分量，不是可测局部光速。这是 Schwarzschild 零测地线的空间表达，不是人为加一个牛顿吸力让光拐弯。shader 使用有限步长 Velocity Verlet；model.js 用较细 RK4 轨道作独立参考，并计算守恒量残差。

光子球 r = 1.5、临界冲量参数 b_crit = 3√3/2 是解析基准。远方静止相机的阴影角半径还满足 sin α = b_crit·sqrt(f_cam)/r_cam，不可把冲量参数当作有形表面。

## 4. 数值积分与成像停止

实时步长随半径改变，越接近视界越小。积分从实际相机位置开始，没有先沿直线跳到某个球壳的捷径。停止条件包括视界附近捕获、从有限外边界向外逃逸、透射率已很小或用尽步数。

当前捕获阈值略高于 r = 1，背景逃逸边界为有限半径，shader 有最多 980 次循环的硬上限，实际预算由质量档控制。近临界光线可能绕行很久，高阶窄环对步长、像素与预算特别敏感。没有逃逸也没有捕获但用尽预算的光线以紫色诊断像素标记，不能当作捕获阴影或已经找到远方来源。流畅和均衡档均有 900 步预算，精细档 980 步；质量档主要改变像素数。

这些限制会影响细环、阴影边缘和背景点源，解析公式正确不保证每个像素都收敛。精细研究应增加单束收敛实验、相机有限距离校正和带宽过滤，而不是只提高截图分辨率。

## 5. 几何薄盘、温度与图案

盘的辐射面位于 y = 0。渲染在光线穿过该平面时采样，发光区约为 3.05–8.7Rₛ；物理温度模型的零力矩边缘取 r_in = 3Rₛ。稍外移的绘制起点和平滑边缘是有限采样处理。

```text
T_eff⁴ = [3GM Ṁ/(8πσr³)] · [1 - sqrt(r_in/r)]
r_peak = (49/36)r_in
```

该表达使用牛顿稳态通量和局部黑体辐射，是温度近似；轨道弯光采用相对论背景，并不使盘通量自动变成 Novikov–Thorne 相对论盘。

质量改变 km/归一化长度、s/归一化时间和温度；在固定 r/Rₛ 的几何中，成像形状不因为质量单位改变而任意变化。Ṁ 改变选定温度模型，T 在固定 r/Rₛ 下按 (Ṁ/M²)^(1/4) 缩放。参数范围内，真实气流可能进入当前薄盘模型不适用的状态。

径向条带与角向波纹是程序化图案，温度中有小幅艺术纹理调制；图案转速采用 Schwarzschild 圆轨道角速度 Ω = 1/sqrt(2r³)，播放时间按教学速度放慢。它没有计算真实湍流、密度波、磁应力或精确发射迟延。光学柱密度控制改变透明度，不能解释成已求解盘的垂直流体结构。

## 6. 局部气体运动与接收频率

在盘交点处，坐标光切向量的径向分量要除以 sqrt(f_em)，得到当地静止观察者测量的方向。反向追迹取负号后得到到达相机的实际光方向。圆轨道气体相对于该当地观察者的速度为：

```text
β = sqrt[1/(2(r - 1))]
D = sqrt(1 - β²)/(1 - β cos θ)
g = sqrt(f_em/f_cam) · D
```

cos θ 用局部气体运动方向与出射光方向的点积计算。g 同时包含重力与运动的频率变化；这里没有相机运动产生的额外多普勒因子。对照中去除运动因子用于教学，保留其余关系；直线光路对照本身是非物理实验。

## 7. 可见光与伪彩分别做了什么

默认可见模式利用辐亮度不变量 I_ν/ν³。局部黑体经过频率比 g 后，接收到的光谱等同于温度 gT 的黑体：

```text
I_ν,obs(ν) = g³ I_ν,em(ν/g)
B_ν,obs = B_ν(gT)
XYZ ≈ Σ B_λ(gT) · [x̄(λ),ȳ(λ),z̄(λ)] · Δλ
```

shader 采用 12 个波长样本（395–725 nm，间隔 30 nm）与 [Wyman、Sloan、Shirley 2013 的 CIE 解析拟合](https://jcgt.org/published/0002/02/01/paper.pdf)，再转换线性 RGB。有限波长与拟合都带来数值误差；这不是完整人眼、望远镜响应或绝对曝光模型。

温度/亮度伪彩模式用暖色标表示温度，用积分辐亮度 g⁴ 关系显示亮度趋势。它明确标注为伪彩。不能把这个模式的橙色称为实际可见光颜色，也不能把特定频率的 g³ 与总频率积分的 g⁴ 混用。

最终还有指数曝光映射、显示 gamma 与轻微暗角。程序化星空只用于展示方向扭曲，不包含真实恒星谱、点源束面积过滤或经过校准的天空亮度。因此画面是带数值模型的教学可视化，不是某个实测对象的照片预测。

## 8. 图解层与讲解层

physics.js 将计算的 r(τ)、径向零曲线、盘温度和选中的光轨道画成 Canvas 图。压力、角动量输运和气体集中采用机制示意。course.js 用同一章和播放进度控制画面、解释字幕与预录旁白，避免讲解落后于画面。

旁白由官方 MiniMax TTS 生成，使用 speech-2.8-hd 和 doc_commentary 音色，30 段 MP3 随项目保存。原生 HTMLAudioElement 的 currentTime 驱动同步进度，ended 事件决定换段；不再按短字幕字数或固定超时中断语音。暂停和继续保留 currentTime。

当前朗读内容使用 API 返回的实际句块时间。01-00 段未返回分句时间，显示覆盖整段时长的完整原稿，不伪造逐字时间轴。生成记录保存原稿指纹、音频散列、时长和安全回执；网页运行不调用付费 API，也不包含密钥。完整稿与制作方法见 [NARRATION.md](NARRATION.md)。PNG 导出读取当前可见的画布，不包含面板字幕。

## 9. 怎样核对，怎样继续提高

tooling/verify-model.cjs 检查物理尺度、自由落体关系、内外光的方向、薄盘温度、零轨道守恒量与偏折参考；model-validation.json 保留实际结果。tooling/verify.cjs 另检查可操作流程、字幕与画面的同步、物理参数对影像的影响、暂停回放、导出和浏览器限制。数值基准应与浏览器功能测试分别看待。

进一步扩展的顺序：先做步长与预算的收敛校验，再加入相对论盘通量与真实带通，然后才扩展到 Kerr 自旋、辐射转移和磁流体。恒星形成史另需恒星演化、状态方程、中微子输运和动态时空。每条扩展都应有自己的可核对数据。

运行只有浏览器依赖，验证需要 Node.js/Playwright。自动截图使用 Chromium/SwiftShader，FPS 是画面提交速率，不能作为硬件 GPU 性能结论。视觉参考与代码归属见项目 README；本代码没有复制未公开的 Reddit 原作者实现。
