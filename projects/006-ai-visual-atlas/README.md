## 当前研究摘要（截至 2026-10-08）

初始目标是把原帖中的十个链接整理成可阅读、可看效果的网页，辨认每个项目的能力、实现原理和使用范围，再实际探索“歌曲 → 音乐 MV”与“网页 → 宣传短片”。现在已形成项目总览、完整理解汇总、两项技术拆解和本机结果展示。这里区分原库提供的能力、作者样片、本机实际执行结果和待建设方案，演示页面本身不提交生成任务。

这些项目并非同一种“模型生成视频”工具。代码动画由模型或作者设计分镜并编写场景，浏览器根据时间重新绘制，FFmpeg 编码；生成式 MV 调用图像 / 视频模型制作连续表演，再剪辑或合成；实时游戏执行图形与交互程序；索引库帮助找参考和追溯来源。音乐配静态图片只是 MV 的一种路线。Opus 等语言模型主要承担理解、导演和编程角色，不能与生成连续画面的专门视频模型混为一谈。

### 两项重点探索：实际结果与边界

- **歌曲 → MV：**使用用户的《Still a Light》制作约 127 秒整曲图片 MV，并完成歌曲 10–15 秒的五秒 MiniMax 官方 H3 表演、去绿与背景合成。整曲真实角色表演尚未完成，逐字口型尚未验收；现有正面近景也未实现列车坐姿、桌椅接触与遮挡关系。原库默认分层，但完整场景生成、后做口型、动作驱动、绑定动画和叙事镜头都可以按镜头选择；这些扩展不代表本机已经接通。
- **网页 → 宣传短片：**读取真实能力图谱网页，由当前对话模型设计并编写动画，完成早期五幕版和最新六幕版。最新成片为 24 秒、1280 × 720、24fps、576 帧，无音轨，复用已有 H3 素材；素材加载、指定时间重绘、规格和完整解码检查已有记录。任意 URL 的自动采集、模型后台、队列、预算与交付服务尚未建设完成。

### 探索的意义与可沉淀技术

模型提供理解、创作和素材生成能力；目标、参考设计、已有素材、组件、执行与审查共同决定结果。Skill 的价值是组织步骤、工具和检查，工程的价值是让创作可修改、可追踪、可复用。值得保留的模块包括有来源的产品简报、角色与素材版本、风格 / 动效组件、歌曲和场景时间契约、提供商适配、任务恢复、预算限制、渲染合成及分层验收。

提示词约束风格与意图，属于软控制；参数校验、可用组件、执行隔离、任务顺序和预算门控需要程序实现。技术成功、事实准确与主观效果应分别审查：生成了文件不等于表演自然，上传音频不等于每个音素同步，已有样片也不等于通用自动产品已经完成。

## 初始结论与来源（2026-10-01 历史记录）

作品源码、创作工具和资料索引应分别使用。代码视频通常通过时间线组织场景、浏览器逐帧绘制、ffmpeg 编码；实时游戏响应用户输入。makevoid 工具还调用外部素材生成服务，涉及额外费用与配置。

网页每张卡片附对应 GitHub 源库。完整数据在 web/app.js 中。未复制上游源码或媒体；Tidewater 与 ClaudeAnimationBase 页面标示 MIT，其余许可尚未逐项确认，采用时应核对当前 LICENSE 和媒体条款。
