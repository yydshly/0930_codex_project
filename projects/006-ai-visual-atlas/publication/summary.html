RESEARCH SUMMARY / 能力、原理、探索与价值

看清创作能力，

从最初的十个链接，研究真实作品如何由模型、代码、素材和工具链共同制作；重点实做歌曲 MV 与网页宣传片。

研究结论：代码动画由模型或作者编排、程序按时间绘制；混合 MV 加入图像与视频模型的表演素材；游戏由实时引擎响应操作；资料索引提供参考。设计、素材、模型、执行和审查共同决定最终效果。

SCOPE / 研究什么、适合什么

作品、工具、基础工程和索引分别理解。

能力与范围

十项目覆盖风格短片、手绘与动态字体、混合音乐 MV、网页宣传片、实时游戏及案例索引。它们的输入输出和运行条件不同；有些是成品源码，有些才提供生产流程。

共同原理

语言模型理解和设计、编写代码；图形与媒体工具运行、渲染、合成和编码。写实表演可由专门的视频模型生成；Skill 组织制作方法与检查。

使用场景

产品传播、信息与机制演示、歌曲视觉、角色故事、互动体验、技术教学、风格与工具选型。不同任务应挑对应的制作路线。

本研究边界

这是有来源、有实作证据的研究汇总。通用输入到视频产品、整曲自然演唱和全部游戏兼容性尚未完成验证；作者的成功案例不等于通用成功保证。

06 · 音乐 MV 制作 Skill

makevoid/motion-graphics-music-video-skill

能力与产物
歌曲＋创意 → 音乐分析、角色、分镜、表演镜头、动效与整曲 MP4。
实现原理
GPT Image 2.5 角色图 → Fal H3 Max＋对应音频生成短镜头 → 绿幕提取人物 → p5.js 场景 / 合成 → FFmpeg 合入原曲。

我们的探索

我们做了什么，并由此确认了什么？

十项目的本地效果与技术研究

实际探索：保存并查看部分原作样片，构建原作游戏和源码预览；为十项目逐项记录输入、产出、原理、条件与边界。

范围：作者样片、源码预览和游戏启动界面分别证明不同范围；没有完成每个 Skill 的完整生产或所有游戏的流程验收。

约 127 秒整曲图片 MV

实际探索：以《Still a Light》及同一人物参考制作六幕图像，运镜、转场与原曲合成实际 MP4。

范围：图片镜头版，整曲真实人物演唱尚未完成；它不能代表原 makevoid 的表演质量。

五秒 H3 表演与人物场景合成

实际探索：通过 MiniMax 官方 API 生成歌曲 10–15 秒的真实表演；提取人物透明层，与窗景和对应歌曲片段合成。

范围：仅一小段，逐字口型、坐姿、桌椅接触和前后遮挡尚未验收。

24 秒六幕网页宣传片

实际探索：读取真实能力图谱网页，模型编写分镜与 Canvas；本机导出 720p、24fps、576 帧，完整解码通过。

范围：无音轨；复用已有 H3 素材。任意 URL 的通用采集、模型后台、队列和自动交付服务尚未接通。

还拆解了人物主导与场景主导、分层与完整场景、音频条件与逐字口型、坐姿接触与遮挡、软提示与硬规则。这些帮助解释原作与本机试验的差异，并确定下一步需要补的模块。

VALUE / 探索的意义是什么

从一次效果，沉淀可修改、可追溯、可复用的制作能力。

判断价值

能选对制作路线

区分代码、生成素材、游戏和索引；按场景选工具，明确设备、模型和费用条件，避免把成品误当生成服务。

技术价值

能保留执行底座

事实快照、素材与角色版本、统一时间、动效组件、提供商适配、任务恢复、渲染与合成可以跨创作复用。

产品价值

能控制过程并验收

产品规定内容、结构、可用素材、预算与组件。文件成功、事实准确、口型自然和美感分别检查；商业效果仍需实际业务验证。
