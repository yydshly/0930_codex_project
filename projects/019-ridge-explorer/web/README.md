# Ridge Explorer · Web 运行与操作说明

独立的 019 客户端在已保存的 018 场景基础上，增加自由骑行、连通路线、溪流、营地和观景地点。v2 继续补全小径导航、地点停留与取景、骑行恢复及可选环境声音。它使用同一套三维风景、大气与角色资源；原版仍可独立打开。


`npm run build` 先构建 `app/dist/client/`，再将真实浏览器产物复制到 `web/`。资源使用相对路径，可从共享站子目录加载；通过 HTTP 打开，避免 `file://` 的模块与资源限制。`app/package-lock.json` 保留锁定依赖，Three.js 版本为 0.180.0。

## 骑行与探索

自由骑行是用户控制的前进和转向。主小径与两条支线在同一块地形上连通：谷侧经过薄雾溪流和林边营地，再回到主路；另一侧通往雪峰观景台。靠近地点触发发现，地图位置来自真实世界坐标。

马匹沿用真实 GLB 的奔跑形变，动画节奏按实际移动速度调整。松开前进逐渐停下，制动停止前进；停止后从奔跑形变平滑回到原模型的触地静止姿态。暂停和摄影保留当前姿态。边界、过陡坡面、树干与营地道具采用简化约束；没有完整游戏物理和骑马动作系统。

| 控制 | 操作 |
| --- | --- |
| `W / ↑` | 前进，最高 4.2 m/s |
| `A / ←`、`D / →` | 向左、向右转向 |
| `S / ↓` | 制动；不会倒退播放马匹动画 |
| 按住 `Shift` 和前进 | 最高 6.3 m/s |
| “沿途巡游” | 以 4.2 m/s 沿连通环线游览，进入每个地点中心 2 米范围后停留 12 秒 |
| “继续巡游” | 提前结束当前地点停留，沿小径继续 |
| `空格` | 场景内暂停或继续时光 |
| `M` | 打开探索地图，选择地点开启沿小径的路线、路程与转向提示 |
| `E` 或“停留看看” | 在地点附近打开地点卡，选择“在此取景”观察当地景物 |
| `P` | 进入或结束摄影 |
| `H` | 隐藏或显示界面，沉浸观看 |
| `Esc` | 关闭当前弹窗、结束摄影或退出沉浸 |

选择地图地点后，金色线路沿实际小径连接骑手与目的地，显示沿路剩余距离。离路时虚线指向返回小径的位置，跟随方向提示自行骑行。巡游停留时马匹停止，场景仍可观察；全局暂停和摄影会冻结停留倒计时。

发现记录保存在浏览器 `ridge-explorer.visited.v1`。v2 的 `ridge-explorer.ride.v1` 另记录最近有效骑行的位置、朝向、累计距离、世界时刻、天气和取景参数。重新打开仍展示默认起点；起点处点击“继续上次骑行”才恢复记录，以自由骑行和静止马匹继续。回到起点前会保存当前有效骑行，重置与重新加载保留发现和骑行记录。记录属于当前浏览器，禁用或清空浏览器存储后无法恢复；存储失败不会阻止探索。弹窗、暂停、摄影和失去窗口焦点会停止骑行输入。

触屏布局提供可按住的前进、左右转向、减速和加速按钮；松手、触摸取消或失去焦点会清除对应输入。触屏操作支持不代表实体手机 GPU 已完成验收。

直接拖动画面旋转、滚轮缩放，首次手势接管当前镜头。返回跟随镜头后，相机重新随骑手朝向移动。界面中的操作提示说明当前骑行和摄影键位；控制与暂停期间应停止骑行输入，失去窗口焦点后清除按键状态。

## 天气、镜头与照片

天气面板保留“山雨欲来”“晨间薄雾”“云隙夕光”，以及雾气浓度、山间风力和云隙亮度。分层开关分别控制风动草地、山腰低云和远景空气透视，便于观察各层效果。控制面板默认折叠，保持风景可见。

进入摄影模式会冻结世界时间和骑行，并切换到环绕镜头。可拖动旋转、滚轮缩放，通过视角调节使用 28–80° 取景；“原色”“暖调”“冷调”直接作用于最后的场景渲染，因此 PNG 保留同样色调。附近地点卡的“在此取景”将相机对准溪流、营地或观景台，马匹留在当前位置。结束摄影恢复进入前的暂停与镜头状态。

保存画面生成当前 WebGL 画布的原始 PNG，并显示图像预览与标准下载链接，导出不包含页面控制界面。沉浸观看用于隐藏界面；暂停、重置和关闭弹窗按实际界面提示操作。

## 山间声音

打开“调整天气与镜头”，点击“山间声音”才启用音频，初始和刷新后保持关闭。风声受风力与天气影响，溪流及火堆随骑手与地点的实际距离衰减；三拍蹄声按马匹行进的真实距离触发，停止后不继续打拍。暂停、摄影、弹窗或隐藏页面时静音，恢复骑行不会补播暂停期间的蹄声。

这些声音由 Web Audio 程序合成，使用滤波噪声与短音，无外部录音。骑行存档不保存声音开关；设备或浏览器无法开启时会显示提示，仍可正常浏览与骑行。

## 打包、保存与许可

仓库根目录执行 `python scripts/build_site.py`，将已登记的客户端复制到 `_site/projects/019-ridge-explorer/`。精确白名单仅允许此项目的马模型、原有声明，以及 `assets/exploration/` 中三个营地 GLB 和原始许可、新来源声明。其他模型、内部文本、基线 ZIP、依赖和私有目录不会因这些规则放行。

`python -m unittest discover -s tests -p test_ridge_explorer_site.py -v` 使用真实客户端检查资源字节、GLB 格式与许可、JS/CSS 子路径和白名单范围。此检查不构建客户端，不生成替代风景，不证明图形渲染或浏览器交互通过。

018 的源码和网页 ZIP 与 SHA-256 清单保存在原版 `releases/`，未放进 019 的公开网页。保存方式、恢复说明与素材条件见 [019 项目说明](../README.md)。营地模型的 CC0 与马模型的 CC BY-NC-SA 3.0 分别保留；商业使用须遵守每项素材的条件。
