# 从效果机制到业务技能

本轮目标是让案例研究形成可重复执行的交付方法。实际视觉与交互核心分五项研究，面向客户则按四类任务组织：品牌叙事与选型、操作式产品解释、区域服务查询、内容揭晓与任务反馈。

## 我们沉淀了什么

- 项目内 `interactive-business-experience` 技能：任务选择、内容与状态、结果导出、视觉/任务验收与价值证据。
- 输入约定：客户提供品牌与产品资料、自有素材、选项、参数范围、地区或提示规则。
- 输出约定：运行页面、当前真实结果、需求说明、结构化数据与验收记录。
- 页面工作台：编辑计划范围并记录示例结果，提供 Markdown 与 JSON 的真实本地下载。

原站素材与绘制核心保留来源。用于新客户时适配自有素材和业务规则，不把原站完整皮肤、外部视频或澳大利亚地图当默认客户资产。研究模块尚无统一 content/config API；技能指导适配开发，不是现成低代码 SDK。

## 价值和证据

对用户：内容、选择、反馈与下一步在同一条任务路径；结果可以带走。对团队：复用输入输出约定、状态流程、适配方法与验收标准，减少每个项目重新组织需求和交付。对客户业务：理解正确率、任务耗时、选择错误、需求完整度和有效咨询是待测指标。

已实现与已验收的结果能作为交付依据。节省工时、提高咨询或收入均未实测，不能仅凭动画与功能通过断言这些收益。实际采用时以相同任务比较原有方式与新体验，记录基线和结果。

## 四类真实运行证据

品牌场景包含三款虚构茶款和活动目标，参数同步包装、事实 JSON、需求单与技能计划。产品场景升级为原创 ARC 桌灯真实 WebGL 展示：曲面与 PBR 材质、三色/两材质、棚拍/夜景、四视角、四部件热点、旋转/缩放、灯光和结构展开；工作台导出最近配置及观察状态，产品页面支持当前画面 PNG 和需求单。区域示例：杭州覆盖改造和维护，宁波覆盖改造、不覆盖维护，上海未覆盖；显示与导出使用同一规则。内容示例为三条普通提示及行动内容，支持重复与重置，没有真实券或抽奖。

产品新能力对应的可验收价值是“交互产品解释与配置记录”：用户能主动观察部件与变化，团队拿到明确参数和画面。真实客户素材、产品尺寸、材质/光照标定及库存/报价规则仍需接入。ARC 是本项目原创概念模型，未按工业精度或物理测量校准，也未使用实物照片；本地 Three.js r160 渲染库采用 MIT 许可。二维兼容回退保留选配与导出，不支持自由旋转缩放。

品牌和产品快照按场景缓存；切换到其他业务场景不会丢失前一配置。本次页面缓存在刷新后清空。编辑计划项目名和任务不修改原型本身，integration 范围只增加业务接入计划，不冒充业务完成。

## 验证记录

`tooling/verify-skills.mjs` 的 39 项检查通过，`notes/skill-verification.json` 无未处理浏览器错误。检查实际 Markdown 与 JSON 下载、客户任务文本、产品/茶款配置、跨场景结果保留、六个区域/服务组合、揭晓/循环/重置、减少动态偏好、键盘和 390/768/1440 像素布局。新增茶款后原业务 48 项回归也通过。

独立评审修复两个问题：跨场景产品结果遗漏；默认品牌任务大于原型能力（现已对齐为茶款选择和需求输出）。技能文件通过官方 quick_validate.py。实际截图在 `assets/skills-workbench.png` 和 `assets/qa/skills-*.png`，下载证据在 `notes/skill-downloads/`。

产品升级的 50 项独立检查在 `notes/product-showcase-verification.json`，核对 WebGL 像素、配置、视角/热点、夜景/灯光、旋转/缩放、实际 PNG、中文需求单、技能计划和 390/768/1440 像素布局。视觉证据在 `assets/qa/product-final-{hero/detail/structure}-{390/768/1440}.png`，实际下载在 `notes/product-downloads/`。第五版重新运行产品、技能和业务回归；通过报告只证明检查范围内的行为，视觉复核另见 scene-visual-review-v5.md。未测真实手机性能、实物精度或商业收益。

下一步将技能用在一个真实客户任务中，补入客户素材、规则与所需接口，形成真实项目的交付和价值证据。

## 第五版：视觉质量也必须落实到交付

品牌摄影、产品反射与微纹理、庭院三维植物/水面/日夜不是网址能直接提供的客户素材；它们需要按目标制作、接入并检查。三场景分别展示品牌表达、产品理解与空间取舍，仍由业务状态驱动实际反馈和导出。最终呈现依赖模型的制作与取舍能力，技能积累的是已验证的实现和验收方法。

功能通过数量不能代替质感评审。第四版的通过结论已因用户反馈重新开启；第五版保留来源、升级前后真实画面和操作录像，让用户直接判断差异。采用真实客户项目时还需验证理解和沟通收益。

## 第六版：素材作用可观察、结果可保留

产品让客户在室内全景与棚拍下比较配色和表面，反射开关让材料差异直接可见；需求单、事实与技能计划保存 `setting/reflections` 和实际背景状态。庭院近景让空间总览与细节评审使用同一模型，避免用另一张概念图替代当前方案。房间和叶片原图可展开查看，素材与效果之间的对应关系可以检查。

本轮是把现有素材接入真实交互，未重新生成房间或植物。可交付价值是清楚的观察入口、可重复的比较与准确的结果记录；理解改善、沟通减少与商业收益仍需真实用户任务验证。
