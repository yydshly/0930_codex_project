# AURA · 耳机选配 · 产品定义与首版交付

## 产品想法

让关注外观的用户看清耳机材质、比较配色与表面，再留下准确配置。

目标用户：关注设计与日常佩戴的购买者
用户问题：照片不能解释不同配色和结构，购买前希望看清外观与细节。
输入：产品配色、表面与观察状态
完成结果：保留配色、表面、折叠和观察环境的配置记录

## 首版任务

1. 看系列影像与材质
2. 选择配色与表面
3. 旋转、折叠与部件观察
4. 导出当前配置

## 已实现原型

- 产品目标与制作方案可随定义保存
- 系列影像与独立品牌页
- 原创耳机实时三维
- 配色、表面、折叠与环境同步
- 配置记录/JSON/PNG 与独立项目包

构建方式：已实现的本地产品模块与当前定义。本页自由文本不由在线模型分析。产品选配使用原创概念模型；地区规则为用户填写的本地数据，默认示例尚未获业务方确认。

## 下一阶段接入

- 厂商真实型号、规格与模型
- 库存、报价或订单接口

## 验收

- 完成选配任务
- 画面与导出一致
- 折叠与部件关系可读
- 桌面和手机可操作

## 待测价值

- 访客能否看清材质与结构
- 选配记录是否保留真实选择
- 比较和选配的耗时

## 启动项目包

在解压目录运行 python -m http.server 8080，再打开 http://127.0.0.1:8080/ 。包内不需要 npm 安装，包含当前配置和需要的本地文件。模板已实现的任务可操作；账号、支付、真实提交和 AI 服务未接入。
