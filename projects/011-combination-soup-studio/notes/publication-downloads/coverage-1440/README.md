# 到家 · 安装服务查询 · 产品定义与首版交付

## 产品想法

让顾客先确认自己的地区是否提供安装服务，再留下完整需求。

目标用户：准备预约灯具安装的顾客
用户问题：顾客反复询问服务范围，咨询信息也经常不完整。
输入：地区、服务规则和用户需求
完成结果：明确的资格结果与可交接的咨询摘要

## 首版任务

1. 选择地区
2. 核对服务资格
3. 填写需求说明
4. 导出查询摘要

## 已实现原型

- 地区规则查询
- 覆盖与未覆盖反馈
- 需求摘要导出

构建方式：已实现的本地产品模块与当前定义。本页自由文本不由在线模型分析。产品选配使用原创概念模型；地区规则为用户填写的本地数据，默认示例尚未获业务方确认。

## 下一阶段接入

- 业务方确认的地区规则
- 咨询提交与送达接口

## 验收

- 用户完成完整任务
- 结果与输入规则一致
- 导出与屏幕一致
- 手机和键盘可操作

## 待测价值

- 查询结果与确认规则是否一致
- 咨询摘要缺失字段数
- 确认覆盖范围的耗时

## 启动项目包

在解压目录运行 python -m http.server 8080，再打开 http://127.0.0.1:8080/ 。包内不需要 npm 安装，包含当前配置和需要的本地文件。模板已实现的任务可操作；账号、支付、真实提交和 AI 服务未接入。
