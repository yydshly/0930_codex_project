# 到家 · 维修资格查询 · 产品定义与首版交付

## 产品想法

让顾客确认自己所在地区是否可以上门维修，再整理故障需求。

目标用户：准备预约灯具安装的顾客
用户问题：顾客不清楚上门范围，咨询经常缺少故障说明。
输入：地区规则和故障需求
完成结果：明确的服务结果和可交接的维修需求

## 首版任务

1. 选择地区
2. 核对服务资格
3. 填写需求说明
4. 导出查询摘要

## 已实现原型

- 地区规则查询
- 覆盖与未覆盖反馈
- 需求摘要导出

构建方式：已实现的本地产品模块与当前定义。本页自由文本不由在线模型分析。产品选配使用原创概念模型；地区规则为用户填写的本地数据，默认示例尚未获业务方确认。

## 下一阶段接入

- 业务方确认的地区规则
- 咨询提交与送达接口

## 验收

- 用户完成完整任务
- 结果与输入规则一致
- 导出与屏幕一致
- 手机和键盘可操作

## 待测价值

- 查询结果与确认规则是否一致
- 咨询摘要缺失字段数
- 确认覆盖范围的耗时

## 启动项目包

在解压目录运行 python -m http.server 8080，再打开 http://127.0.0.1:8080/ 。包内不需要 npm 安装，包含当前配置和需要的本地文件。模板已实现的任务可操作；账号、支付、真实提交和 AI 服务未接入。
