# 头戴式耳机 · 产品体验 · 产品定义与首版交付

## 产品想法

让用户看清外观、比较材质并选择配色，留下明确的配置。

目标用户：关注外观与日常佩戴的购买者
用户问题：照片不能解释不同配色和结构，购买前希望看清外观与细节。
输入：产品配色、表面与观察状态
完成结果：让用户看清外观、比较材质并选择配色，留下明确的配置。

## 首版任务

1. 看系列影像与材质
2. 选择配色
3. 旋转、折叠观察
4. 导出当前配置

## 已实现原型

- 产品目标与制作方案可随定义保存
- 系列影像与独立品牌页
- 原创耳机实时三维
- 配色、折叠与环境同步
- 配置记录/JSON/PNG 与独立项目包

构建方式：已实现的本地产品模块与当前定义。制作要求来源：AI 制作示例 · 预置 · 已调整；方案是制作依据，专属形体与素材不会在浏览器内自动生成。产品选配使用原创概念模型；地区规则为用户填写的本地数据，默认示例尚未获业务方确认。

## 下一阶段接入

- 厂商真实型号、规格与模型
- 库存、报价或订单接口

## 验收

- 完成选配任务
- 画面与导出一致
- 折叠与部件关系可读
- 桌面和手机可操作

## 待测价值

- 访客能否看清材质与结构
- 选配记录是否保留真实选择
- 比较和选配的耗时

## 启动项目包

在解压目录运行 python -m http.server 8080，再打开 http://127.0.0.1:8080/ 。包内不需要 npm 安装，包含当前配置和需要的本地文件。模板已实现的任务可操作；账号、支付、真实提交和 AI 服务未接入。

## 制作要求与验收

- 品牌首屏：完整头戴轮廓，手机标题不能覆盖头梁。 验收：检查 390 像素首屏的主体与按钮。
- 材质细节：银色铝壳、深色皮革耳垫、弧形头梁与金属旋钮保持同一设计语言。 验收：首屏与近景并排检查产品识别点，不以泛化耳机图补图。
- 实时选配：银、石墨与橄榄配色；哑光/亮面；旋转、折叠和分层观察实际改变模型。 验收：每种操作检查实际像素与配置，折叠 0/50/100% 检查部件关系。
- 观察环境：可切暖色摄影棚与夜色声场，轮廓与材质保持可读。 验收：环境实际改变灯光与背景；操作后导出保存该环境。
- 可读与布局：主要产品、标题与操作在桌面和手机保持完整，文字和控件不互相遮挡。 验收：检查 1440、768、390 像素视口的真实截图与点击目标。
- 状态与交付：选择、说明、结果和下载使用同一状态源；独立包携带实际使用的素材。 验收：修改选项后实际下载并核对，再解压阻断外部资源运行。
- 本次操作范围：实际操作包含：旋转观察、选择配色、折叠观察。本项覆盖先前方案中对关闭操作的要求。 验收：页面与导出只提供本次选择的操作；关闭表面或部件后不显示对应控件。
