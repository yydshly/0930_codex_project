# 工作台内试用产品 · V1.5

日期：2026-10-03。revision：20261003-14。

[新版工作台](http://127.0.0.1:8951/projects/011-combination-soup-studio/foundry/studio.html?example=headphones&revision=20261003-14)

此前制作方案与实际产品分在两个页面。用户必须先阅读长方案、打开产品工作台，才能看到选配效果。本轮将耳机的实际实时模型前置到目标工作台，并把工作台选择接入已有完整产品与交付流程。

## 实际改进

- 耳机示例链接直接载入预置方案与实时模型。打开后无需再次点击整理；生成后 URL 移除示例重置参数，刷新同一页面可以恢复本次方案和选择。
- 工作台可以旋转、切换视角、比较配色和表面、切换环境、观察折叠与部件。采用已有消费者页面的同一个 `createHeadphoneRenderer`，没有制作另一套简化示意。
- 可修改文案与操作范围；应用后立即进入预览。调整尚未应用或目标改变时，旧模型停用并释放资源，旧方案不可继续交付。
- 工作台选择写入方案记录。完整产品页接收相同的配色、表面、折叠、展开、环境与自定义相机；制作简报和实际下载包保留选择。
- 桌面预览将文案与操作放在模型旁，手机先展示画面再展示操作；模型和视角按钮分开布局，中文标题均衡断行，避免尾部孤字。
- 无 WebGL 时保留明确提示和配置记录；真实 WebGL 连接失效时停用模型操作，窗口尺寸变化不会误报恢复。

`studio-product.js` 负责统一的方案到产品定义转换；`studio-live.js` 负责工作台预览。目标与方案仍由既有 `studio.js` 管理，完整页面与项目包仍采用已有产品模块。

## 能力边界

工作台内预览目前接入已实现的头戴耳机模块。马桶、桌灯仍可打开已有对应产品；咖啡机等未知类别只整理要求与模块缺口，不展示耳机替代。制作要求的文字调整不会自动制作新几何或影像。

当前系列影像、模型和规格边界与 V1.4 相同：原创概念，未作厂商实物或声学标定；本轮没有新增生成影像或真实在线模型调用。手机使用模拟视口，未测试真机性能、完整无障碍合规或商业收益。浏览器截图与流程验证沿用此前授权的本地 Playwright；没有发布网站或修改真实业务数据。
