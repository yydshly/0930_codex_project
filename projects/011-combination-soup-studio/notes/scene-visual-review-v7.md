# 第七版 · 模型与材质细节

本轮基于现有第六版继续优化，不复制原站整页，也不生成虚假的界面截图。先记录当前桌面和手机画面 `assets/qa/v7/before-{brand/product/garden}-{1440/390}.png`，并结合第六版实际近景检查可见问题。

| 可见问题 | 修改与核对 |
| --- | --- |
| 桌灯下方只有一块木板，空间支撑不清楚 | 室内展示增加桌框和渐细桌腿；主视角缩小约 9% 以显示更多桌面与支撑，哑光材质保留更有层次的高光。检查 `final-product-{1440/768/390}.png` |
| 树冠呈规整球状，近景看不见枝干 | 树干和枝条使用渐细几何，九组非对称叶簇沿枝条分布；保持生成叶片的透明轮廓与弯曲。检查 `final-garden-plant-{1440/768/390}.png` |
| 草叶过宽、直立，变化不足 | 草叶缩细、弯曲、渐尖，并改变长度和颜色，保留实例绘制 |
| 池底是贴近水面的平板，部分石子露出水面 | 基础分区围绕真实下凹盆体，池底下降，石子放入水下；水面增加细波纹法线，与原有顶点动态及场景反射结合。检查 `final-garden-water-{1440/768/390}.png` |
| 手机上修改下面参数时，画布可能已离开视口而停止更新 | 修复前已复现：画布在视口外、事实为 gloss，但 Canvas 像素没有改变。修复后同一操作改变像素；参数与导出刷新一次，隐藏的持续动画仍暂停。产品和庭院各自验证离开视口后的 PNG 与当前 Canvas 字节相同 |

最终画面在 `assets/qa/v7/`，当前组合与前后对照为 `assets/scene-polish-v7-{gallery/comparison}.png`。组合只缩放并排列真实浏览器截图。`assets/scene-polish-v7.mp4` 为 1440×1100 的实际操作录像，包含产品材质、旋转、夜景、结构，植物与水景近景、水面动态、方案 A 与总览平面。

当前第七版通过 47 项场景核对、41 项品牌/庭院回归及 50 项产品回归。报告为 `scene-refinements-v7-verification.json`、`business-scenes-v7-verification.json` 和 `product-showcase-verification.json`；浏览器未处理错误为空。47 项包含新增加的产品/庭院离开视口后的修改和真实 PNG 输出检查。早先功能检查中的一次首屏切换失败也促使本轮检查主动刷新与视口状态，修复后全部重跑。

使用已有生成摄影、LDR 全景、透明叶片与木石纹理。产品和庭院仍是交互概念模型，水面是实时视觉表达；没有进行流体仿真、施工精度、实物材质或照度标定。三档浏览器视口核对不等于真实手机硬件性能测试。截图与功能通过不证明达到原站照片的质感，视觉偏好仍由用户判断。
