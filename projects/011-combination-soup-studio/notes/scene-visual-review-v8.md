# 第八版 · 庭院层次、桌灯微调与可带走的选择

沿用项目的原创摄影、参数化几何和业务契约。先在实际浏览器记录第七版桌面、平板与手机画面，保存在 `assets/qa/v8/before-*.png`；本轮没有生成网页效果图。最终组合和同视角比较均只使用真实浏览器截图，见 `assets/scene-polish-v8-{gallery/comparison}.png`。

| 实际画面或任务问题 | 实现与结果 |
| --- | --- |
| 水池只有透明绿色表面与池底，倒影不足 | 用镜像相机渲染当前场景；裁剪池面以下区域，把真实树木、边界和灯光倒影投射到水面。多方向法线、细波、角度反射和底部透明层次结合，日夜与相机变化均可观察 |
| 枫叶过亮、叶簇分层规整，灌木与树木使用同样叶片 | 主枝增添细枝，沿枝组织大小不同的内外叶簇；叶片弯曲、朝向和颜色变化。灌木改为独立小叶几何，避免把枫叶重复贴在所有植物上 |
| 木石凹凸过重、直接光和植物颜色不协调 | 减弱凹凸幅度，调整较低的后侧日光、前侧补光和环境亮度，让影子与水面高光明确 |
| 桌灯过亮的涂层高光与室内环境不协调 | 调整哑光粗糙度、清漆与直接光强度，定向生成室内反射环境，微调全景取景。全景依旧是概念背景，不是经过尺寸标定的三维房间 |
| 看过互动后，用户不容易说明做了什么选择 | 三个业务场景新增同源结果区：活动主题、产品配置、庭院面积；需求单和 JSON 同步。庭院独立保存 A 与当前参数，明确当前相对 A 的差值 |
| 新结果区与原有产品网格行号冲突，在窄屏产生隐式第二列；缩放遮挡视角按钮 | 实际点击回归发现遮挡，检查布局定位到隐式 Grid 列。统一窄屏列及行号，缩放移动到视角栏上方；新增完整容器宽度和真实按钮命中检查 |

评审示例：在 12×8 m 的同一场地保存水景 18%、绿化 32%、平台 18% 的 A，改为水景 14%、绿化 30%、聚会重点的平台 30%。结果显示水景 -3.8 m²、绿化 -1.9 m²、活动平台 +11.5 m²；文件保留精确差值 -3.84/-1.92/+11.52 及两套参数。查看 A 时的面积与 PNG 回到 A，当前编辑参数仍独立保留。
