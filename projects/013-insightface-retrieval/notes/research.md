# 讨论脉络与结论

日期：2026-10-02。研究依据是当日公开文档、论文与选定 master 源码，未固定 commit，未下载权重或运行上游模型。

## 我们如何形成理解

| 讨论问题 | 形成的理解 |
| --- | --- |
| AVScan 的本质与卖点 | 把截图反查作品和时间的需求做成低门槛检索入口；后台实现没有确认 |
| 图搜图是否必须认人 | 画面同源匹配、人物身份检索与语义相关检索的目标不同 |
| 是否一定需要特征数据库 | 现代路线通常提前提取特征并建立目标索引；传统指纹与局部特征也有用途 |
| 如何从很多人中找出某个人 | 人脸模型提取身份向量，参考照与图库的向量在兼容空间中比较；仍会误认与漏认 |
| 特征到底是什么 | 网络从训练反馈中学习可区分的像素组合，各维不是预先指定的某个五官 |
| 模型、算法和数据库是否一回事 | 算法规定训练目标，模型权重执行特征提取，数据库保存目标与来源映射 |
| InsightFace 底层与可靠性 | 检测、关键点对齐、识别网络、训练方法与推理工具协作；实际可靠性按自己的样本验证 |
| 个人能不能做 | 复用现成模型建立小图库原型可行；领先模型训练和海量视频服务的资源要求高 |
| 识别的实际价值 | 缩短人工翻找、形成候选与归组；姓名和视频出处需要独立映射，允许没有可靠匹配 |
