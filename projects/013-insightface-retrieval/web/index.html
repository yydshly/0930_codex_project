先明确目标

同样是一张图片，问题有三种。

身份检索

这个人出现在哪些照片？

保留稳定身份特征，比较参考照与图库中的脸；姓名需要另有登记映射。

看找人路线 →
同源匹配

这张截图出自哪个视频？

保留具体画面的姿态、纹理、构图和局部细节；返回已收录视频与时间位置。

看找出处路线 →
语义检索

有哪些内容相似的素材？

关注场景、物体、动作是否相关；找到相关片段，不保证原始截图出处。

看内容检索路线 →

我们形成的核心理解

模型决定能区分什么，
目标库决定能搜到什么。

算法规定训练目标，网络与权重生成特征，特征数据库保存目标，索引提高检索效率。训练模型和日常建库是两件事；最像的候选还需要阈值、拒识与来源映射。

识人 ≠ 找原画面相似 ≠ 同一人向量 ≠ 姓名库外目标可无匹配

源库能力与底层

InsightFace 能提供哪几块能力？

检测与对齐

先找到可比较的人脸

SCRFD / RetinaFace 输出脸框与关键点；几何对齐减少位置与拍摄变化。检测到脸不等于识别身份。

查看源库能力 →
网络与训练

从像素学到身份向量

ResNet 等识别网络生成特征；ArcFace 是角度间隔训练方法，权重记录训练学到的参数。

查看特征学习 →
运行与索引

模型和目标库分别负责什么

ONNX Runtime 执行模型；索引匹配向量；路径、登记信息和视频时间映射回答来源。

查看建库与查询 →

实际识别的价值

把人工寻找变成可复核的候选。

技术已有可用实现；自己的图库是否可靠，要分别测误认、漏认、排名、库外目标和运行成本。公开 LFW 成绩不能直接当作自己的 1:N 检索准确率。

图库 / 相册

减少人工翻找

按参考照找人物照片，协助活动照片筛选与素材归组；多个不确定候选仍需要复核。

看实际价值与验收 →
视频 / 素材

缩小出处查找范围

截图匹配可定位已收录视频，身份检索可提供人物出现线索；人物身份不能独立确定镜头出处。

个人 / 原型

复用现成模型，小范围验证

建库通常不需要重新训练每个人。先用小图库验证误认、漏认与拒识，再考虑大规模索引。
