# ARC LAB · 研究工作台照明选型

这是保留的补充实验，不计入十个案例的一对一演示。十例主入口见 [十案例产品演示](../labs/README.md)。

这是一份已经实现的本地概念原型：给我们的研究工作台选一盏灯，先认识结构，再保存方案 A、调整另一套配置并导出选型记录。模型与渲染基础来自项目 011 的原创 ARC 桌灯，选型、方案对比、保存和交付流程由项目 015 实现。

[主站实际演示](http://127.0.0.1:8975/#demo) · [独立打开选型页](http://127.0.0.1:8975/demo/) · [研究说明](../../notes/demo-research.md)

## 可以实际操作什么

- 观察整体、正面、细节与结构；在三维模式下拖动旋转、滚轮或双指缩放，聚焦画布后用方向键调整。
- 通过四个部件入口查看灯罩、扩散板、支柱和底座说明，并聚焦相应部件。
- 从工作桌、夜间氛围或展示拍摄预设开始，选择三种配色、哑光或亮面、日光或夜景、室内或简洁背景。
- 调整画面光感与结构展开，开启或关闭缓慢自动旋转；自动引导分四步展示外观、材质、结构与夜间氛围，可随时停止。
- 保存方案 A，继续修改形成当前方案 B；比较配色、表面、使用氛围、展示环境与视觉亮度五项差别，或恢复 A。
- 为方案填写名称与用途，导出 Markdown 选型记录、配置 JSON 和当前画布 PNG。

## 建议体验顺序

1. 点“结构”或任一部件，先看懂零件组成。
2. 选定一套工作桌配置，点“保存为方案 A”。
3. 切换夜间氛围或改变材质，在对照区查看五项配置差异。
4. 填写方案名称与考虑，导出配置、选型记录和当前画面。

“恢复初始配置与视角”会重置当前选择，保留已经保存的 A。自动引导会切换当前配置，也保留 A。

## 保存与导出的范围

当前配置、名称、用途、标准视角和方案 A 自动保存在此浏览器的 localStorage。同一浏览器、同一主机和端口下，独立页与主站嵌入页共享存档。恢复或重新打开时使用标准视角；自由拖动后的精确相机角度不属于恢复内容。自动旋转在重新打开或恢复 A 时关闭。

浏览器不允许本地保存时，可以在当前页面继续操作和下载，保存状态会提示限制。数据没有同步到云端；换浏览器、清理本地数据或更换主机、端口后，不能据此承诺恢复原存档。

JSON 记录配置、观察状态、方案 A、五项差异、来源与范围；Markdown 记录用途、当前选择、结构展开和对照结果。第一版没有 JSON 文件导入入口。PNG 导出会先回到模型并刷新最新配置，再截取画布画面；不包含页面中的表单和对照表。

## 运行

在研究集根目录运行：

```powershell
python -m http.server 8975 --bind 127.0.0.1 --directory projects/015-ai-creative-products/web
```

访问 `/demo/` 独立体验，或在主站进入 `#demo`。本页使用 JavaScript 模块及本地纹理，应通过 HTTP 服务打开。主站用同源 iframe 嵌入，独立页面可以显示完整页头和来源说明。

`app.js` 管理选型状态、对比、保存、引导与文件生成。`runtime/product-renderer.js` 使用本地 Three.js r160 渲染原创几何、材质、光照和环境；其依赖与三张 WebP 素材均在 `runtime/` 内，Three.js 的 MIT 许可随 `runtime/vendor/THREE-LICENSE.txt` 保存。演示没有模型服务或云端渲染调用。

## 能力边界

这是一盏原创概念桌灯，未校准真实尺寸、照度、色温、功率、价格或生产规格。画面光感百分比是视觉参数，不是照明测量。室内环境使用生成的 LDR 素材，不是测量 HDR 环境。

WebGL 不可用时保留二维兼容预览、部分选配、结构查看和导出；不能自由旋转，室内环境、自动旋转和正面视角入口会关闭。兼容画面不等同于三维材质与光照验证。

没有在线订单、采购请求、库存、支付、多人协作或商业成效数据。该原型只实现八个产品方向中的一个选型场景，不代表八项完整产品都已完成。
