# 展示页

原生静态页面，直接打开 `index.html` 或使用 Python HTTP 服务。来源位于 `source-data.js`，分析与产品计划位于 `research-data.js`。

首页默认进入效果展厅，展示十个大画面原作视频卡片；产品对比卡和计划中也可直接观看关联效果。

初次打开无第三方媒体请求。点击播放后原生播放器读取 `video.twimg.com`，失败时提供重试和原帖链接。同一时间只播放一条，离开视图或滚出屏幕后暂停。页面没有外部字体和运行库，不调用付费模型。

本轮增强了阅读与比较入口：

- 顶部直接进入三个优先产品方向；案例可切换上一例、下一例，并保留阅读角度。
- 类型筛选与搜索同步案例详情，无结果时可一键清除条件。
- 播放器提示加载与缓冲状态，可重试或回到原帖查看。
- 产品对比默认选择三个优先方向，允许改选最多三项，对照任务、交付、第一版、验收、复用与难点。选择保存在当前浏览器本地，不上传数据。
- 桌面采用 sticky 导航，手机布局与操作入口做了适配。

深链接：`#case-06`、`#product-brand-film`、`#capabilities`、`#products`。产品计划由浏览器生成并下载，不上传数据。兼容研究集 GitHub Pages 子路径发布，完整资源按 publication-files.json 登记。


## 完整公开入口

首页新增十项当前真实画面、原帖、原作对照与独立试玩入口，保持原有五个视图与额外 ARC 实验。`research.html` 是无需 JavaScript 的完整理解页，逐项说明原理、输出、扩展与范围。`publication.css` 提供首页入口布局，`research.css` 提供全文阅读布局；导航支持直接进入单项以及浏览器前进 / 后退。

引导图沿用 `assets/library-overview/creative-products-capability-overview-v16.png` 和 SVG，和原文件完全对应。核心运行资源随站提供；原作者媒体需联网。音乐 WebM 编码需支持 WebCodecs 的 Chrome / Edge 和安全上下文，HTTPS 正式站满足这一前提；其他平台支持按实际浏览器功能检测。
