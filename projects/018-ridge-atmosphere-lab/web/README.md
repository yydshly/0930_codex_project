# Ridge Atmosphere Lab · Web 运行说明

独立实时风景原型，使用 Three.js / WebGL 实现程序化山脊、云雾、风草与骑行跟随镜头。原作视频只作为视觉参考，网页使用本项目的场景与资源。

## 本地预览

源码在 `../app/`，React 负责控制界面，Three.js 负责 WebGL 场景。项目入口脚本使用 `npm run dev` 启动开发预览，默认地址为 <http://127.0.0.1:8988/>。不要直接以 `file://` 打开。

当前会话由实现代理运行本地预览。后续从子项目根目录重启开发环境时使用：

```powershell
Set-Location F:\codex_project\0930_codex_project\projects\018-ridge-atmosphere-lab
npm --prefix app ci
npm run dev
```

构建执行 `npm run build`，先产生 `app/dist/client/`，再将浏览器静态文件复制到 `web/`，以接入仓库共享静态站。引入 Three.js 版本为 0.180.0，完整依赖由 `app/package-lock.json` 锁定。

运行环境应启用浏览器 GPU 硬件加速并支持 WebGL。当前没有实体手机实测结果，性能与画质须按实际设备核对。

## 控制内容

控制界面提供“山雨欲来”“晨间薄雾”和“云隙夕光”三种光色方向，分别调整“雾气浓度”“山间风力”和“云隙亮度”。“分层观察”可开关风动草地、山腰低云和远景空气透视；云层与距离雾独立开关，便于分别核对谷地遮挡和远景层次。默认跟随时直接拖动画面即可旋转，滚轮即可缩放；首个手势自动切到“自由观察”，保留当前视角，支持右键平移，相机仍随马前进。点击“沿山脊骑行”恢复自动跟随。暂停停止行进和动画，重置恢复默认设置并回到起点。

“画面拆解”打开来源截帧和层次说明；“沉浸观看”隐藏控制界面，`H` 切换沉浸，`Esc` 退出沉浸或关闭弹窗，空格暂停/继续。“保存画面”从 WebGL 画布生成 PNG，并打开“这一刻的山间”预览，只包含场景；点击“下载 PNG”使用浏览器标准下载，也可以右键保存预览图像。

桌面与窄屏都默认收起调节面板，点击“调整天气与镜头”打开，点击“收起调节”关闭。窄屏展开后的面板可以滚动；实体手机性能仍未实测。

返回跟随时位置与朝向平滑恢复；近距离环绕设有地面限制。暂停时仍可旋转、调整风力和天气，但复用未变化的阴影图。保存画面同步重绘再生成 PNG，已核对暂停、环绕和行进三种状态的实际导出。

## 源码入口

| 入口 | 职责 |
| --- | --- |
| `app/src/App.jsx` | 研究控制界面与状态 |
| `app/src/scene/renderer.js` | WebGL 生命周期、路径移动、跟随/环绕相机、截图 |
| `app/src/scene/terrain.js` | 程序化山体、路径和风草 |
| `app/src/scene/atmosphere.js` | 天空着色器、分层谷云、距离雾、天气光色 |
| `app/src/scene/rider.js` | 模型加载、马匹动画、程序化骑手与披风 |

谷雾采用 `volumetric-fog.js` 的 3D 噪声密度、28/16 次视线积分与真实深度裁剪；地表加入 CC0 扫描 PBR 材质，草灌使用生成的透明纹理三维交叉片。原游戏使用的算法尚未确认，详细取舍见 [画面分析](../notes/source-analysis.md)。

本轮启用了围绕骑手的局部动态 shadow map。马模型朝向已修正，鞍和骑手跟随真实形变脊背，身体、缰绳、尾毛与披肩有同步运动。保留原模型奔跑形变，尚非新制作的四拍步行骨骼动画。控制面板在桌面与窄屏都默认折叠。

草地与地表的颜色衔接、根部明暗和纹理变化已细化，树林按不规则林簇分布；草卡、细草与树木数量保持原预算。手掌与袖子独立响应马头/胸口变化，接触阴影取自真实蹄位；动态尾毛与缰绳复用缓冲区及解析法线，减轻重复计算。

## 共享站打包

在仓库根目录执行 `python scripts/build_site.py`，脚本会将已登记项目的 `web/index.html` 与许可范围内的静态资源打包到 `_site/projects/018-ridge-atmosphere-lab/`。页面和资源使用相对路径，以支持共享站子目录部署。公开地址验证前，`projects.json` 的 `demo` 保持为空。

马模型与声明通过本项目的精确白名单复制：`assets/horse.glb`、`assets/HORSE-LICENSE.txt`、`assets/THREE-LICENSE.txt`、`assets/SOURCE-NOTICE.txt`。它不为其他项目或同目录其他模型放行 `.glb` / `.txt` 文件。马素材的 CC BY-NC-SA 3.0 条件与 Three.js 的 MIT 许可分开保留。

已有客户端构建后，在仓库根目录运行 `python -m unittest discover -s tests -p test_ridge_site.py`，检查真实构建中的模型和许可文件完整性、JS/CSS 子路径、马模型路径与白名单范围。检查不执行 npm，也不生成替代场景；它不能证明 WebGL 或 GPU 渲染通过。

最终构建的公开资源与共享站逐项 SHA-256 核对，详情见 [构建与打包记录](../notes/build-validation.json)。
