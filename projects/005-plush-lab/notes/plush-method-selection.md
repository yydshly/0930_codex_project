# 舒适毛绒效果：方法、工具与制作路线

第一阶段记录：2026-10-02。目标仍是用户截图中的浅蓝卷绒星仔与黑色贝雷帽，先达到外观要求，再开展扩展。该阶段完成方法核查与选型，没有生成新的 Blender 工程、训练资产或效果图。随后已生成原生毛丝与 Cycles 样片，实际工程、图片和未达成项见[第二阶段制作记录](cycles-material-study.md)。

## 选型结论

先用成熟的毛发制作工具建立可编辑的高质量原始资产：**形体网格 → 导向曲线与密集毛丝 → 纤维散射材质 → 路径追踪与柔和光照**。首轮选 Blender / Cycles；Houdini 的 Guide Groom / Hair Generate 是成熟替代。先验收局部毛料，再应用到整只角色。

网页交付随后选择。以静态外观和环绕展示为主，可评估从已验收资产的多视图渲染拟合 3DGS，再用成熟的 SuperSplat viewer 对照。需要修剪、梳理、局部按压或换灯时，优先保留网格与导向曲线，评估实时纤维、毛发卡片或 shells/fins。网页引擎可继续沿用 Three.js。

这是根据输入条件和交付目标作出的工程选择，不是论文或产品对本角色画质的保证。代码可以用于自动化建模、参数管理、批量渲染与接入；外观判断应由资产、散射方法和实际样片支持。

## 当前差距的证据

[v4 原图与画布对照](../artifacts/reference-comparison.html)仍显示较粗的凸起线团，参考截图表现为更细密、柔和的毛层。[当前资产生成器](../src/gaussian-plush.js)以少量椭圆高斯拼接向外拱起的短曲线，并通过主体法线和手写遮蔽生成固定 RGB。提高高斯数量主要增加重叠，32,000 到 80,000 的截面缩细约 9%；没有生成高质量毛发资产所需的纤维层次和真实光照信息。

[当前渲染器](../src/gaussian-splat-renderer.js)能投影协方差、排序、过滤并混合这些高斯，但输入颜色缺少逐丝散射与毛层光影。它也没有多视图图像监督下的位置、形状、颜色和密度优化。继续增加点数或随机扰动，不能单独补齐这些环节。

项目此前已参考层壳毛发、FTL 保长动力学与湿毛聚集，范围见[原有研究记录](research.md)。问题不是完全没有论文依据，而是当前高斯分支尚未形成“高质量原始资产—拟合—展示”的制作流程。

## 方法比较：输入决定适用性

| 方法与原始来源 | 输入 → 输出 | 适合解决的问题 | 对当前任务的决定 |
| --- | --- | --- | --- |
| [Disney / Chiang 等，2016](https://www.disneyanimation.com/publications/a-practical-and-controllable-hair-and-fur-model-for-production-path-tracing/) | 已有毛丝几何、材质参数与光照 → 纤维散射响应，供路径追踪采样 | 毛发反射、透射、能量守恒与高阶内部反射；多次纤维间散射由路径追踪处理 | 优先作为毛料着色依据；不负责重建角色或生成毛丝。蓝色合成纤维仍需视觉标定 |
| [3DGS / Kerbl 等，2023](https://arxiv.org/html/2308.04079) | 静态场景多视图、标定相机，通常还有 SfM 点云 → 优化后的高斯位置、协方差、透明度与 SH 颜色 | 拟合观测外观并快速合成新视角 | 适合后续静态展示；先要有合格照片或渲染图。单张截图和手工撒点不等于论文训练流程 |
| [Shells / Fins / Lengyel 等，2001](https://hhoppe.com/proj/fur/) | 毛发采样成的体纹理与表面网格 → 半透明层壳及轮廓鳍片 | 在实时预算内表现毛层、轮廓与光照 | 作为可交互网页候选。当前项目只有部分层壳实现，仍需局部样片对照验证近景质量 |
| [GaussianHair / Luo 等，2024](https://arxiv.org/html/2402.10483v1) | 人发环绕视频、相机、方向图、遮罩、头皮模型与发丝先验 → 连接的高斯毛丝及散射表示 | 人类发型重建、编辑、重光照与模拟驱动动画 | 研究其毛丝连接与材质表示，暂不作为默认实现。论文使用约 80–100 帧，未验证单图合成毛绒角色 |
| [Disney Volumetric Sheen / Zeltner 等，2022](https://www.disneyanimation.com/publications/practical-volumetric-sheen/) | 薄纤维层散射 → 离线拟合的 LTC BRDF；渲染时由颜色、粗糙度及入射 / 出射方向求散射响应 | 布料、短绒表面的柔和光泽 | 黑帽可参考布料底材与短绒 sheen，配合少量边缘纤维。模型本身不生成轮廓毛丝 |

原版 3DGS 学习的是视角相关外观，不能直接据此宣称可以任意换灯、局部修剪或逐丝动画。它没有显式分离材质与光源；后续专门研究可以扩展这些能力，但需要另选方法和验证。GaussianHair 虽有相关能力，输入先验与验证对象也不直接匹配本角色。

## 实施顺序与验收条件

1. **毛料样片。** 同一小块曲面、固定相机、固定大面积柔光。制作细密短底绒、由导向曲线控制的弯曲毛束，以及少量更长飞毛。保存粗细、长度分布、结簇尺度、密度和材质参数；用少量候选样片比较，不先渲染整只角色。
2. **毛料验收。** 按参考图的观察尺度对照细丝、连续毛层、根部暗部、软阴影和轮廓。若仍像颗粒、绣线或尖刺，先修资产；若内部发黑、表层发硬，再检查散射和灯光。保留一个略侧角度，排除只在正面成立的效果。验收后才进入整只角色。
3. **完整原始资产。** 对齐双肩凹谷、圆臂圆腹、帽沿压缩、凸眼和主视角。帽子单独做哑黑布料、短纤维与褶面。输出可编辑原工程、匹配主视角图片和侧面检查图；实际形体比例由截图标定，未观察到的背面明确作为设计补全。
4. **网页方案对照。** 保持同一资产、灯光、视角和分辨率。静态展示候选为多视图渲染 → 高斯拟合 → SuperSplat viewer；交互候选为网格 / guides → 实时纤维、卡片或 shells/fins。实际测量细毛保留、旋转闪烁、缩放失真、内存与帧率，再决定接入方式。
5. **接入与记录。** 沿用现有网页入口和作品数据，以新增资产或分支接入。记录来源、版本、许可证、参数、制作步骤、实际截图、尚未实现的部分与下一步。功能测试保证接入和保存；视觉对照判断毛料是否达到目标。

仅凭这张视频截图，无法恢复唯一的背面、真实毛丝结构或灯光参数。正面相似度也会受视频压缩和底部控件渐变影响。匹配主视角是当前可检查目标；不能用不存在的原始多视图计算重建精度，也不能用测试通过代替视觉验收。

## 第三阶段：导向结构与长度的实测

继续新增 A/B/C/D 同条件导向对照，保存独立隐藏导向与逐毛映射；它们是生成时烘焙的记录，修改导向不会自动更新毛层。中段成束与末端放松使卷束可辨，但会明显改变实际弧长。E 与完整 v6 追加毛根固定的整根曲线缩放，将样条弧长归一到 v3 基线。十个原生工程、58 个输入文件的只读检查 **589 / 589 项通过**；E/v6 毛根逐位不变，实际保存曲线的最大相对弧长误差分别为 0.000184364% 与 0.0009804751%。它是几何修正，没有实现 FTL、分段约束或物理模拟。

实际渲染显示 E/v6 更紧凑，外观改善有限，仍未达到参考中厚实、断续的小卷绒。主要待验证因素是导向仍抽自随机一圈螺旋、纤维末端过细，以及缺少可直接编辑和重算的 groom 流程。散射论文已由 Cycles 运行，但它不负责这些几何形态；继续增加毛量或提高采样不能单独解决。

已从本机官方 `procedural_hair_node_assets.blend` 只读加载并核查 Curl Hair Curves、Clump Hair Curves、Interpolate Hair Curves、Restore Curve Segment Length、Set Hair Curve Profile 与表面附着相关节点。其卷曲半径、频率、沿长权重、导向索引、毛尖扩散、保长与截面接口实际可用。下一步用这些成熟节点制作可编辑的小样，先检查节点真的改变评估后的毛丝，再以同条件渲染检查短卷结构；节点存在和接口核查本身不算新毛料效果。

## 第四阶段：官方节点实际联动，外观仍待解决

## 第五阶段：按结构证据隔离制作问题

已对 E / v3 / GN1 / GN2 保存工程做只读毛层诊断，输入与源哈希保持。GN2 正面外绒毛冠中位高度 0.01135，底绒 0.01454；77.6% 外绒毛冠低于局部底绒毛冠 P95。51.21% 外绒有采样点深入解析椭球超过 0.001。原分组毛根切向 RMS 中位数 0.03182，大于导向最近邻距离中位数 0.01720，说明导向对应区域过宽，值得先单独验证。此处是几何采样和梯度距离近似，不能解释成实际逐像素遮挡率。[诊断数据与输入证据](../artifacts/cycles-study/gn-layer-geometry-diagnostic-1.json)。

GN3 已实际验证最近毛根映射：保留 GN2 的已保存导向形态、rest、半径、长度预算、节点参数、底绒、飞毛、灯光和材质，GPU 生成与渲染 17.94 秒。根到导向的空间距离 RMS 从 0.03261 降到 0.01746；深于椭球 0.001 的平均弧长比例由 13.37% 降到 7.35%。独立读取保存工程的 120 项检查通过，14 个输入哈希保持，85,000 个最近导向索引均正确。实际画面多了一些离散毛束，但仍细薄，75.04% 正面毛冠仍低于局部底绒 P95 包络。[GN3 实际图与工程](../artifacts/cycles-material-study.html#hair-nodes)。

GN4 已实际单独比较底绒几何：从保存 GN3 载入，90,000 根底绒围绕固定毛根缩至 0.35 倍，含横向展开；外绒与其评估结果、导向、半径、数量、材质和场景设置保持。GPU 渲染 11.68 秒，768 × 768 / 96 样本，独立检查 147 项通过，15 个输入哈希不变。外绒高于局部底绒 P95 的平均正面弧比例由 6.39% 升到 55.15%，但这是几何包络，不能当作像素可见率或画质提升幅度。实际图仅稍更显毛束，仍薄碎，没有形成参考的厚实卷绒；没有看到大片裸露底材。底绒覆盖只是部分原因，随后逐节点定位卷束的表面下陷。[GN4 实际图与记录](cycles-material-study.md#gn4只缩短底绒露出不等于厚实卷绒)。

## 第六阶段：查清成熟节点的参考与组合

已记录的下一轮两组计划：将导向补到 10,628 个并真实更新 nearest 映射，两组共用新根、rest、ID 和 joined 索引；一组保留旧回卷宽度，另一组仅把两个切向分量缩至 0.5、继承旧法线高度函数。固定 85,000 根子毛、GN11 沿长控制及场景，与既有 GN11 一同比较。需先验每束根跨度和人数实际下降，再看真实卷团是否变细；导向数、长度或冠高不能替代舒适感。该计划尚未执行，没有新的工程或图片成果。

## 第十五阶段：空间细化出现可见收益，转到完整形象验证

GN14 已实际完成上述两组工程与 GPU 渲染，耗时 8.06 / 7.94 秒。真实最近根映射将每束子毛中位数从 32 降到 7，根部切向跨度中位数从 0.04606 降到 0.01684 场景单位；两组共用 10,628 个根、rest、ID 和 joined 映射，半宽组只缩小两个切向分量，继承法向高度。85,000 根外绒、90,000 根底绒、隐藏飞毛、官方沿长控制及场景保持。[同条件三图](../artifacts/cycles-material-study.html#bundle-scale-study)显示宽扇片明显细化；半宽相对全宽只稍紧细，额外视觉收益有限。顺向细钩、横纹与压实感尚有，参考的自然松厚卷绒仍未验收。

该结果支持把更细的空间束用于一次完整星仔，而不再把所有进展停留在球形样片。完整角色需要星形表面的真实法线，继承眼窝、帽檐的长度预算；不能把球形解析法线直接套上。保留保存的 v6 场景和全部历史，新增完整工程，与参考截图和 v6 直接看图比较。完整配方适配包含毛料迁移与角色尺度调整，不能当作 GN14 两张样片的单变量试验，也不保证外观已达标。

本轮再次核对成熟 [SideFX 泰迪熊流程](https://www.sidefx.com/docs/houdini/fur/teddybear.html) 与 [Hair Clump](https://www.sidefx.com/docs/houdini/nodes/sop/hairclump.html)：导向、真实生成的毛丝、空间束尺度、长度差异、实体宽度与多层组织是不同制作控制。空间细化只能解决其中一部分。实际运行仍为 Blender 官方节点和 Cycles；本机没有运行 Houdini、Accurate Bundling、Fractal 或接触求解器，不把自写造型公式冒充已有论文复现。

### 完整形象结果：细化解决宽扇，尚未解决松厚卷团

本阶段已新增两套完整星仔工程与真实 1536×1536 / 256 样本 Cycles 图：细束版耗时 47.075 秒，撑开版耗时 60.718 秒。[参考、旧 v6 与撑开版直接对照](../artifacts/cycles-material-study.html#character-fine-bundle-study)成为当前入口，两套候选和全部旧作品均保留。完整角色使用真实星形表面法线与眼窝、帽檐压缩，没有沿用球形解析法线；320,000 根外绒分到 40,000 条导向，缩短底绒并隐藏飞毛。

实际高清图中，细束版减少了长丝棉絮，却偏贴体短绒。撑开版将外绒与导向法向分量乘 1.65、导向切向分量乘 1.25、Clump 峰值降到 0.65，并增加 260 W / 5 m 下前柔光。小回卷与开放圈更可见、边缘稍厚、底暗减轻，仍偏均匀细密，缺参考图的松厚不规则卷团。这是复合角色配方，不能从两图拆出各项的独立贡献，也不能宣称参考匹配达标。

下一项问题应围绕卷团层级与长度错开组织完整 groom，再用完整角色检验，避免继续只积累球形参数样片。当前实际交付为可编辑 Blender 工程与静态渲染；实时网页角色尚未替换，也没有训练出新的 Gaussian Splatting 资产。先验外观，再选网页部署方式。

## 第十六阶段：直接重做完整厚卷绒形象

此前多轮建立了原生毛丝、可编辑导向和实际渲染管线，也完成大量球形参数样片；这些工程成果没有替用户完成参考外观。本轮从完整浅蓝星仔出发重做 groom，交付真实高清成片，让判断落在完整角色上。[第一屏参考与 V15 成片](../artifacts/cycles-material-study.html#character-v15-delivery)并排，[制作过程与工程](../artifacts/cycles-material-study.html#character-v15-making)默认折叠，历史作品、首稿和所有旧记录保留。

6,400 主卷团首稿过于颗粒，最终细化为 10,800 个主卷团、每团 56 根外绒，共 604,800 根，每根 32 个控制点；另外制作 185,000 根短底绒和 28,000 根散毛。主卷团混合短、中、长高度及不同卷径、方向，束内加入细卷，中段松聚、末端散开。短底绒填补根部，散毛形成柔和边缘，帽沿和眼窝附近适当压短毛形。帽子与亮眼睛保留真实几何。最终实际 Cycles OptiX 渲染为 1536×1536 / 256 样本，耗时 49.40 秒；工程、冻结源、毛形报告、预览和实际渲染凭证独立保存。

## 第十七阶段：找到原作者场景，直接建立可见基准

V15 的完整图仍被用户指出质感不够。其高拱毛形和较强聚束造成球团、羊羔绒颗粒感，增加毛量没有直接解决参考中的细密连续表面。V16 因此改为更低的细卷绒：26,000 组、每组 32 根，共 832,000 根主毛，每根 24 控制点；大部分高度为 0.025–0.034 场景单位，另混合更短与更长毛形，卷半径为 0.004–0.0085，聚拢系数降低到 0.20。底绒为 240,000 根、长度配方 0.024，短散毛为 18,000 根、长度配方 0.038；毛流局部连续下垂。毛根采样原来把参数余弦截在 ±0.998，漏掉正面极点附近一小块区域，改为 ±0.999999 补齐覆盖；同时缩小眼周压缩、减弱主光并适度补环境光，使用较低反差。工程与实际预览已保存，**只有预览实验，没有高清成片或外观认可**；继续使用原生毛丝、Cycles / Chiang，没有新的 3DGS 训练或 Houdini 求解。
