# 迭代实现记录 · 2026-10-01

以下按迭代顺序保留历史事实，当前功能与验证进度见末尾「局部创作、毛流随动与简化接触」。

## 历史：第二版

第一版使用三段 LineSegments 与预计算颜色，表现偏硬，毛宽受 WebGL 线条实现限制。第二版改成 InstancedBufferGeometry 渐细毛束，ShaderMaterial 实时纤维光照；增加短底绒、长外层毛、面积加权采样与空间相关毛流。

毛束在顶点着色器中沿归一化方向作六段积分，毛根固定、每段弧长保持。毛束根据视角展开，片元着色器结合圆柱纤维漫反射、Kajiya–Kay 风格高光、根部遮蔽与端部透光。它不是完整 Marschner 或离线多重散射模型。参考 [PBRT 的毛发模型综述](https://www.pbr-book.org/4ed/Reflection_Models/Further_Reading) 与 [Three.js 实例几何文档](https://threejs.org/docs/pages/InstancedBufferGeometry.html)。

使用 32 个导向点的切向弹簧阻尼响应处理风场与拨毛，每根毛束插值最近的两个导向点。固定时间步 1/120 秒，长毛更软，强力限制偏转，抖动与弹跳惯性作为附加弯曲。重力由世界空间转换为局部空间；未求解逐根碰撞。弹跳重力为场景单位 8，地面回弹系数 .24，弱回弹停止；身体压缩近似体积守恒。

性能方面，共享 ribbon 拓扑、实例属性和 GPU 曲线计算。100k 根毛发属性约 5.2 MB；大部分参数只更新 uniform，密度与角色切换才重建。暂停时停止无变化的绘制。物理和渲染代码分开。

已通过七项 Node 物理测试，浏览器验证全部角色、材质、灯光和新交互，无控制台及着色器错误。手机检查发现 align-items:start 把绝对定位舞台挤成窄条，修复为移动端 stretch；亚像素细毛的覆盖公式在手机上过度衰减，限制抗锯齿过渡宽度后恢复可见绒毛。还修正了领结与各角色的近似着地高度。

截图覆盖 390 × 844 手机和 1280 × 900 宽屏。参数均为相对或场景单位；不宣称真实材料测量、逐根动力学、精确毛发碰撞或完整多重散射。真实手机 GPU 和长时间帧率仍需后续验证。

## 历史：闪烁修正

用户指出第二版细毛出现闪烁感，视觉质量下降。原实现将 alpha-to-coverage 与毛束深度写入结合，大量亚像素三角形在运动中变化采样覆盖，造成不连续亮点；高频毛色与高光增加颗粒感。改为连续 alpha 混合、关闭毛束深度写入与 alpha-to-coverage。毛束至少覆盖约 1.4 个渲染像素的宽度，并以原宽度/扩展宽度降低透明度，保留细毛的平均覆盖量。加入视线与毛束切线近平行时的 ribbon 方向退化保护；降低随机颜色差异和高光强度，默认毛长从 .15 调到 .11。

这是空间抗锯齿与透明混合改进，未实现 TAA 或逐根透明排序。浏览器复核旋转、风场和特写，未观察到着色器或控制台错误。仍不能保证所有 GPU 与距离下完全没有时域混叠。

## 历史：回到用户认可的短绒基准

用户提供第一版黄色角色截图，认为其效果更舒服。保留该图作为视觉基准，恢复默认 .09 长度、90k 密度与均匀短绒分布。云朵绒/短天鹅绒用实例线段，长毛/卷羊毛继续 ribbon，共享物理导向点。整体方向光替代逐纤维高光与根尖明暗层级，避免明显毛刺边圈。恢复原相机距离，让角色更饱满。保留改进后的领结与新交互。短绒线宽固定，其粗细控制禁用，避免滑块产生虚假的可调反馈。

浏览器验证从长毛切回短绒、风场与拨毛，无控制台或着色器错误。此轮以用户视觉偏好为准，不把更复杂的渲染算法视为更好效果。


## 历史：产品化与按钮可用性复核

发现眼镜避让在其他角色上静默无效、暂停后拨毛不响应、重置遗留动作、暂停重置视角只缓动一帧、手机演示在屏幕外结束。已统一动作清理与反馈，互斥拨毛/按压/转台，限制眼镜避让适用角色，演示回正面并展示压力圆环。

面板改为装扮/陪伴/收藏，加入起名、三份配方、本地收藏、撤销、UTF-8 配方链接与导入、透明 PNG 和名字卡片、像素精细度。收藏写入前读取最新集合并监听跨页面 storage 事件。配方校验忽略未知字段、限制参数与 token 长度，不将导入值直接传给渲染器。

验证 18 项测试、双页面同步、中文链接、损坏代码反馈、PNG 像素预览与手机无横向溢出。用户已打开的另一预览页仍显示第一版，已刷新为新版。自动下载无可靠落盘反馈，产品仅在 PNG blob 生成并可预览时报告生成成功。

## 八种角色与材质扩展

针对用户希望补全更多效果的反馈，角色从五个扩展到八个，增加兔兔、团熊与星仔；材质从四种扩展到八种，增加顺滑长毛、泰迪卷绒、蒲公英绒与雨后湿绒。默认继续保持用户认可的奶油与密实短绒，不改变短绒视觉基准。角色与材质可以组合，收藏面板提供六份灵感配方。

增加梳顺毛流、吹干蓬松、雨后贴伏三项操作，十一项高级参数中新增梳理度 `groom` 与湿润度 `wetness`。两项参数均为 0–1 的相对系数，随配方收藏、导入与分享。角色编号范围扩展为 0–7，新增角色有对应默认颜色；旧版 version 1 配方缺失两项字段时默认 0，保持已有收藏与代码兼容。

湿绒通过贴伏方向、毛束宽度与颜色变化近似湿润外观，没有液体模拟或纤维真实结团。纤维仍采用保长积分，不随湿润度缩短。当前梳理度表达整体毛流走向，局部笔刷轨迹尚未持久化；后续可保存导向场，再研究真实束间聚集、自阴影和压力传递。

团熊耳型修复增加圆耳轮廓检查后，共 29 项测试全部通过：9 项物理与形变、12 项配方、8 项形状检查，覆盖保长弯曲、轮廓和配方边界。新增配方检查包括角色 5–7 的分享往返、旧版缺失新参数的默认值、非有限值处理与范围钳制。湿绒 GPU 外观通过浏览器视觉检查，不宣称自动测试验证了湿润物理计算。本轮截图为 `assets/effects-expanded.jpg` 与 `assets/effects-mobile.jpg`。

浏览器检查新增三种造型与四种材质、梳顺/湿润/吹干的外观与参数联动、星形湿绒配方链接恢复和旧收藏兼容。390 × 844 下八个角色按钮完整显示，没有横向溢出。复核发现风力为零时按钮会高亮却无风，已改为再次启用时恢复 0.50 并同步控件；浏览器确认修复。暂停时湿绒参数仍能重绘，未观察到控制台或着色器错误。

## 新增论文实验与持久毛流

用户要求参考论文新增效果，并明确不要替换已有效果。因此增加第四个「论文实验」面板，保留八种角色、八种材质与原有渲染。`experiment.mode` 有 `off`、`shell`、`bundles`、`ftl` 四个值，其中 `off` 是首次打开和旧配方的默认值，其余三项实验一次选择一种。「应用本实验示例」只调整当前材质参数，帮助观察差异，不移除或替换八种预设；可以在装扮面板重新选择材质。实验面板提供来源、边界与吹风回弹演示。

### 层壳部分

读 [Lengyel 等作者项目页](https://www.hhoppe.com/proj/fur/) 与 [Real-Time Fur over Arbitrary Surfaces（2001）论文](https://www.hhoppe.com/fur.pdf)，新增独立 `src/shell-fur.js`。采用 32 层实例化同心曲面，固定种子的周期纤维截面纹理提供覆盖、长度和色泽变化；采样绑定物体局部坐标，导数覆盖预滤不引入随帧改变的噪声。根部深度遮蔽表现绒层厚度，沿表面法线偏移并以切向剪切响应风、整体梳理和触碰；共享 `deformation.js` 的按压场，让毛根随身体凹陷移动。

本轮仅实现层壳采样与剪切，没有论文的 lapped textures 参数化、轮廓 fins 或完整光照模型。层壳的有限采样在较长毛和侧面轮廓处可能出现间隙，因此界面标明适合短绒。密度调节纹理采样而非显式毛根数量；截面粗细与整体哑光固定。

### 动态 Follow-The-Leader 部分

读 [Müller 等，Fast Simulation of Inextensible Hair and Fur（2012）](https://matthias-research.github.io/pages/publications/FTLHairFur.pdf)，新增 32 根六段导向链。每步预测位置后，从固定毛根向毛尖逐段投影到定长球面，按论文式（9）使用后继投影修正更新速度。引入静止形态吸引与阻尼，作为网页玩偶运动的简化。渲染纤维通过稀疏导向链插值跟随变化，并沿归一化方向作保长积分。

这实现了动态 FTL 的核心投影与速度修正，不是论文的完整逐毛 CUDA 系统；没有毛发密度网格、毛发间排斥/摩擦、逐根碰撞或真实弹性杆材料求解。导向链保长和渲染曲线保长分别有算法检查，不把稀疏插值等同于每根毛独立求解。

### 毛束聚集部分

参考 [Fei 等，A Multi-Scale Model for Simulating Liquid-Hair Interactions（2017）研究页及源码](https://www.cs.columbia.edu/cg/liquidhair/) 中的湿毛聚集现象，以及 [Houdini 泰迪熊导向毛和分束制作教程](https://www.sidefx.com/docs/houdini/fur/teddybear.html)。新增固定毛束中心，将附近毛尖方向聚拢，提供聚集强度与根部遮蔽系数。与湿润度和较长材质搭配后，可观察分束与绒层明暗变化。

这是几何聚拢和深度遮蔽近似。没有复现 Fei 论文的多尺度液体-毛发耦合，没有求解液桥、液体流动或表面张力，也没有新增完整纤维散射模型；遮蔽系数不代表真实光传输或自阴影。实际画面最初出现规则锯齿分束，改为独立整数 hash 生成错落中心、按局部邻域实际距离分配，仅弯曲毛尖并减弱短绒聚集。新中心不消耗原有随机序列；离线生成 2,000 根毛发时，毛根、法线、种子和导向分配与原网格中心版本逐值一致，原有渲染基线保留。

### 局部毛流和配方兼容

毛束聚集与保长动力学模式支持「记录梳理轨迹」：开启后按住角色拖动，写入 32 个导向点的方向向量，再插值到附近毛束。松手、关闭记录或恢复平静后保留毛流，恢复平静只清瞬时运动；专门「清除局部毛流」或全重置清除记录。切换角色也清除局部场，因为不同身体表面的方向不宜直接错投射。此场是持久的稀疏方向场，不是逐根笔刷轨迹，暂未提供方向场可视化编辑。

收藏与分享保存 `experiment` 设置和 `experiment.field`。旧版 version 1 配方缺失这些字段时采用 `off` 与空场，保持原有模式；新配方可以往返导入并恢复实验和局部毛流。导入做有限值、范围与场大小约束，避免直接接受任意数组作为 GPU 参数。

本轮 55 项测试通过：9 项原有物理与形变、8 项形状、18 项配方、9 项毛流场、3 项层壳采样、8 项导向链动力学。检查覆盖固定根与保长、约束和稳定、持久场、实验序列化与旧版兼容、确定性截面纹理与根尖收窄。新增毛流回归采样八种角色前侧共 36,867 笔，包含奶油肚子与兔熊耳尖；32 个稀疏导向点的支撑半径采用 .72，避免有些区域拖动无记录。普通拨毛与持久记录改为互斥显示，按压演示会结束记录模式但保留已有毛流。

实际 GPU 检查发现层壳导数预滤过早退到均值，32 层透明叠加使身体变成平滑模糊外壳。降低纹理频率、延后均值滤波并缩窄截面抗锯齿范围后，恢复可辨认的短绒截面，仍不使用随帧噪声。浏览器验证三种实验、风吹与停风、拖动与持久毛流、模式互斥、收藏刷新恢复、新实验链接导入以及旧收藏默认原有渲染。390 × 844 下四个标签和八个角色可用，没有横向溢出，演示自动返回舞台；未观察到控制台或着色器错误。截图为 `assets/paper-experiments.jpg`、`assets/paper-mobile.jpg` 与 `assets/paper-shell-after.jpg`。这些浏览器检查不等同于全平台长期帧率或零时间混叠保证。

## 局部创作、毛流随动与简化接触

用户同意继续增加局部剪毛、染色、卷曲笔刷。增加独立创作面板后，页面有装扮、陪伴、收藏、创作、论文实验五个并列面板，八种角色、八种材质和前轮三项论文实验继续保留。新能力按需开启，不改变旧配方和默认密实短绒。

### 可重放局部场

新增纯 CPU `src/local-coat-field.js`，采用与身体 SphereGeometry 一致的 UV：程序曲面 `theta = π(1−v)`、`phi = 2πu−π/2`。128 × 64 栅格的 RGBA 场存长度比例、局部卷曲变化和染色覆盖，颜色纹理存线性预乘 RGB。根据静止曲面根部和笔刷中心的三维距离计算平滑衰减，不使用单纯 UV 距离，以避免接缝断开和相邻 UV 导致的背面串色。

修剪指定 8%–100% 的目标保留毛长，只允许缩短；较轻后续笔触不会让已剪毛重新长回。局部卷曲变化可正可负，叠加整体卷度后限制在有效范围。染色只修改被刷过的纤维，覆盖和颜色以线性预乘方式合成，避免未染像素在双线性采样时混入白色。停止涂画后可拖动旋转到另一面。

配方最多记录 64 条采样笔触，确定性重放生成纹理，避免保存全部像素。一次按住拖动会产生一组撤销记录，其中可以包含多个笔刷采样；撤销/重做只回放局部场，不改变整体材质。达到上限拒绝新增并给出反馈，不默默删除旧记录。清除局部创作也可撤销；恢复平静只停运动，保留笔触与毛流。

### 毛流与运动联动

可选「毛流随动」将整体梳理与 32 点持久方向场变成导向链的静止形态/回弹目标，使风和触碰后的运动恢复到梳过的形态。局部修剪、卷曲与导向形态采用稀疏采样近似，渲染纤维仍插值跟随导向；没有新增逐根真实弹性杆求解。核心动力学继续参考已读的 [Müller 等动态 FTL 论文](https://matthias-research.github.io/pages/publications/FTLHairFur.pdf)，静止形态吸引、阻尼和局部编辑联动属于本项目实现。

### 简化身体与配饰接触

新增可选「身体与配饰接触」，使用毛根附近局部表面与椭球/胶囊代理体，给导向链增加受限位置投影并保持段长，渲染阶段采用接触近似降低明显穿插。配饰代理覆盖帽子、眼镜、耳机等当前角色部件；示例会开启接触和毛流随动、应用长毛并吹风，便于观察。

这是稀疏导向和粗形体接触，没有精确网格或逐根碰撞，也没有毛发之间的碰撞、真实填充物传力或完整软体求解。身体采用局部表面近似，复杂凹面和受限空间中的多约束冲突不能保证全部消除穿插。当前实现范围不能被称为论文的完整物理系统。

### 配方兼容与本轮边界

`experiment` 新增 `edits`、`collision` 和 `groomDynamics`，默认分别为 `[]`、`false`、`false`。保持 version 1 与原收藏键，旧配方恢复原有渲染、空编辑和关闭开关；新收藏/分享/导入保存笔触、毛流和可选状态。分享代码上限提高到 16,384 字符，收藏 JSON 上限提高到 256,000 字符，仍最多 12 份作品。字段校验限制笔触类型、有限中心坐标、半径、数值和 64 条数量，并复制输入而不修改来源对象。

切换角色会清空当前笔触、局部毛流和撤销历史，避免异形表面的记录错投射；已收藏作品不受影响。切换实验模式保留记录。层壳 `shell` 本轮禁用局部编辑、毛流随动和简化接触，继续原有层壳剪切响应，切回纤维模式可继续编辑。

本轮 79 项 CPU 测试通过：原物理与变形 9、梳理场 9、局部场 8、配方 21、造型 8、层壳 3、接触 11、保长链 10。局部场测试涵盖 UV 对应、身份默认、局部作用范围、仅缩短修剪、线性预乘颜色合成、接缝/极点连续、确定性重放和上限拒绝；配方检查覆盖新字段、旧默认和 64 条笔触、32 点毛流、Unicode 名字的最大代码往返。接触检查覆盖整段与薄配饰、滑动摩擦、强载荷、不可行约束上报；动力学检查覆盖梳理静止形态、回弹、固定毛根和段长。

## 连续创作与组合步骤

此前容量按采样点累计，一次拖动可包含多点，因此把上限从 64 扩到 256、512 仍会很快满。本轮将 512 改为近期重放缓存阈值：实际变化达到阈值后，把当前 128 × 64 表面场编码为无损 Float32 检查点，清空近期缓存并继续写入。检查点按递增纹理索引保存六个通道：毛长比例、卷度变化、染色覆盖、线性预乘 RGB；不量化，不删除此前效果，不改变纹理数组引用或原有毛发光照。检查点及近期记录共同控制 GPU 的局部编辑开关，确保合并后效果不会消失。

`experiment.coat` 新增 `lc1:` 检查点字符串，缺省为空；`experiment.edits` 继续保存至多 512 条近期记录。版本仍为 1，旧 64/256/512 条作品从原表面重放后可继续编辑。导入先完整验证字节长度、纹理索引、有限值及通道范围，非法检查点不能部分修改场。分享代码上限 524288 字符，收藏 JSON 6000000 字符，草稿 1048576 字符；实际浏览器存储另受配额约束，失败仍报告给用户。

新增显式组合步骤：开始组合后可连续切换修剪、染色、卷曲、恢复、梳理，多次拖动及清除共同提交为一个历史事务。停止涂画可旋转后续画；完成组合或离开创作面板时提交。默认仍是一拖一步，最近 24 步可撤销；历史快照包含检查点、近期笔触与毛流，能跨合并边界恢复。空组合不清重做，修改后清除回到起点不产生无效撤销按钮。提示区分本笔加入组合与单笔撤销。整体材质和运动开关独立于笔刷历史，草稿恢复当前效果，不保存撤销历史。

本轮共 143 项 CPU 检查通过。连续 1156 条混合工具跨两次检查点，与不合并参考场的每个 Float32 值相同；覆盖稀疏和密集编码、恶意输入、旧作品续画、跨边界及组合撤销、最大分享/收藏/草稿格式往返。12 件密集作品用内存存储验证格式，不代表宿主浏览器配额能存满。

浏览器实测旧 512 条作品继续修剪后生成 7530 字符检查点与 11 条近期笔触，跨边界撤销恢复原 512 条、重做精确恢复；三次修剪/染色/梳理一起撤销和重做，空组保留重做，净零组合无无效撤销。验证检查点收藏、同链接草稿刷新、导入、清除撤销、层壳返回，以及纯检查点无近期笔触仍显示染色。用户 256 条笔触和 26 个毛流区域保留，390 × 844 新控件无横向溢出，验证页面未出现控制台警告或错误。原默认短绒与渲染分支保留，不新增真实设备性能声明。截图见 `../assets/continuous-editing.png`。

## 论文理解与独立高斯实验 · 2026-10-02

本节新增研究理解与实现边界，前文的迭代记录继续保留。完整解释、计算公式、工具关系、验收办法和后续路线见 [Gaussian Splatting 与毛绒研究理解](gaussian-splatting.md)。项目内置记录同步追加可搜索条目，个人补充、旧配方、收藏和笔记不做替换。

### 引擎与研究方法是不同层次

Three.js 提供场景、相机、几何与 WebGL 接口；毛绒表示、着色、毛流和运动算法仍需项目实现。原实验室 `index.html` 已参考三个研究方向：Lengyel 等的层壳部分、Müller 等动态 FTL 的导向链近似、Fei 等湿毛聚集现象。它们分别属于“部分绘制方法”“核心算法的稀疏实现”“物理现象的外观启发”，不能合称三篇论文完整复现。

这个范围有页面差异：`world.html` 使用默认 `FurCoat` 构造，小世界没有自动开启 Shell、湿毛束或 FTL 实验；`studio.html` 嵌入小世界，并增加笔记、提醒与 Agent 事件展示。本轮不修改这一差异，也不把三个页面的既有能力全部归为论文实验。

### 新增分支研究什么

独立 `splat.html` 分支研究程序化 3D 高斯表示和前向绘制：按种子构造均值、轴向尺度、四元数、透明度和常数颜色，用三维协方差到二维椭圆的投影以及有序 alpha 混合表现毛簇，提供配色、蓬松度、旋转观察与 PLY 交换入口。它与原纤维、局部笔刷、场景和陪伴功能并列，不替换旧创作。

[Kerbl 等 2023 年原论文](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/)研究的是用带相机信息的多视角图像，优化可实时观察的新视角场景表示。本轮资产直接由程序构造，没有照片拟合、反向传播、增密剪枝训练、原 CUDA 栅格器或高阶球谐方向颜色。因此当前准确名称是“程序化 3D 高斯毛绒实验”，不能声称完成多视角重建、完整复现原论文，或仅凭参考截图宣称达到视频画质。

实现与浏览器验收由本轮最终记录另行确认；本节记录研究范围，不预填未执行的测试数量、帧率或画质指标。后续优先检查协方差、深度合成、旋转轮廓、PLY 往返与真实设备帧耗时，再考虑外部训练资产、骨骼绑定以及与原纤维的混合使用。
