016 · Chippytea Lab · 功能、角色与音乐的共同编排#

Chippytea 是一个 Mac 清理应用，也将功能成果延伸成手绘角色、收集动画、短音效和可参与的歌曲场景。本项目研究它如何把功能、图像、动作与音乐组织为同一段体验，并扩展为三个原创互动小世界。

我们的理解：功能提供含义，图像建立角色与世界，动画表达过程和回应，音乐组织节奏与情绪；用户参与后，结果在世界里留下变化。 源库提供可研究的完整产品实现，这套表达仍需要原创角色、旋律、动作与业务含义的共同设计。

源库的能力#

源库有两层：原生应用负责真实文件工作，官网将产品及成果编排成可观看、可点按的声画体验。它不是通用动画或音乐 SDK。

层次能力与边界
发现空间占用在选定位置识别开发依赖、构建产物、已知工具缓存、应用缓存、日志、下载和较大/较旧的个人文件，展示估算与原因
审阅与操作按类别复核归属、活动和内容，用户选择保留、移入 Trash 或永久清理合适的开发产物；个人文件仍需用户判断
成果记账符合条件的永久操作完成后保守核算空间，每 100 MB 计一个 chip，余量累计；估算与 Trash 不计奖，成功操作也可能核算为零
原生系统整合SwiftUI 界面、Rust 有界扫描和 SQLite 索引、Finder/Trash、位置权限、本地历史与账本；无需账号
网页表达React、SVG、Canvas、CSS 与 Web Audio；纸张墨线、统一手绘组件、角色关系、收集动画与短音效、歌词和段落同步、用户投放互动

本项目清理组件采用上游虚构数据与预设结果，没有在访客电脑扫描或删除文件。Mac 应用与 Rust 引擎未在本轮实机运行，原生能力不会随静态网页变成 Windows/Linux 清理工具。事实依据为 源码快照 f245695，官网观察记录于 2026-10-02。

原理与对我们的价值#

编排的因果链是 功能事件 → 确认结果 → 声画编排 → 用户参与 → 世界积累。真实结果决定何时展示完成；角色和世界解释这次结果；动作、字幕与音乐围绕共同含义发生。比如将来接入知识收藏时，应先确认收藏成功，再让种子落地、生长并配合乐句回应，最后留下可见记录。这个业务映射尚未接入当前三个小世界。

上游用稳定种子噪声和曲线形成墨线，循环三个种子产生低帧率重绘感。歌曲以实际播放时间同步歌词与段落，Canvas 根据段落编排角色和点击反馈，音频能量补充节奏细节。本地花园与影子用 HTMLAudio.currentTime 统一四幕，AnalyserNode 的低频、高频和能量影响细节；即兴动作与收藏有独立时钟，暂停也能完成反馈。频谱响应不等于自动理解乐句或逐音符编舞。

价值对我们意味着什么
让结果可感知用过程、角色回应和留下的变化表达一次完成，适合抽象的收藏、整理与创作结果
建立原创辨识度角色性格、关系和世界规则形成属于产品的视觉与声音语言
沉淀可复用编排共享绘图、媒体主钟、段落脚本、交互阶段与失败回退，减少重复实现
让重复使用有积累用户每次行动可以改变世界，形成可以回看和继续参与的痕迹；真实留存效果仍需测试

精彩程度取决于创意、音乐、动作与节奏的匹配。完成率、传播、付费与商业收益尚未测量。

  5. 扩展产品：知识收藏/研究归档、任务习惯/专注、文件素材整理、创作成果/品牌展示、互动课程/新手引导、音乐叙事编辑器。当前都是待接业务方向，不是已经交付的六款产品。

计奖不是按估算大小直接相除#

accounting.rs 先要求操作为永久清理、目标内容完整移除、私有分配可证明、审阅项目存在分配字节，并且容量采样显示可用空间增加。空间计奖受到三个上界约束：可证明的私有分配、审阅分配大小、扣除测得背景增长后的容量增量。条件不足时计奖为零；APFS 共享、快照和其他磁盘活动也会影响游戏计奖，源码没有把它称为精确磁盘节省结论。

累计本次有证据支持的空间与历史余量后，按十进制 100 MB = 100,000,000 字节 增加一个 chip，余量继续保留。操作、核算分配、收入和余额在 SQLite 事务中更新，避免同一个观察窗口被重复结算。

移入 Trash 不建立已恢复空间，也不计奖。 应用缓存、日志、Python 字节码、Xcode DerivedData、下载与个人文件属于上游说明的审阅/Trash 范围；符合条件且重新验证通过的开发缓存、依赖与构建文件才可能永久操作并计奖。不能为了让动画好看，把所有文件估算大小都转换为奖励。

依据：accounting.rs、cleanup.rs、根 README 计奖说明。这是源码核对结果，不是对本机空间核算的测量。

浏览器收到新增回执成功响应后，才让研究卡片在约 1.3 秒内飞入收集册，编号落印、数字增长，并在卡片归位时播放上游 chime.ts 合成的约 0.67 秒短声音。这些反馈对应同一次真实保存；重复核验与回执更新不制造新增奖励。声音可关闭或试听，试听不写入回执；减少动态偏好省略飞行与数字渐变，保留文字结果。最终交互实测与截图仍由 设计验收记录 记录，不能由源码实现直接宣布通过。

静态页面使用构建时的 web/research-state.json 只读快照，明确标记未连接本机服务并禁用入册。快照生成脚本仅读取，不创建回执。这样同一页面既能公开展示实际资料，又不会在没有服务器保存的情况下假装完成。

歌曲的时间同步与跨域处理#

上游歌曲 Save Your Mac with chippytea 由 <audio> 播放，歌词每个词有起止时间；sections.ts 将歌词连续段落归为 intro、chorus、verse、pre-chorus、bridge、last chorus 等区间。Karaoke 按 audio.currentTime 查找当前词和段落，karaokeScene 根据区间编排游鱼、薯条、拍手、强调与点击投放。原官网的 AnalyserNode 检查低频强度变化形成节拍刺激，它没有自动完成整首歌的分镜。

本地 SONG_SRC 指向原官网歌曲，不下载音乐归档。跨域媒体通过 createMediaElementSource 时可能受 CORS 限制而得到静音，因此本地让远程原曲走 HTML 音频原生播放，跳过音频分析节点，并使用现有 FALLBACK_BEAT（0.5 秒）驱动角色节奏。歌词、段落和拖动后的同步继续依据音频真实播放时间；关闭时通过 HTMLAudio 的 volume 淡出。这份适配让远程歌曲走原生播放通道，实际可听与同步仍需浏览器验证；它不是本地对原曲做实时频谱检测。

词级时间生成方案来自上游：歌词表加 Whisper word timestamps 后执行对齐脚本，生成 lyrics.ts。新的歌曲仍需人工校正时间和表演；更换音轨不能沿用原曲时间数据。依据：site/README、Karaoke.tsx、sections.ts。

参考什么#

Chippytea 的启发在于角色、音乐和动作共同构成一个有性格的小世界。我们保留温暖的奶油纸底、墨线与水粉笔触、轻微不规则的形体，以及角色可以失误、回应和合作的俏皮气质。原作猫、鱼和食品对应原作品牌；三个新世界发展自己的角色关系与场景规则。

每场由两个性格不同的角色和一条荒诞规则出发：高低音改变重力、拉线补月亮形成乐句、光影大小表现胆量。花园与影子已接入真实音乐播放时间及频谱，动作仍有四幕编排，信号只作小幅回应，尚未逐音符标注乐句或实现完全由音高控制的重力。修补铺的音乐规则仍是创作目标。

功能可以成为触发器：收藏使花园积累星种，整理给月亮留下补丁，探索角度留下一个喜欢的姿势。场景的主要内容是角色之间的小戏与用户的参与，用户即使只想看、碰一碰或重演，也有完整的体验理由。

真实场景：工作区研究入册#

例如今天看完 Chippytea，我们已留下来源、能力原理说明、截图、可操作网页和目录登记。下一步点击“检查并入册”，系统检查这份工作区成果，再生成一张可以打开原作、研究说明和本地展示的收藏卡。

建议交互闭环：

  1. 选择一个实际登记的项目，先显示缺少什么和已有成果链接。
  2. 检查来源、清单、研究说明、展示入口与代表图。状态由实际检查返回；失败时给出可解决的缺项。
  3. 材料条件通过且该版本首次入册时，研究卡从工作区进入书架，编号印记落下，响起一次短声音。

  5. 修改成果后可重新检查、更新该卡，不把同一项目的重复点击累计为多张完成卡。

卡片、编号和书架直接对应我们真实积累的研究成果。第一轮只需要一个认真打磨的“归位”动作、一个落印动作和一个短音效；一般阅读、判断和错误提示保持清楚、平静。

真实触发条件与计奖边界#

建议自动检查的内容包括：项目 ID 与目录对应，源库或参考链接已登记，README 和研究笔记存在且没有关键“待填写”项，网页入口与本地资源存在，封面路径有效，目录索引检查通过。展示操作和内容质量仍按各项目的实际验收记录判断。

三个原创小世界怎样操作#

每场 32 秒四幕，每幕 8 秒，结束后停在终幕。页面提供暂停/继续、重演、章节、进度、强度、专注观看与有限连演。连演依次经过花园、月亮和影子，每场谢幕后至少等待 3.5 秒并等当前互动完成；手动切场、重演、跳转或花园选位会取消连演。

  1. 引力花园：拖动改变风向，点按让星种飞起并触发园丁与风精灵接力。点击“选个位置种下”后演出与配乐暂停，种子预览随选位移动；点按岛面提交，也可方向键选位、Enter/空格种下、Esc 取消。种下后仍暂停，独立收藏动画完成连续生根、抽芽、展叶和站稳，再点继续演出恢复。最近四株实际落点保存在本机；原保存按钮自动选位。
  2. 月亮修补铺：拖动拉线，点按触发月亮打嗝与裁缝追逐。收藏让补丁从裁缝手中飞向月亮，三针逐次拉紧，月亮闭眼满足。当前没有音乐文件。
  3. 影子排练场：拖动灯光，影子即时追光倾身和压低身形；点按切换站立、跃起、旋转与行礼，小光团随后举灯。收藏当时姿势与参数，纸影飞到前排并留下回应。

即兴与收藏有独立时钟，暂停也能完成反馈。舞台聚焦后可用方向键移动、空格触发；专注模式可用退出按钮或 Esc 返回。系统“减少动态”偏好会暂停配乐并保持选定章节静帧，禁用连演，操作保留静态结果。

世界状态仅存于本浏览器 localStorage：三个计数位于 chippytea-original-worlds，各场上限 30；花园 chippytea-garden-plots 保留最近四株归一化落点；影子 chippytea-shadow-poses 保留最近三个实际动作、指针、时间与强度。前排最多五位观众，其中最近三份用实际动作，其余为通用行礼剪影。当前不保存实际研究内容，不提交 /api/research/collect，不增加真实研究回执。

音乐与声画同步#
