先确定字符的位置

  • 重复字符：找到目标位置，平滑迁移
  • 删除字符：原位缩小并淡出
  • 新增字符：在目标位置长大并淡入
x(t) = x₀ + (x₁ − x₀) × ease(p)

p 是当前阶段的时间进度，ease 决定起步与收尾的速度。

01

拆分与布局

把文字拆成字符，把图标作为独立单元；按字体测量宽度，计算字位。

Intl.Segmenter · measureText
02

匹配与编排

字融按字符 key 匹配前后句；其他效果可使用关键帧、路径、粒子或物理规则。

matchGlyphs · keyframes
03

时间驱动

根据 t 找到当前阶段，计算位置、缩放、透明度和颜色，再绘制这一帧。

resolveTimeline · renderFrame
04

画布渲染

现代文字效果可用 Canvas 2D；部分早期和立体效果使用 p5.js / WebGL。

Canvas 2D · p5.js · WebGL
05

逐帧编码

按 t = 帧号 / fps 重绘，送入 GIF 或视频编码器；预览与导出复用时间逻辑。

RGBA frames · H.264 / GIF

「字融」并非逐笔画变成另一个字。源码匹配重复字符并移动字位，对删字和增字处理缩放与透明度。字阶则使用字形框关键帧插值，其他效果有自己的算法。

04 / WHEN TO USE IT

从想表达什么，选择运动。

下面是基于效果特征的使用建议，点击可回到对应原作。

品牌 / 活动

一句话，留下印象。

动态口号、活动标题、开场字标。用字符重组表达变化，用逐字放大强调重点。

产品 / 功能

把卖点分成几拍。

产品功能介绍、搜索流程、发布会屏幕。每一拍承载一个信息，避免同时塞满画面。

作品 / 商品

让变化可以被看见。

修图前后、视觉方案对比、商品与照片展示。快门和翻面给切换一个明确的发生时刻。

内容 / 教学

让信息跟上节奏。

短视频章节标题、知识点轮播、课程开场。少量关键词逐次出现，配合后续剪辑与配音。

采用它的价值

把已经编排好的运动作为起点，把时间花在文案、素材和节奏上。适合反复制作风格一致的动态片段；复杂长片、音轨混合与自由时间线剪辑仍需其他工具配合。
