# 庭院猫与鱼群惊散

这是在独立庭院中新增的行为示范，不属于上游原作已有元素。原作运行副本继续保持原代码，仅替换两处依赖地址。

| 画面效果 | 实现方式 | 当前范围 |
| --- | --- | --- |
| 猫观察、起身、巡游、坐下 | 有限状态机；固定模拟步长推进计时，闭合路线连续给出位置与朝向 | 固定干地路线，未接入任意地形寻路 |
| 猫四肢、呼吸与眨眼 | 两段腿部逆运动学，四足相位错开，低幅度周期姿态 | 运动学步态，未求解全身动力学或精确防滑落脚 |
| 猫的连续形体和弯曲尾巴 | SDF 平滑合并与 Surface Nets；单一封闭尾网格由九骨骼蒙皮 | 程序虎斑材质，未使用毛发束模拟 |
| 调整池塘尺度后猫仍保持原尺寸 | 用完整父仿射矩阵的逆变换建立世界姿态；插值记录尾骨和关节 | 路线位置固定在庭院前景砾石上 |
| 手靠近后鱼警觉、惊散 | 水面上方距离阈值触发警觉和一次近距离刺激；局部径向避让有不同偏角 | 不判断鱼的真实情绪，也不伪造已经接触水下鱼背 |
| 鱼转向、加速、下潜、恢复 | 有界角速度、角加速度和游速；增强分离、减弱对齐聚集；4.5 模拟秒平滑衰减 | 保留池岸、鱼身碰撞与导入水域的深度约束 |
| 手及时撤回 | 开始时确定附近鱼的位置，短暂靠近后收回 | 不吸附鱼，不持续追逐逃开的鱼 |

操作：在“按图构造”的动物控制区点击“庭院猫巡游”；也可在视角菜单选择“观察庭院猫”。选择视角保留暂停状态，巡游按钮会开始动态观察。点击“轻触锦鲤”，或聚焦画布后按 G，可观察警觉、惊散和恢复；空格暂停或继续。“效果与技术原理”新增对应观察项，并可打开验证入口。

零鱼时轻触入口拒绝执行，不添加鱼。正在恢复时再次轻触会提示等待；结束手部动作不清除已触发的受惊记忆。恢复参考、A/B 重置与水域切换清除反应；普通清理饲料不会清除鱼的受惊状态。导入模型时庭院猫不可用，未绑定水域时鱼群互动不可用。

价值是把动作改成可以检查、可调节的连续反馈：可以分别调距离阈值、转向限制、反应范围和衰减时间，再观察角色与环境的关系。当前示范先完成这两种行为，未来可复用状态机和姿态插值增加其他庭院动物。

实现：`src/cat.js`、`cat-anatomy.js`、`cat-motion.js`、`animals.js`、`fish-startle.js`、`fish.js`、`interaction.js`；反馈与说明在 `wildlife-ui.js`、`principles.js`、`principle-learning.js`。
