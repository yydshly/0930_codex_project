# 网页破坏交互研究 · 完整汇总

整理日期：2026-10-02。研究总览：[网页入口](http://127.0.0.1:8949/projects/009-sprite-destruction-lab/)，[一图完整汇总](../web/research/overview.svg)，[高清 PNG](../web/research/overview.png)。

## 我们研究的到底是什么？

起点是 Sprite Fusion 的 **Destroy Any Website**，它是将网站转换为可破坏射击关卡的游戏应用。我们核对官方页面、公开客户端与两个实际网址场景；**未确认它有公开的网页破坏 SDK、服务端源码或开源许可**。素材生成 API 不等同于网页破坏能力。

本地可复用对象是独立实现的 **DestructionEngine**。Matter.js 0.20.0 提供二维刚体求解；html2canvas 1.4.1 或浏览器截图提供画面。不能据此推定原作用了这两个库。独立模块进一步提供角色编排、浏览器接入和各产品任务。

核心结论：让现有内容成为视觉输入，把内容、区域、运动、角色、任务和业务服务分开，才能判断哪些能力能直接复用，哪些需要另外开发。

## 原始效果与本地效果

| 项目 | 原作观察与官方能力 | 本地实现 |
| --- | --- | --- |
| 输入 | 网址转游戏关卡；两网址实际进入关卡 | 自有 DOM，或扩展当前视口截图 |
| 运动 | 角色跑动、跳跃、飞行 | 游戏角色刚体；头像角色预设动作编排 |
| 破坏 | 射击文字与块，武器和手雷 | 真实纹理切片；射线命中或区域冲击 |
| 表现 | 网页成为可破坏射击环境 | 玻璃、纸片、方块、像素、霓虹、涟漪六模式 |
| 多人 | 官方提供房间，本次未实测 | 本地未实现联机服务器 |
| 接入 | 原作网址参数与嵌入入口 | DOM、快照、冲击、帧回调、事件和恢复接口 |

原作客户端可见 URL 获取、代理 / iframe 采集、元素几何与文字，以及房间 WebSocket 路径。服务端处理与完整同步机制不在证据范围内。

本地六模式的计算方式分开：玻璃是不规则三角刚体，纸片是条带刚体加风力 / 摆动近似，方块是矩形刚体；像素使用采样颜色与寿命衰减，霓虹使用曲线聚合与回收计数；涟漪用累计遮罩和采样面积。后三者不是刚体碰撞，涟漪进度也不是像素精度。

## 可复用原理

1. **取得内容**：DOM 路径根据支持的样式重建画面；扩展调用当前标签截图；后续自有宿主可以提供 Image / canvas。
2. **定位区域**：用 CSS 像素矩形建立纹理坐标、点击目标与角色来源。图像像素倍率独立换算，避免 DPR 与布局混用。
3. **生成表现**：切片持有原图区域；按模式建立刚体、粒子或遮罩。纹理随位置与角度绘制。
4. **驱动动作**：命中后解除固定并赋予初始运动；角色动作通过帧回调独立编排，脚部调用 impactAt。角色本体并未参与真实刚体行走碰撞。
5. **连接流程**：命中、首次交互、完成与进度交给业务层。按原始面积统计，目标标签单独计算；复原销毁物理、帧循环与监听。

两条准备路径为 `prepare()` 和 `prepareSnapshot({texture,width,height,regions,dpr,transparent})`。`impactAt()` 接受外部角色冲击；`onFrame` 提供逐帧时机；`onEvent` 连接任务；`dispose()` 清理。引擎并不负责翻译、商品资格、多人同步或 AI 角色生成。

跨站路径只隐藏选中子树，并按属性恢复原 visibility 和优先级，其他区域仍可操作。动态布局、滚动、缩放、切走标签或结束效果都清理场景。网页自身 Shadow DOM / iframe、离屏采集和保持位置不变的内容更新仍有适配限制。

## 产品能力与价值

**直接复用视觉互动**：内容动效制作、网页反馈组件、品牌角色、创作者主页、可玩入口与碰撞教学。现有输入、状态、动作和输出可以作为组件化基础。

**结合实际任务和服务**：新品揭晓、品牌展览、活动领取 / 预约、提案对比、维护指南、数据故事。视觉互动帮助展示与反馈；资格、核销、项目版本、型号资料、数据接口和协作状态需要自己的实现。

**另建网页效率插件**：翻译阅读、来源摘录、表格提取、文字处理和批量整理。可与角色 UI 共存并按需调用，底层能力分别来自语言服务、DOM / 浏览器 API 和数据处理模块。

当前价值是降低内容互动适配成本，让能力可操作、可导出、可观察。还没有线上留存、付费、营销转化或普遍兼容证据。采用时先测任务完成、后续动作与维护成本，再扩大投入。

本次网页整理后，研究首页 21/21、总览图导出与文字边界 4/4、原实验迁移回归 21/21 通过。检查了实际功能路由、PNG 文件、桌面 / 手机、分类、放大 / 缩放及来源说明。记录见 `summary-checks.json`、`summary-image-checks.json`、`browser-checks.json`。

效果模式 49/49、产品原型 50/50、头像 18/18、跨站头像 21/21、工具箱 30/30、工具箱扩展 19/19、旧游戏 21/21 为各自浏览器验证；它们测不同功能，不能简单相加当成一个覆盖率。详细记录保存在对应 notes/*checks.json。

**GitHub 15.48 秒视频是实际浏览器录制，操作由脚本完成。** 真实网页当场截图提供纹理，角色和碎片现场运行。无界面测试无法点击扩展工具栏，仅临时副本加入全站截图授权；下载包仍为 activeTab+scripting。因此跨站流程与像素管线已验证，生产包人工点击获取临时权限的步骤未在录像中验证。

翻译曾在实际 MDN 页面成功，之后真实服务返回 HTTP 429；本地翻译模型当前不可用。不得用 UI 测试成功代替在线服务可用。
