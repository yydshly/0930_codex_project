# 六种效果模式扩展 · 2026-10-02

模式与场景分开选择，同一个真实 DOM、任务阈值与完成动作可对应六种表现。默认玻璃裂解；选择模式时复原页面，正在运行的体验会在新模式中继续。五种新模式均直接点按/拖拽触发，方块模式保留角色射击。

| 模式 | 形状与运动 | 适用场景 | 本地计算方式 |
| --- | --- | --- | --- |
| 玻璃裂解 | 错位网格形成不规则三角碎片，带原内容旋转弹跳 | 产品揭晓、科技展示、冲击反馈 | 凸三角形 Matter 刚体、纹理裁剪 |
| 纸片飘散 | 细长纸带，轻风、升力、角度摆动、缓慢下落 | 编辑内容、邀请函、节庆 | 条带刚体，风力与摆动近似；无三维折纸 |
| 像素消融 | 细像素颜色来自原页面，向上漂浮并衰减 | 游戏入口、数字内容、加载转场 | 纹理采样、位置积分、寿命衰减 |
| 霓虹聚合 | 彩色光点沿曲线进入右下能量环，显示实际回收数量 | 数据归集、积分收集、科技活动 | 曲线插值、光点轨迹、寿命结束累加 |
| 涟漪揭幕 | 触点扩散涟漪，圆形遮罩渐进擦除 | 导览、活动揭晓、轻互动 | 累计 Canvas 遮罩与每片区 25 点面积估计 |
| 方块破坏 | 原有矩形切片、角色、射线攻击、重力碰撞 | 动作游戏、碰撞教学、对比基线 | 原有 Matter 矩形刚体 |

## 接入接口

```js
const lab = new DestructionEngine({
  canvas,
  source,
  effect: 'neon', // glass / paper / pixels / neon / ripple / classic
  threshold: 0.35,
  onEvent: event => { if (event.type === 'complete') revealNextStep(); }
});
await lab.prepare();
lab.start();
```

对外构造默认仍为 classic，兼容之前的接入代码；研究网页默认 glass。模式改变几何与运行时状态，需要 dispose 后重新构造，不能只替换颜色。

- web/effects.js：模式说明、粒子生成/更新/绘制、纸片风力与圆形遮罩。
- web/model.js：不规则三角切片、细条带、面积统计与部分覆盖。
- web/engine.js：直接交互或角色射击、刚体及纹理绘制。
- web/app.js：模式切换、业务任务、输入说明与模式对应统计。

继续扩展时，可增加 profile、几何切片或 EffectLayer 的表现分支；保留统一 complete 事件，让业务行为复用。玻璃/纸片/方块是刚体模式，像素/霓虹是粒子动画，涟漪是遮罩，界面不把后三者的视觉元素标成物理碎片。

## 参数与统计

重力与刚体边界仅在三个刚体模式显示。强度影响刚体初始运动、像素速度、霓虹聚合时长；涟漪模式中控制擦除半径。片区尺寸在下一次开始时生效。

涟漪进度允许部分片区覆盖；每个片区采用 5×5 点估计，重复圆形区域不重复计数。这是近似面积，不宣称像素精度。活动旧价目标仍单独按标签统计，不能用其他内容代替旧价达成任务。

像素/霓虹实时粒子上限为 6500，按寿命回收；切换模式会销毁旧的刚体与循环。当前没有移动设备实机性能或三维材质验证。
