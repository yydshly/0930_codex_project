把工具箱带到其他网页

网页版可直接演示，扩展版可处理你正在阅读的网页。使用相同工具代码，不需要账号。

安装 Chrome / Edge 扩展

  1. 下载 ZIP 扩展包，解压到一个固定文件夹。
  2. 在浏览器地址栏输入 chrome://extensions 或 edge://extensions，打开「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择包含 manifest.json 的解压目录。
  4. 打开普通网页，点击浏览器工具栏中的 Forma 图标。选中文字后可翻译、摘录，或读取当前页面表格。

内容如何处理

扩展在你主动点击时访问当前网页。摘录保存在扩展本地存储中，带原文、标题和来源。表格提取、文本整理和单位换算在本地运行。

在线翻译使用 MyMemory GET 接口，会发送你选择的文字和语言对；免费服务有配额与网络限制。本地翻译模式依赖浏览器的 Translator API 和可用语言模型，不支持时会明确提示。

浏览器设置页、扩展商店等受保护页面不能注入；图片里的文字需要另加 OCR，当前工具只读取网页可访问的文字和 HTML 表格。

更新与移除

更新时重新解压文件，并在扩展管理页点击「重新加载」。关闭工具箱会移除页面中的面板、插入译文和临时标记。要删除摘录，可在摘录列表逐条删除；卸载扩展会移除扩展存储。
