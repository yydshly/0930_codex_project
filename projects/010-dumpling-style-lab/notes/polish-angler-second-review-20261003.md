# 暮湾浮标：第二轮场景精修

第一轮实看暴露的问题是：四株稀疏小树、大片裸坡、灰平水面及青色岸带，以及将普通暮色背景图作为球面全景后丢失的远山。

第二轮在 `web/showcase-angler-polished.js` 中修正：

- 保留生成背景的云层、夕照和山线，将其放到湾后方的背景面；环境照明仍使用同一图像。
- 新增闭合远湾的起伏地形，避免两侧岸线在开放水面中突然终止。
- 六株真实近景松树，155 株中远景松树。远景使用同一真实松树模型在初始化时烘出的透明树影，保留枝叶细节，并避免每株重复 124,481 个枝叶顶点。
- 岸石提高自然曝光，泥岸色彩降低青绿色突变，水面新增微波、天空倒影和弱窄泡沫。
- 降低芦苇的饱和度和高光，增加少量植被聚落。

保留原模块、模型、纹理及存档键。规则常量及存档默认字段与原版逐字相同，抛投、等待、扬竿、控线和得分逻辑与原版一致。已有精修版鱼竿位置属于视觉映射，本轮没有更改。

Node 语法检查通过。实际画面审查及试玩由主任务统一使用 CUA 完成；此笔记不将语法检查视为视觉验收。
