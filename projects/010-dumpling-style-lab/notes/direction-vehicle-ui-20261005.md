# 岚谷试车场：页面与控制器

第十个原创方向为 `web/direction-vehicle.html`，配套 `direction-vehicle.css` 与 `direction-vehicle.js`。RIDGE WORKS 使用深钢绿、暖铜色仪表与山谷实景纹理，形成户外工程车的试车台。页面按钮文字至少 13px，说明文字至少 11px，主要操作目标至少 44px。

## 真实驾驶与操作

- 生产控制器导出 `createVehicleController(options)`；浏览器中的 `window.vehicleDirection` 提供 `getWorld()`、`getCamera()`、`getTimescale()`、`getSelected()`、`getDemoMode()`、`ready` 与 `readyPromise`。
- 点击场景聚焦后，W / 上方向键为油门，S / 下方向键倒车，A D / 左右方向键转向，B 制动，E 按实际地点与任务阶段领取运输任务、装载、卸货或回库验收，C 在追尾、场地总览与环绕检视三种真实渲染相机之间切换，空格暂停。按钮、表单和链接聚焦时保留浏览器键盘行为。
- 多个指针可以同时持有油门、转向与制动。一个按钮可拥有多个触点，取消单个触点只释放该触点；暂停、页面暂离、接管、重开与场景失效统一清理所有持有者。
- 调校按钮通过引擎预览得到可用性与拒绝原因。只有停车后才可切换舒适或紧致弹簧与阻尼，不会改变货物。紧致设定明确描述为更硬弹簧、更强阻尼与清晰路感，不宣称在所有路面下更舒适或更稳定。
- 装卸需要实际驶入北坡料站或桥东工地的地点标记并停稳。4 件货物固定增加 320 kg，车身质量从 1,250 kg 变为 1,570 kg；卸货后恢复空车质量。车库领取与最终验收也来自真实任务顺序、地点和速度规则。
- 驾驶辅助使用普通转向、油门与制动持续走完真实道路。人工踏板或转向立即取消辅助。完整示范只规划动作与输入，再对真实世界调用一次 `stepWorld`；×1 / ×2 保留同一辆车，只改变后续步长。
- 亲自驾驶与示范均可完成领取、缓坡行驶、装载、搓板路交付、空车跨桥与回库验收。完成后由引擎立即暂停；普通后续帧不会继续推进时钟、车身或弹簧。结果卡为紧凑文字卡，最大宽度 480px。
- “开始亲自驾驶”“观看完整试车”“开启新一轮试车”创建新的现场。“接管当前车辆”和“继续上次”保留位置、速度、载重、四轮悬架、调校和已完成的任务，接管只撤销示范和驾驶辅助。

## 舞台与保存

全屏请求完整的 `vehicle-stage`，包含 HUD、三维场地、触屏踏板、暂停、相机、读数、倍速、E 操作，以及可展开的路线、调校与货台终端。全屏退出有独立入口。终端内与侧栏的调校、装卸按钮共用同一控制器。

Canvas 绝对定位填满视口容器，避免内在 1440×800 尺寸反向撑高网格。场地最小高度 240px；控制区可独立滚动，侧栏在桌面上独立滚动。终端展开或收起会请求渲染器调整并重新对齐完整舞台，舞台禁用浏览器滚动锚定。`#play` 首次入口在异步渲染器就绪后再次对齐舞台，使 HUD 位于可见区域。

唯一存储键为 `world-play-direction-vehicle-v1`，保存引擎序列化现场、相机、读数显示、倍速、目标与示范偏好。引擎负责验证货物、质量、任务账本、地点、四轮数据及路线；有效现场恢复为暂停，`?demo=1` 不替换已恢复现场。页面不读取或清除前九个方向的保存键。

异步 Three.js 场景准备完成前不安排动画帧或推进世界。启动失败、WebGL 上下文丢失或运行时渲染错误都暂停并保留车辆，显示明确重试入口。重试只重建渲染器，保留同一辆车。

`tooling/check-direction-vehicle-controller.mjs` 完成 35 项生产控制器检查，报告为 `notes/direction-vehicle-controller-20261005.json`。测试读取实际页面 ID 与 data 属性、触发生产回调并使用真实车辆引擎；只有 DOM、RAF、保存与异步渲染边界使用适配器。

验证覆盖手动驾驶与整轮示范的普通帧完成、320 kg 实际装卸、桥面路径、停车调校、真实速度与四轮读数、惯性与制动、同车接管、一次步进、×2、完成冻结、并发触点、键盘焦点、三种相机请求、全屏目标与终端、舞台对齐、独立存档、伪造货物拒绝、上下文中断与运行错误恢复。旧方向保存哨兵保持不变。

CSS、实际 Three.js 画面、浏览器原生全屏与硬件触屏由真实浏览器验收；控制器适配器检查不宣称覆盖视觉渲染。此版本是原创本地刚体姿态与四弹簧工程样例，不实现真实软体车辆、破坏、联机或 Rigs of Rods 代码移植。
