# 四种新的游戏参与形式

本批新增地图勘察旅行、柔性多肢操控、剪纸造路、360°环视勘察。当前共 **83 种可玩形态、92 个入口**。此前的 79 种形态、88 个入口及全部美术版本继续保留；旧文件没有覆盖，存档前缀和已有 ID 不变。

| 形式 | 玩家实际改变什么 | 本版呈现与完成流程 | 明确边界 |
| --- | --- | --- | --- |
| 地图勘察旅行 | 旅行顺序、路线预算和观察记录 | 原创海岛地图；选择相邻地点、领取渡船证、队伍实际沿线旅行，记录三处地标并回营地 | 八处地点、十条连线；没有环球旅行与分支小说 |
| 柔性多肢操控 | 每条肢体的末端和持物状态 | 原创水下研究舱和玻璃机身；三条会连续弯曲的臂分别搬运样本，装入同色接口 | 固定机身，反向运动学链；没有完整软体碰撞或全身步行 |
| 剪纸造路 | 纸片的位置、角度与实际长度 | 原创纸片海岸、折纸桥和信使；自由布置三片桥，端点连通后信使沿真实通路走到远岸；有缺口会坠落 | 几何连通与路径行走；没有自由剪切或完整刚体物理 |
| 360°环视勘察 | 观察方向、视场与地标测量 | 原创全景纹理在三维球面上投影；转动完整一圈、望远镜放大、保持准星稳定，记录三处地标的方位及仰角 | 固定观察点，没有自由行走或立体地形；细节层是独立方向插画，非摄影测量重建 |

每种都有自己的目标、错误反馈、正常操作完成流程、原生按钮、暂停门控与独立状态保存。卡片预览来自实际生产绘制函数；全景卡片使用明确标注的兼容投影，不是浏览器 WebGL 截图。

地图可以按“营地 → 崖边 → 灯塔 → 山脊 → 岔口 → 湿地 → 河口 → 旧港 → 营地”规划，先领取渡船证。到灯塔用盐雾、到湿地用芦苇、到旧港用石墙标记记录，再继续出发。

柔性臂选中一条后拖末端到样本旁，抓取并移到同色接口，再松开。1 / 2 / 3 选臂，方向键微移，空格抓放。纸片拖动改变位置，Q / E 每次旋转 3°，按钮每次改变 5% 长度；金色端点接到锚点后让信使试走。全景拖动或用方向按钮转动，放大至 2.2 倍以上，对准圆标，测量时稳定保持 1.2 秒。

## 参考案例与原创部分

地图方向参考 [80 Days 的官方介绍](https://www.inklestudios.com/80days/) 中组织路线和旅行方式的参与感；本版只做一座岛的路线勘察。柔性肢体参考 [Octodad 的开发者商店介绍](https://store.steampowered.com/app/224480/Octodad__Dadliest_Catch/) 中协调不易控制的肢体；本版为固定研究机的三条柔性臂。

剪纸方向参考 [Tearaway 的官方纸艺页面](https://www.mediamolecule.com/tearaway-papercraft) 的材料世界表达；纸桥端点连通和试走规则由本项目独立设计。全景方向参考 [Myst III: Exile 的官方介绍](https://cyan.com/games/myst-iii/) 所述的 360°观察自由度；本版增加地标方位测量。这些是参与形式的参考，没有使用参考游戏的角色、美术或代码。

十份素材通过**内置 ImageGen** 制作。原始 PNG 在 `assets/game-forms/voyages-sources/`，运行 WebP 在 `web/assets/game-forms/voyages/`。[完整提示词、参考/编辑来源、尺寸和哈希](../assets/game-forms/voyages-generation.json) 均保存。图像处理只做原件复制与 WebP 编码，没有用程序重新绘制原画。关卡中的路线、末端运动、纸片变形、地标投影和反馈由游戏规则实时驱动。

## 实现与验证

路线按实际连线消耗补给，渡船采用海侧曲线路径，中途恢复不重复扣费。柔性臂使用固定根部的 24 段定长链求解，末端逐渐跟随，拿起的样本跟随实际末端位置。纸桥的变换直接生成世界端点，连通关系决定信使行走；撤销以整次拖动为单位。

全景主模式使用本地 Three.js、内向纹理球面与透视相机。三张高细节方向层映射在相同方位的平面上，放大时渐显；转动与视场变化仍作用于同一个相机。兼容模式按球面射线采样原图与同方位细节层，使用小纹理块近似重投影并缓存静止视角，不冒充真实 WebGL 输出。

**113 项新增检查通过**：53 项规则/投影检查和 60 项生命周期/原生回调检查。四个正常操作流程都完成，12 张开始、进展、结果的生产绘制输出已检查。修正了长度链退化、地图缩放对齐、全景近景模糊、完成卡遮挡与纹理释放。

旧玩法回归、6 项站点测试、19 个演示构建通过。2,389 个受保护旧文件未变化；旧目录条目逐项一致；26 个新打包目标与源文件哈希一致，HTTP 返回的文件也与工作区一致。8962 静态服务和 8963 房间服务继续运行，没有重启或修改旧房间。

**真实浏览器验收尚未完成**：本次重新初始化后，浏览器控制内核在连接前退出。未验证真实 HTML 排版、触摸、全屏、刷新存档、GPU 纹理接缝及帧率，因此不宣称展示质量全部达标。[完整检查](voyages-package-check-20261004.json) 和 [预览来源](voyages-preview-provenance-20261004.json) 明确区分已通过内容和待验收内容。

## 下一步可以延伸

地图可加入交通选择与旅行事件；柔性臂可加入接触碰撞和可移动机身；剪纸可加入自由剪切、折叠和作品导出；全景可加入多观察点、空间热点和方向声音。这些没有计入已实现数量。新的参与形式仍可探索绘制轨迹来驱动角色、跨时间的异步传递、语音或摄像头输入；应先做清晰可操作的短场景，再接受真实设备和画面验收。
