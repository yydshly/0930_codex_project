## 四种差异如何实际呈现

指令战斗的主要决定是技能、资源与目标，没有走格或移动操作。城市规划改变道路与设施，路线连通、拆路断流和车辆移动反映规划结果。物理机关使用连续位置、旋转与接触结果，玩家要让结构真实支撑。合作改变参与方式：两位玩家分别控制角色，一人独自到达出口不能完成关卡。

四款都是可继续迭代的固定短局。RPG 没有开放世界与长期成长；城市没有长周期财政、复杂路口或完整交通模型，共用路段采用车辆密度减速；物理只提供一组工坊搭建任务；合作是本地同屏，没有联网和分屏。人物动画仍是本批使用的独立位图角色与实时移动、行动反馈，没有完整逐帧动作图集或动作捕捉。

## 美术、模型与物理引擎

本批位图采用 **内置 `image_gen`**，共六个任务。精确提示、透明背景设置、源文件和项目副本保存在 [生成清单](../assets/game-forms/systems-generation-20261003.json)。源副本位于 `assets/game-forms/systems-sources/`，运行 WebP 位于 `web/assets/game-forms/party/`、`tandem/`、`balance/`；裁切尺寸见 [素材记录](systems-assets-20261003.json)。

| 任务 | 用途 |
| --- | --- |
| `partyScene` | 天文台战场背景，中央留给实际队员、敌人与行动 |
| `partyHeroes` | 三名成年队员的透明立绘图集 |
| `partyEnemies` | 铜卫、影兽与星轮三种透明敌人图集 |
| `tandemScene` | 海岸动力站侧视环境背景 |
| `tandemEngineers` | 两名成年工程师的透明角色图集 |
| `balanceStone` | 三维工坊石材表面的可重复纹理 |

晨湾街区使用 Kenney 官方作者制作的 19 个 GLB 模型及四张原始色板贴图，分别来自 [City Kit Suburban](https://kenney.nl/assets/city-kit-suburban)、[City Kit Commercial](https://kenney.nl/assets/city-kit-commercial)、[City Kit Roads](https://kenney.nl/assets/city-kit-roads)、[Car Kit](https://kenney.nl/assets/car-kit)。这些官方页面标注 CC0 许可。原始包、原始许可与 SHA256 来源见 [城市素材清单](../assets/game-forms/systems-city-sources.json)，运行文件保存在 `web/assets/game-forms/district/`。模型网格和色板保留，GLB 仅改外部贴图路径，避免四个包的 `colormap.png` 文件名冲突；三维布景、灯光、道路拓扑、建筑摆放和通勤由本项目实现。

重力工坊复用项目中已有的 Kenney CC0 木板、箱子、设备等模型，加入原创石材纹理与实时物理。刚体引擎采用 [cannon-es 官方项目](https://github.com/pmndrs/cannon-es) 的 0.20.0 本地模块；[官方许可](https://github.com/pmndrs/cannon-es/blob/master/LICENSE)与本地 [MIT LICENSE](../web/vendor/physics/LICENSE)均保留。[物理引擎与模型来源清单](../assets/game-forms/systems-balance-sources.json)记录本地依赖。模型显示由 Three.js 驱动，碰撞体、约束和重力由本地物理引擎计算。

生成图和三维模型只提供美术资源。运行时不调用图像模型，技能结果、路网、车辆、刚体接触与合作机关由实际游戏状态驱动；没有导入历史参考游戏的角色、关卡或音乐。

## 独立保存与操作

四款分别保存为 `dumpling-showcase-v1-party`、`dumpling-showcase-v1-district`、`dumpling-showcase-v1-balance`、`dumpling-showcase-v1-tandem`。完成记录沿用 `dumpling-showcase-v1-records`。暂停、刷新恢复与当前入口重开沿用展厅外壳，不清除其他游戏进度；完成后的重玩保留展厅完成记录。

检查入口带 `qa=1`，使用 `dumpling-showcase-qa-v1-<id>` 与 `dumpling-showcase-qa-v1-records`，独立于正常存档。当前存档是浏览器 localStorage，没有账户、云同步或跨浏览器恢复。

城市用建设按钮与点击地块完成操作，可旋转街区；RPG 用技能与目标按钮选择行动，也可点击场中目标；物理提供完整抓取、移动、升降、旋转、放开与检验按钮；合作 P1 使用 A/D 与 W 或空格，P2 使用左右与上方向键，手机提供两组独立的 44 px 触控按钮。合作触控按钮现在放在独立控制行，不遮挡游戏画面。
