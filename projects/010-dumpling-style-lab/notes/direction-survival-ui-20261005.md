# 雨后余生：页面与控制器

第九个原创方向页面为 `web/direction-survival.html`，配套样式与控制器为 `web/direction-survival.css`、`web/direction-survival.js`。页面以雨雾山谷、墨绿底色、鼠尾草色状态线与暖琥珀色行动按钮呈现一个夜晚的生存旅程。

页面沿用方向页的基础样式，单独设置至少 13px 的按钮文字与 11px 的说明文字。桌面游戏舞台按视口高度布局，旁侧背包与日志独立滚动；窄屏上下排列。触屏移动按钮为至少 44px，可由多个指针同时持有，取消一个指针不会撤销另一个指针的控制。

## 实际交互

- “观看完整生存旅程”和“开始亲自探索”创建一片新山谷；“接管当前旅程”和“继续上次”保留当前位置、背包、物件耗尽状态、营地、天气与制作进度。
- Canvas 聚焦后，WASD / 方向键实际移动；E 搜寻、接水、修复或发送无线电；空格暂停。表单、按钮和链接聚焦时保留浏览器键盘行为。
- 地图点击先由渲染器转换为地图坐标，再调用真实路径规划；选择地点与“步行前往”使用同一条规则。
- 每帧示范只安排普通行动与路径，再调用一次生存物理更新。×1 / ×2 不创建世界、不重置路线，只改变后续真实时间步长。
- 完整示范首次达成天明目标后立即暂停并保存，结果画面不继续消耗燃料、推进天气或降低身体状态。点击“继续探索”、“继续上次”或“接管当前旅程”后，以手动模式恢复同一片现场；手动达成目标则继续开放探索。
- 配方与消耗按钮的可用性、缺少资源原因来自生存引擎对现场副本的预览；点击按钮才对真实现场调用 `act`。旁侧与舞台内的重复按钮共享同一个控制器状态。
- 三秒净水制作显示剩余时间，实际锁定移动与其他行动，暂停时进度冻结。营火搭建与添柴为两个独立行动。
- 原生全屏请求目标为完整的 `survival-stage`，包含身体 HUD、地图、暂停、接管、E 互动、倍速、触屏移动与可展开的背包 / 制作终端。
- Canvas 绝对定位填满实际地图容器，背包终端展开时不会由 Canvas 内在尺寸反向撑大舞台或裁切地图。终端展开 / 折叠会重新对齐舞台，舞台子树禁用浏览器滚动锚定，以保持 HUD 可见。
- 页面暂离清除所有键盘和触屏持有者并暂停现场。重新打开后恢复暂停；暂停与离线期间世界不推进。
- 异步场景就绪前不运行世界。加载失败或运行时渲染失败保留现场、暂停并显示明确重试入口。场景准备完成后，`#play` 入口重新对齐整个舞台，避免 HUD 被锚点或旧滚动位置裁掉。

## 状态接口

生产控制器导出 `createSurvivalController(options)` 与 `SURVIVAL_STORAGE_KEY`。浏览器可通过 `window.survivalDirection` 检查 `getWorld()`、`getSpeed()`、`getSelected()` 和 `ready`；`readyPromise` 用于等待初次场景准备完成。

唯一保存键为 `world-play-direction-survival-v1`。它保存引擎序列化现场、地点选择、倍速与地点标记偏好。恢复交由真实生存引擎验证；无法通过验证的存档回到新建暂停营地。控制器不读取或清除旧方向保存键。

关键 DOM ID：`survival-stage`、`survival-canvas`、`surv-demo`、`surv-manual`、`surv-pause`、`surv-takeover`、`surv-context`、`surv-speed`、`surv-labels`、`surv-fullscreen`、`surv-fullscreen-exit`、`surv-target`、`surv-stage-target`、`surv-stage-terminal`、`surv-load-status`、`surv-load-retry`。实际行动按钮使用 `data-surv-act` / `data-surv-value`，资源原因使用 `data-surv-reason`，触屏移动使用 `data-surv-input`。

## 验证边界

`tooling/check-direction-survival-controller.mjs` 完成 30 项生产控制器检查，报告为 `notes/direction-survival-controller-20261005.json`。测试读取实际 HTML 的 ID 与 data 属性，触发实际生产回调并使用真实生存引擎；仅浏览器 DOM、RAF、存储和异步渲染器边界使用适配器。

检查通过真实路线搜寻资源、修复并发送无线电、建营地、三秒净水、饮水进食与等待天明，完成手动和示范两种旅程。另验证同一状态接管、倍速、标记、物资耗尽、水泵冷却、暂停与恢复、多指针取消、键盘焦点、全屏目标、独立保存、伪造物资存档拒绝、加载与运行时错误恢复，以及直接锚点的舞台对齐。旧保存键哨兵保持不变。

CSS 实际外观、真实浏览器全屏以及硬件触屏须由浏览器验收，控制器适配器检查不宣称覆盖这些渲染环境。
