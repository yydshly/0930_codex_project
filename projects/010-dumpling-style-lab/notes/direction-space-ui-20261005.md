# 星潮航路：页面与控制器交付记录

新增独立的 `web/direction-space.html`、`web/direction-space.css`、`web/direction-space.js` 与 `tooling/check-direction-space-controller.mjs`，未修改既有方向页面、共享样式与导航。真实 Three.js 渲染器和规则引擎由主任务及并行规则任务提供。

页面采用暗蓝星舰控制台，首屏简洁介绍自由职业循环；原创星云横幅仅用于叙事，不能替代三维画面。舞台内一直显示速度、燃料、资金、货舱和任务，全屏保留相同读数及暂停、导航、接管、泊船、扫描、视角、退出与触屏输入。追尾与航区总览改变渲染视角，不改变飞船世界。

桌面舞台高度为 `min(760px, 100dvh - 30px)`，至少 590px。侧栏与舞台匹配高度并单独滚动，避免整个网格被长任务面板拉高；移动端侧栏恢复自然文档流。正文与侧栏说明桌面至少 13px、移动至少 12px；按钮与选择器至少 13px，HUD 说明至少 11px，任务至少 13px，触屏标签至少 10px。控制排换行，保持可读，不通过缩小文字容纳全部控件。

用户明确开始、接管或继续上次时，按照实际 `innerHeight` 和舞台矩形滚入视野，并使用 `focus({preventScroll:true})`。自动载入、恢复与动画帧不会自动滚动。开始新航程和显式恢复会把侧栏终端滚回顶部。

外侧和全屏终端有同步的目标选择器，可选择三座港站或远域信标。接单、买卖、交付、补给与结算使用同一套实际 `act` 回调。货舱会包含两舱封签运单，出售按钮只允许销售自由购买的货物。

键盘操纵为 W 推力、AD 转向、S 制动、Shift 加速、E 泊船 / 离港、按住 F 连续扫描、C 切换视角、空格暂停。触屏转向、推力、制动与加速独立保存 pointer ID，支持多指组合与单独取消。松开推力保留实际惯性；暂停、失焦、隐藏和 WebGL 上下文丢失清除输入并暂停模拟。SELECT、BUTTON、输入与链接获得焦点时，快捷键不抢占浏览器行为。

加载时等待 `createSpaceRenderer` 真正就绪，模型与纹理装载期间不推进时间。渲染器阶段进度显示在舞台内。WebGL 或资源失败显示明确解释和重试按钮，不用图片冒充 3D；重试与上下文恢复保留同一现场并暂停。

示范每帧只调用 `demoStep`，手动每帧只调用 `stepWorld`，避免物理双重推进。接管关闭自动脚本与导航，保留位置、惯性、资金、燃料、货舱与任务。完成报告读取冻结的 `completedAt`；目标完成后仍可继续自由飞行与贸易。

救援入口仅在燃料低于 1 且未靠泊时出现，舞台与侧栏都可使用。六秒接应期间显示倒数并锁定操纵、导航、目标与交易，清除所有持有输入。救援后返回曙光港、燃料为 20，保留货舱与任务，费用以引擎的实际现金与账本规则结算。

控制器导出 `createSpaceController` 工厂供真实回调验收。只把浏览器 DOM 和异步渲染器边界作为适配器；飞行、贸易、委托、扫描、救援与存档验证全部使用真实引擎。25 项检查通过，见 `direction-space-controller-20261005.json`，包括普通帧完成示范与手动完整航程、每帧只推进一次、真实惯性与加速、多指输入、五秒连续扫描、全屏目标同步、WebGL 失败 / 重试 / 上下文丢失、损坏金融存档以及通过真实耗油触发的六秒救援。与最终 27 项引擎规则检查合计 52 项；实际 WebGL 视觉、CSS 和硬件触屏由主任务另行验收。

保存只读写 `world-play-direction-space-v1`，恢复必须通过引擎金融账本和世界验证，并始终暂停。`?demo=1` 不会替换有效旧航程，既有方向存档保持不变。

参考明确限定为 Endless Sky 的自由职业循环，原创本地三维小航区，不移植源码、不提供联机。模型标明 Kenney Space Kit CC0，纹理与星云为原创 ImageGen；参考链接采用官方来源和安全的新窗口属性。
