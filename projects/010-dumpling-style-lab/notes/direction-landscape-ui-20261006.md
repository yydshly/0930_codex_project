# 溪丘拼境 / RIVERFOLD · 原创方向 14

## 已实现界面

- 四个新增文件：`web/direction-landscape.html`、`.css`、`.js`、`-render.js`。既有网页、图像、代码及存档未改动。
- 日间湖畔、浅玉色和奶油色面板。地图用内置 ImageGen 原创地貌 atlas 和柔雾背景；地貌不是用程序画出的装饰图标。
- 实际 Canvas2D 点尖六边形地图，1 片起点 + 18 片真实地块。地块可旋转、放置、撤回，牌堆耗尽后需主动封存。展示的是有限原创短局。
- Atlas 实际为 1536 × 1024，四个 768 × 512 象限。渲染器取每个象限中央的原生 512 × 512 方形，源裁切分别为 `[128,0,512,512]`、`[896,0,512,512]`、`[128,512,512,512]`、`[896,512,512,512]`，不会把长方形素材压成方形。
- 每片地块的六个地貌扇区来自实际旋转后的 `edges`。水路及岸线仅通往实际 `water` 端口，村落道路仅通往实际 `village` 端口。端口在一片地块内相连，符合规则的连接群定义。
- 预览是一片尚未放置的半透明地块；接边标记使用真实 `preview.connections`：绿点同类、黄点普通不同、棕点阻止放置的水边冲突。得分与三种最大连通地块群均来自实际状态。
- 原生空位选择器、上一处/下一处按钮及放置按钮提供完整可访问路径；地图点击只选中，不自动放置。当前地块另有真实六边编号与原生文本接边列表。
- 地块只有实际新增后才有 420ms 的轻微落位变化；撤回及起点不播放落位动画。减少动态偏好严格禁用落位变化。

## 原生控件与测试入口

ID 全部以 `landscape-` 开头：

- `demo` / `stage-demo`：主动开启新示范；`manual` / `new`：主动开启新手动局。
- `pause` / `takeover` / `resume` / `timescale`：暂停、原处接管、恢复及未来示范节奏 ×1 / ×2。
- `frontier`：原生 select，值为 `q,r`；`frontier-prev` / `frontier-next`：选择相邻空位；`rotate-left` / `rotate-right`：六边朝向。
- `place` / `undo` / `finish`：显式确认放置、撤回上一片及显式封存；`canvas`：真实地图指针和键盘入口。
- Canvas 聚焦后，左右箭头选择空位，Q / E 旋转，空格放置。不会劫持原生 select、页面键盘或组合快捷键。
- `score` / `progress` / `preview-title` / `preview-detail` / `objective-list` / `result-detail` / `mode` / `save-status`：全部来自真实规则状态的可读原生文本。
- `fullscreen` / `fullscreen-exit`：整座 stage 全屏，包含地图、当前地块、原生操作、目标及结局。

## 保存与示范

- 独立 localStorage 键 `world-play-direction-landscape-v1`，只读写该键。
- 世界由引擎严格动作回放恢复，读取成功后暂停。`?demo=1` 不会覆盖原有有效存档；新示范只有玩家显式点击后才重置。
- 图像就绪前操作与示范均冻结；图像失败显示重试。重试不重置已存在地图。保存空间失败明示“仅本次保留”。
- 失焦、页面隐藏、离开页面会暂停并保存；接管保留实际世界。
- 普通示范由实际引擎 `demoPlanner` 在普通 RAF 中每 800ms 执行一次合法操作，×2 仅改变未来节奏。实际完整示范 43 次操作、18 次放置、536 分、3 项连通目标，最后动作是普通 `finish`。

## 验证与边界

`tooling/check-direction-landscape-controller.mjs` 已实际运行 31 项生产控制器与生产渲染器检查。原生手动回调实际放完十八片后另外确认封存；普通 RAF 实际走完 43 步。也检查错误水路旋转、得分预览、撤回、六边端口、原生选择器焦点、严格存档拒伪造、查询保留、独立保存、素材失败重试、额度失败、全 stage 全屏、后台暂停、DPR 与 CSS 比例、像素几何命中及减少动态。

这些测试使用明确的 DOM、图像、Canvas2D 命令、RAF、storage、fullscreen 边界适配器。规则、tile、frontier、preview、score、groups、planner、恢复及生产渲染函数均是真实实现。测试结果不等于真实浏览器像素验收；后者由主任务另行检查原始素材、完整原生试玩、宽窄布局与原生全屏截图。

类型参考仅为 [Dorfromantik 官方介绍](https://www.toukana.com/dorfromantik)。素材、牌堆、原始规则均独立制作；这一项商业类型研究属于首批十项开源参考之外的后续方向。
