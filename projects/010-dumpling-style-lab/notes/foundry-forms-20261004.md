## 画面和素材

机械与航廊采用真正的 Three.js 三维模型、透视摄像机、阴影和材质。四轮可见独立贴地与转动，车辆有简化的俯仰、侧倾和车体弹簧反馈；航廊镜头随真实四元数姿态旋转。模型采用 11 个已有或本轮复制的 Kenney CC0 作者模型，原 GLB 与原始配色纹理保留。新增轮胎、轮辋、胎纹、螺栓、底盘和载货板由三维几何构成。新金属纹理只用于新增部件及工位板，不覆盖模型原有颜色图。

四份原创位图由 **内置 ImageGen** 生成：合金面板、环绕星空、风谷背景、透明物件与人物图集。源 PNG 原样保存于 `assets/game-forms/foundry-sources/`，运行 WebP 保存于 `web/assets/game-forms/foundry/`。[素材清单](../assets/game-forms/foundry-generation.json) 保存完整提示词、路径、透明度、尺寸、SHA-256、模型许可和预览来源。透明图集实际带 alpha，石台、尖刺、晶石、站立及跳跃人物、出口都用于关卡绘制。

开始、过程、完成的九帧保存于 `assets/game-forms/foundry-qa/`。关卡帧来自生产 Canvas2D 工厂，通过 Skia 执行；三维帧来自生产模型、摄像机与普通流程状态的独立深度投影，光照及 HUD 为诊断近似。**这些不是浏览器截图**，目录也分别标明预览方式。[来源记录](foundry-preview-provenance-20261004.json) 可以核对图像哈希。

## 完成条件与验证

运输必须安装抓取臂、靠近货箱、停稳抓取，最后停稳交付；航廊必须实际抵达四个顺序信标；造关必须收集当前设计中的全部晶石并碰到出口。没有定时自动通关或演示完成捷径。

37 项规则检查和 39 项生产控件及生命周期检查覆盖真实配置变化、惯性、局部轴变换、碰撞、编辑、撤销、保存恢复、暂停、焦点离开、指针取消与销毁。三个普通操作流程已完成。两套原始模板都通过实际移动跳跃通关；修改后的模板增加第四颗晶石，实际玩法也要求并收集了它，验证编辑地图确实驱动游戏。六个生产三维场景同步检查不改变玩法状态。

旧玩法回归、站点测试、构建、目录一致性、2498 个旧资源保护及新模块和资源的 HTTP 内容检查，见 [交付检查](foundry-package-check-20261004.json)。[质量复查](foundry-quality-review-20261004.json) 单独记录看过的画面与未完成验收项。

## 当前限制与下一步

机械采用约束配置和简化运动积分，不是自由零件连接或完整刚体机械求解；抓取有安装条件和距离条件，目前没有完整机械臂关节驱动动画。航廊有指定球形障碍碰撞，装饰设施还没有完整网格碰撞。关卡编辑限于固定网格和本地保存，还没有网络分享、多场景关卡包或自由曲面绘制。

浏览器控制工具两次初始化都报告 `trusted Node process exited unexpectedly`，没有返回页面状态。实际 WebGL 驱动画面、浏览器 CSS 排版、触摸、全屏、真实焦点交互与刷新存档尚未完成验收。离线画面与自动检查不能替代这些验证，也不能据此宣称产品质量全部达标。

后续优先完成浏览器验收，再分别扩展自由零件连接与机械任务、狭窄三维航道与可碰撞设施、关卡导出分享及创作挑战。这些未来能力不计入本轮完成数量。
