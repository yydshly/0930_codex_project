# 月影档案：页面与控制器交付记录

本次新增 `web/direction-stealth.html`、`web/direction-stealth.css`、`web/direction-stealth.js` 与 `tooling/check-direction-stealth-controller.mjs`。既有六个方向的页面与实现未修改。引擎与渲染器由并行任务分别完成，页面使用它们的公开接口。

页面采用夜靛、月银与旧铜配色。月下宅邸横幅只用于开场叙事，实际地面由材质、家具与角色图集绘制。保留原四张最终位图，并加载 `state-variants.png` 提供空档案桌、熄灭灯具与关闭开关。五张位图全部装载成功后才开启操作；素材失败时显示解释并禁用操作。

三个方案按钮选择下次开局：借影绕行、切断灯光、投石引开。示范与手动使用相同规则。接管只切换到手动并停止自动脚本，保留当前位置、守卫状态、灯光、计时、物品与目标进度。

控制包括点击地面寻路、独立投石工具、WASD / 方向键持续移动、三种姿态、C 切换蹲伏、Shift 临时奔跑、E 操作附近开关 / 档案 / 出口、空格投向实际瞄准点，以及 P 暂停。守卫选择只读取实时位置、怀疑度、行动状态和调查目的地。SELECT、BUTTON、输入框与链接获得焦点时，快捷键不会抢占浏览器操作。

HUD 中光照与脚步噪声以引擎的 0–1 数值转成百分比；最高怀疑度与守卫明细直接显示引擎的 0–100 数值。全屏顶栏也使用同一份实时数值与目标状态，窄屏读数另起一行，按钮至少 42px 高，不覆盖地图。任务明确区分取得档案和从西门撤离；胜利与失败后显示结果和重玩提示，禁用的动作不再给出移动操作提示。

触屏方向按钮各自保存 pointer ID，允许组合移动。地图仅接受自己的活动指针，另一指针不能覆盖瞄准点或取消捕获。暂停、失焦、隐藏与离开页面会取消按键和触屏输入；失焦时真实模拟也暂停。

完整 stage 包含地图、暂停 / 接管 / 全屏退出、姿态、操作 / 投石与触屏移动。全屏使用独立顶栏、地图区域与底栏，控制栏不覆盖地图。窄屏布局把方案与任务面板转为单列，非全屏方向按钮保持至少 44×44px，提示可换行且不压缩方向组。用户明确开始、重新开始或接管时，非全屏页面依据实际 `innerHeight` 把舞台居中；舞台高于视口时顶部留 12px。自动示范、恢复和动画帧不会滚动。

保存只读取 / 写入 `world-play-direction-stealth-v1`。恢复必须通过引擎模型验证；恢复后暂停，且 `?demo=1` 不会替换有效旧现场。损坏存档回到新的暂停开局。

控制器检查导入真实生产页面控制器、引擎与渲染器，使用最小 DOM / Canvas 适配器。24 项检查通过，结果见 `direction-stealth-controller-20261005.json`，其中包含三种方案通过普通动画回调取得档案并实际撤离、同一现场接管、真实开关与投石、组合指针、焦点保护、暂停恢复、损坏存档与素材失败。

既有六个方向回归全部通过：铜谷 22、风湾 24、雾岭 28、夜航 30、湾岸 33、深岩 47，共 184 项规则 / 控制器检查。加上最终的 22 项引擎检查与 24 项控制器检查，共 230 项。浏览器视觉、响应式与全屏实际验收由主任务另行记录；适配器检查不代替这些验收。
