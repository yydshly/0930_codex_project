# 芦湾观鸟 / REEDLIGHT UI

The original twelfth direction uses a native HTML field journal around a Canvas2D camera. Forest green controls and a warm paper contact sheet frame the original wetland artwork. The complete stage, including species selectors, camera controls, captions, terminal report and modal photo gallery, is the fullscreen target.

The production controller imports the pure wildlife engine and exports `createWildlifeController` for the callback checks. There are no constructed game outcomes. Native range, quick pan taps, pointer holds and held keyboard controls issue bounded ordinary rule actions; observation selection never moves the camera. The ordinary planner performs the demonstration. Demonstration ×2 advances both the observation clock and command pacing, with one bounded engine step per frame. Manual control always advances at normal speed. Takeover retains the same field state, images and camera. Opening the photo gallery pauses the observation clock and clears demonstration ownership; closing it remains paused.

The renderer imports the same `projectSubject` used for scoring. Its fixed 1600×900 sensor and CSS containment preserve the natural proportions of the transparent atlas crops. Partially visible animals are drawn and naturally clipped, while wholly outside subjects are skipped. Canvas contains only the panorama and projected animal images; native labels and reticle never enter captures. Each real shutter copies the current canvas into a 960×540 PNG and a 256×144 thumbnail, then binds those bytes to the engine's returned photograph ID. Rejected and duplicate photographs retain their actual score, reasons and image. Cleanup follows retained engine IDs and preserves best photographs.

Asset inputs are the unchanged local `landscape.png` and `animals-atlas.png` in `web/assets/directions/wildlife/`. The controller gates all observation on their successful load and exposes a visible retry. Tight source crops: heron `[109,28,561,612]`, perched kingfisher `[708,116,1144,599]`, deer `[108,643,564,1211]`, flying kingfisher `[674,674,1179,1147]`.

Full field and photograph records are written to the dedicated IndexedDB database `world-play-direction-wildlife-v1`, object store `archive`, using the same dedicated key. Only that new key is read or written in localStorage for a compact fallback. Restore compares save times, replays the actual rule world and remains paused/manual. Missing PNGs display metadata and a missing-original notice, with no synthesized historical images or download link. Persistence failures identify session-only photographs while allowing immediate download of captured images.

`node tooling/check-direction-wildlife-controller.mjs` produced 33 passing checks in `notes/direction-wildlife-controller-20261005.json`. These call the actual production factory and engine through explicit DOM, RAF, image, capture and persistence boundary adapters. Separate checks call the production Canvas renderer and IndexedDB adapter. Real browser PNG pixels, responsive appearance, pointer behavior and native fullscreen are accepted separately by the root agent.
