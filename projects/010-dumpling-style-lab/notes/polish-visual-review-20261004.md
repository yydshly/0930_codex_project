# 四种游戏形态精修：实际画面审看

## 范围与结果

本轮精修垂钓、回合炮战、迷你高尔夫、铁路调度四种。40 种形态和原有九款继续保留，未新增类型，也未把其余类型标成视觉验收通过。新增独立 polished 模块，默认采用精修画面；每款均有可见的“原版”切换，使用原有存档结构。

此前主要问题是场景层次不足、材质和模型比例不协调、镜头没有把重点组织起来，以及窄窗口仍被挤成两张小画面。此次按实际浏览器截图迭代美术、构图和操作区，未用生成概念图替代可玩场景。

## 浏览器操作证据

CUA 在独立 QA 存档中进行操作，未清空用户正常存档。最终交付页未推进用户正常游戏。

- 垂钓：恢复存档、继续、重新抛竿、选择落点、实际抛竿、错过扬竿后重新整理；原版切换仍恢复同一份进度。本轮没有在 UI 中完成收线入岸，不将张力阶段标为重新审看通过。
- 炮战：真实调整滑杆并发射两次，轮次、双方装甲和弹坑实际变化；刷新保留第三回合、双方55/25装甲与四个弹坑。
- 高尔夫：真实挥杆，杆数由1到2，滚动时禁用击球与滑杆，停稳后恢复。此次浏览器画面审看覆盖第一洞；三个洞的规则兼容检查另列，不能替代第二、三洞的视觉审看。
- 铁路：放行后道岔锁定；一次正确到站计数1/6；错误目的站可实际失败；重新调度后一次放行再切红灯，保留其他车待行。六车完整通关和冲突由独立规则检查验证，不声称六车都在本轮UI操作完成。
- 对照页：放大只显示一栏，返回恢复两栏；切换到另一游戏时前一游戏暂停；说明可以展开折叠。默认桌面、852×720、390×844观察无横向溢出。390px隐藏放大按钮，保留独立试玩入口。所有临时窗口尺寸均已恢复。

独立游戏的此次错误日志检查无错误。对照页捕获到浏览器观察器的 MutationObserver/Node 错误，项目脚本搜索没有对应 MutationObserver；来源日志没有脚本URL，不能确定来源，不宣称对照页日志零错误。已实际验证其加载、双栏、放大、暂停及说明功能正常，没有通过屏蔽错误处理这一记录。
