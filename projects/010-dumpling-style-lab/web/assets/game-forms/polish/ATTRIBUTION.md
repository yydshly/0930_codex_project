# 精修版新增美术来源

- angler-pine.glb: Poly Haven, Pine Sapling Small. 官方作品 https://polyhaven.com/a/pine_sapling_small 。CC0，https://docs.polyhaven.com/en/faq 。从作者模型抽取一株、内嵌 1k 纹理，近景使用真实模型，远景从同一模型生成透明树群纹理。未修改原版资产。
- angler-sky.webp、shore.webp、battery-earth.webp、crate.webp、sandbags.webp、rock.webp、pennant.webp：本项目通过内置 ImageGen 生成的原创场景纹理与道具。生成描述、原始输出路径与 PNG 保存在项目 assets/game-forms/polish-generation-20261003.json、polish-props-generation-20261003.json 与 polish-sources。
- 精修版本使用的已有 Kenney 与 Three.js/Cannon 资源仍遵循各自原目录的许可。铁路新增 Kenney CC0 素材的 License.txt 分别保存在 ../signal-polished/commercial/、industrial/、roads/、suburban/、cars/；下载与逐文件校验记录在项目 assets/game-forms/signal-polish-sources.json。松树原始下载与转换记录在 assets/game-forms/polish-angler-tree-source.json。
- previews/ 中封面由实际运行场景截图生成，未用概念图代替游戏。
