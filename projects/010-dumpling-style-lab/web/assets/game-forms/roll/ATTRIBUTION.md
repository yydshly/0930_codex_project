# 云廊滚球 / Cloud Cloister

- `limestone.webp`: generated specifically for this scene using built-in ImageGen. Full prompt, exact generated source path, source SHA256 and encoding details are recorded in `notes/roll-assets-20261004.json`. The preserved original PNG is `assets/game-forms/roll/limestone-generated.png`. Runtime material is a 1024² WebP; the generated image is used only as a material texture, never as a replacement for the 3D moving scene.
- Plants, flowers, grasses and rocks load the existing Kenney Nature Kit 2.1 GLB models from `assets/showcase/nature/`. Source: <https://kenney.nl/assets/nature-kit>. License: CC0, preserved in that folder's `License.txt`. No original model or license has been modified.
- Architecture, the continuous elevated stone path, arches, terrace edges, brass details, water shader and ceramic ball geometry were authored for this project. The sampled rendered path is exactly the path used for physics collision.
- Rendering uses the existing locally bundled Three.js; physical simulation uses the existing locally bundled Cannon ES 0.20.0. Their existing vendor license files remain in place.

All screenshot covers of this game must be captured from the running scene. A generated concept image must not be labeled as a playable screenshot.
