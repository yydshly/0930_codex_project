# 重力工坊素材

Physics engine: [cannon-es](https://github.com/pmndrs/cannon-es), pinned version 0.20.0, MIT. The full license ships at `web/vendor/physics/LICENSE`.

Authored visible models reuse the local Kenney [Nature Kit](https://kenney.nl/assets/nature-kit), [Space Station Kit](https://kenney.nl/assets/space-station-kit) and [Blaster Kit](https://kenney.nl/assets/blaster-kit), CC0. Their existing license files remain beside the source model packs.

`stone.webp` is an original stone surface generated with the built-in ImageGen for this batch. It is used as a repeated surface, not as a game screenshot.

The complete pinned dependency and per-model source record is `assets/game-forms/systems-balance-sources.json`.
