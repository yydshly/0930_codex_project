## 如何理解展示效果

画面语言、规则类型和参与形式分别记录。素材精美会影响第一眼；操作、动画、空间、反馈与成果共同影响体验。背景位图和局部动效适合部分研究，连续动作、自由镜头和可改造空间需要相应的运行体系。

本站组合 Canvas2D、HTML/CSS、Three.js、部分物理模块和 Web Audio，采用原创位图及有来源许可的模型、音效。各方向的状态、示范、完成反馈和保存属于实际规则；不同渲染能力只适用于对应样例。原作观察、生成美术、实际浏览器截图和规则检查资料保存在上级研究与记录目录。

本地浏览器按游戏隔离进度，摄影照片另用 IndexedDB。十五个独立方向中的合作样例采用本地同屏或一人切换角色；这些方向没有在线联机。公开静态站没有账户或云存档；深蓝议会与月湾接力的房间、接棒功能属于上文单列的本机后端实验。外部原站需要联网。工程验收说明所列行为可用，真人继续意愿、商业成熟度、长期性能与广泛真机覆盖仍要分别验证。

## 运行与发布

从仓库根目录运行：

```powershell
python -m http.server 8962 --bind 127.0.0.1 --directory projects/010-dumpling-style-lab/web
```

本地访问 [http://127.0.0.1:8962/index.html](http://127.0.0.1:8962/index.html)。多数样例及资源从本站加载，不需要另装前端依赖。原作 iframe 与参考原站受外部联网条件影响。

仓库构建命令为 `python scripts/build_site.py`，本项目输出至 `_site/projects/010-dumpling-style-lab/`；发布使用项目子路径，必须携带图片、模型、纹理、声音、供应商模块、许可和历史版资源。正式地址为 [GitHub Pages 项目首页](https://yydshly.github.io/0930_codex_project/projects/010-dumpling-style-lab/)，已完成发布与验收。发布到新域名后，本机旧域名的浏览器存档不会自动迁移。

## 运行

展厅默认入口是原有九款。使用「扩展试玩」或「全部」筛选查看扩展试玩；在原有游戏上方可直接切换画风、记住选择、进入独立窗口或打开冻结的原画快照。画风偏好以 `dumpling-art-directions-v2` 按游戏保存，QA 使用 `dumpling-art-directions-qa-v2`，不会修改原来的进度存档。两个入口中的暂停与声音按钮会同步。

这轮补充内部交互与反馈，不替换原有美术。方块支持 C 暂存，工厂支持暂停输送、施工费用预览与撤销设施编辑，证件桌支持字段核验与决策印章，两个第三人称海岛支持镜头俯仰、缩放和复位。原有九款的证据桌、需求检查、季节预测、物资收支、物件状态、路况与货物清单都由当前游戏状态驱动。逐款范围见 [改进清单](../notes/interiors-20261003.md)。

在仓库根目录执行：

```powershell
python -m http.server 8962 --bind 127.0.0.1 --directory projects/010-dumpling-style-lab/web
```

新增游戏不需要安装前端依赖；所有场景与资源从本地加载。Three.js r160 保留在 `vendor/`，附 [MIT 许可证](THREE-LICENSE.txt)。原作 iframe 从原域名加载，需要联网。

## 保存与共用控制

温室和旅店新增 `look=diorama/voxel/cinematic` 三种真实3D场景。拖动旋转、按钮缩放与复位；可切换外壳/剖面、关闭/打开标签、点设施或房间继续原有玩法。手机使用方形场景以留出操作空间，控件与标签至少44像素。其他游戏保留原有画风，浮岛继续使用已有3D场景；见 [三维记录](../notes/spatial-worlds.md)。

页面新增五种画风选择：`look=paint/pixel/cel/paper/neon`。新模式分别为像素、动态赛璐璐、纸片剧场与霓虹线绘，原画继续可选。选择保存在 `dumpling-art-direction-v1`，切换不重建游戏、不清除进度。二维关节人物与场景由代码绘制，浮岛切换真实3D材质；详见 [画风记录](../notes/art-directions.md)。

修改前的源文件与资源保存在 `versions/painted-20261002/`，可以直接打开其中的 `games.html` 对照。该版首次沿用已有进度，后续使用独立的 `dumpling-painted-preserved-v1-` 前缀保存。正常新版继续使用下述前缀；`qa=1` 两版也分别使用独立检查前缀。

`games.js` 负责游戏切换、按钮、键盘、手机控制、声音、暂停、大画面和保存；各游戏模块提供画布、状态、规则与反馈。

- 九款进度分别存于当前浏览器 localStorage，键名为 `dumpling-extension-v1-` 加 `detective`、`wuxia`、`ecology`、`wasteland`、`dream`、`arcade`、`inn`、`islands`、`movers`。共享存档外层格式仍为1；搬家日内部状态升级为3并兼容旧版1，旧版已交付物件保留。
- 约每 1.1 秒检查保存，操作按钮、切换、页面隐藏或离开时也会保存；刷新后恢复各游戏的进度。
- “重新开始”先显示确认；重访、重跑按钮保留旧结果，清空确认只清除当前游戏，其他方向保留；它们与原作及旧演示不共用存档。
- 声音默认关闭，主动开启后播放 Web Audio 合成的音乐与音效；支持暂停和大画面。
- 手机提供方向及互动按钮；跳跃、投掷按具体游戏规则使用，旅店主要通过点击和安排按钮操作。
- 新入口没有云保存、账户或跨浏览器同步；浏览器无法保存时，页面显示本次可继续游玩的提示。
