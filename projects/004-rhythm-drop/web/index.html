01 / WHAT WE LEARNED

声音主导，设计配合。

这轮讨论留下的创作原则与待验证判断。

01

先让声音成立

动机、音色、密度、强弱、留白与收束，构成情绪发展。动作与镜头接住具体的声音事件；只在节拍上闪光，容易变成机械的效果展示。

02

故事需要一个场合

先确定送给谁、何时播放、希望留下什么感受。陪伴、毕业、发布、欢迎新人，需要不同的乐句、角色目标和结尾。

03

特点来自表达与行为

球形本身没有固定性格。稳定的声音动机、外形细节、动作习惯，以及如何回应别人，才能让角色被记住。“同频”是关系中的回应。

04

成长必须听得见

种下一株植物只是开始。成长改变乐句，吞噬吸收音序，合成混合音色，多声部搭配创造新声音，才可能形成持续创作的理由。

05

真实的人可能带来价值

将声音与作者、背景、意图关联，允许被听见、被回应，并留下共同记忆。漂流瓶式社区是价值假设，需要真实参与者与持续反馈来验证。

06

功能完成，感觉仍然不足

多轮反馈仍认为缺少故事感、效果差。录音、漂流、回应的闭环已在本机实现，但音乐感染力、人物可信度与再次使用的动机尚未成立。

07

角色先于场景扩展

固定身体结构、声音身份、行为和伙伴关系。下一集从角色想要什么、哪里遇到困难、如何改变产生，让观众逐步认识同一组伙伴。

08

矛盾让情绪有层次

想靠近却怕被拒绝，赌气走开却仍在等待。双方都有理由和尝试；声音、视线与身体表达没有说出口的话，结尾也可以保留试探。

09

故事需要实际表演

介绍让角色被理解，乐句、姿态、镜头与停顿让关系发生。当前实现的是编排目标；技术测试通过仍不足以证明观众感受到了情绪。

03 / HOW IT IS MADE

参考图辅助设计，代码驱动实时故事。

当前回声小队由四层内容共同制作，作品的感染力仍取决于故事、音乐与表演。

层次现在如何实现仍需完善
角色设计生成概念、转面和动作参考图，保存提示词；固定声音身份。参考图尚不是完整模型或动画绑定。
角色表演程序化模型、肢体、布片与表情，配合编排的姿态与镜头。造型精度与细微表演仍有限。
音乐声音原创合成音色、乐谱、声像与真实静音；部分配乐提供 WAV。暂无真人配音，未自动分析任意歌曲情绪。
实时呈现声音与动画共用音频时钟，浏览器实时播放和互动。尚无完成的 MP4 或带声音的视频导出。

04 / WHAT REMAINS OPEN

保留理解，也保留不足。

本轮的结果是一组可运行实验和研究记录。更好的配乐、表演与故事，需要在一个具体场合里打磨，并用真实听众的完整观看、记忆与再次使用来判断。

社区方向则需要验证：人是否愿意留下真实声音，是否能得到有意义的回应，是否愿意回来。当前没有这些证据，不能把功能闭环写成产品价值已经成立。

公开版本的边界

  • GitHub Pages 托管静态研究页与声景演示；Python / SQLite 社区服务只在本机运行。
  • 自定义音乐按时长映射故事，尚未自动识别节拍或情绪。
  • 支持作品 / 花园 JSON 保存，部分角色配乐可下载 WAV；用户创作内容尚无音频或带声音的视频导出。
  • 声音形态是创作规则，不是人格判断或心理诊断。
