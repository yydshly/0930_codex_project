# 实现记录 · 2026-10-01

目标：实现音乐驱动球体弹跳的主要体验，形成能够调整参数和导入音乐的浏览器原型。

参考演示中可观察到角色球体、连续落点、发光反馈、跟随镜头和幽默文字。本项目用 Three.js 独立实现这些机制，场景与合成旋律原创。

## 模块

- `src/timeline.mjs`：时间转节拍、确定性轨道、连续弹跳、场景章节和时长。
- `src/app.js`：Three.js 场景、Bloom、台阶复用、相机与小球角色；Web Audio 预调度；本地音乐解码；界面交互。
- `web/index.html` / `style.css`：音乐工作台界面。
- `tooling/build.mjs`：将依赖和源码打包成自包含浏览器脚本，并保留许可证。
- `tests/timeline.test.mjs`：验证节拍落点、轨迹连续、章节边界与音乐时长。

## 时间模型

暂停时保留累计播放秒数。播放时用 `累计秒数 + AudioContext.currentTime - 起播时钟` 计算当前时间；音频与图形从这条时间轴派生。音频每 25 ms 调度未来 140 ms 的音符，暂停和跳转立即停止已调度的音符。

每个整数节拍对应一个台阶；两台阶之间线性推进，加 `4 × 高度 × 相位 × (1 − 相位)` 的弹跳高度。不是碰撞物理系统。渲染帧率降低时，视觉直接更新到正确时间，不累积动画误差；实际设备的音频输出延迟仍可能需要额外校准，当前没有测量或补偿。

内置音乐改变 BPM 时保留节拍进度，并重新调度声音。用户导入音乐改变 BPM 时保留歌曲秒数，调整动画对歌曲的映射；歌曲不变速。轨迹循环复用有限数量物件，但导入音频完整解码到内存。

## 视觉取舍

初次画面小球过亮，后来降低点光强度并提高 Bloom 门槛，保证表情可辨识。镜头看向当前台阶前方一小段，使画面既能看到小球，也能看到后续轨道。不同主题改变颜色、几何装饰、音乐与环境，不加载大型外部素材。

产品下一阶段最值得优先补的是首拍偏移和节拍标记编辑，之后再做自动检测和视频导出。

## v0.2：从参数实验到三个故事

新增 `stories.mjs` 管理故事、章节、字幕、轨迹、配乐谱与结尾；新增 `story-world.js` 绘制持久窗灯、路灯、课本、毕业门、纸飞机、纸屑与品牌粒子标识。

深夜、毕业、品牌使用 76、92、124 BPM，各有四个 16 拍章节，并在第 64 拍到达结尾，再停留 4 拍。相同节拍时钟同时控制角色、配乐与关键事件。毕业在 30、31 拍安排留白，跨过加长的轨道；品牌在 61 拍隐藏角色，把焦点交给终点标识。

城市窗口改用 InstancedMesh，减少重复绘制。背景使用程序化渐变天空，终章镜头拉近目标。跳转章节时相机立即切到该段位置，避免从开场一路滑过整个世界。结束提示通过 aria-hidden 隐藏未发生的结尾。

故事入口通过 `?story=night`、`?story=graduation`、`?story=brand` 选择。音乐导入仍完全在本地处理，但 v0.2 改成按音频时长映射完整剧情，并禁用 BPM 控件，避免把这种映射描述成自动卡点。

合成钢琴用多谐波波形和衰减包络，持续音使用慢起音，电子片使用脉冲与更密的音符。没有引入商业歌曲或参考帖音轨。v0.1 的 64 拍轨道函数和测试保留作为底层机制验证，故事模式使用自己的路径与 68 拍时长。


## v0.3 · 让动作和镜头承担剧情

问题来自实际截图：右侧控制面板导致画面竖长；品牌片使用通用弹跳轨道；终章明度高，字幕与主角抢位置。证据见 `assets/audit-v03/01-brand-opening-before.jpg`、`02-brand-ending-before.jpg`。

- 横向影院、三故事选择条、画面播放入口、折叠调整面板。
- `direction.mjs` 独立定义故事时间到运动时间的映射：夜景六拍停留，毕业两拍犹豫与四拍长跳，品牌固定构图；全部终章冻结。
- 品牌轨道全部退场，12 个伙伴光点、700 粒子、脉冲环与四块光刃构成独立场景；48 拍开始收束，52–58 拍拼合，58–62 拍显示名字。
- 毕业以课本承接落脚、31/32 平台隐藏形成断路，增加五位朋友与末段抛帽。
- 镜头按事件走：开场靠近、途中拉远、跨越侧面观察、结尾定格；品牌保持正面构图。
- 音乐加入压缩、卷积混响、声像、滤波衰减、电子鼓与高频细拍。46/47 拍留白后，以 52–55 拍四音作为品牌声音标记。
- 不增加外部媒体或远程请求，依然可以离线运行。


## v0.4 · 从声音事件生长出场景

新增第四个故事「雨停以后」。独立模块 `rain-world.js` 负责水面 shader、雨线、云层、阳光和伞；`rain-cues.mjs` 从原配乐的钟琴事件产生水面冲击，包含 offset 半拍音符。新增波形模拟钟琴和带通噪声滴音。纯函数保证跳转可复现，最终四拍视觉冻结。

保持原三段索引与 URL，新增 `?story=rain`。四故事入口在桌面一行，在窄屏两列；雨景使用浮动幅度而非弹跳高度文案。无新增依赖、外部素材或上传请求。

## v0.5 · 保留研究与可迁移作品

本轮先对整个仓库已跟踪及未被忽略的研究文件做 ZIP 快照，校验 CRC 与逐文件 SHA-256，再扩展界面。原始四段故事与历史说明、截图保留。新增研究沿革索引，不把文件快照描述成包含 Git 历史或聊天逐字记录。

`works.mjs` 负责作品默认值、字段白名单校验、原作派生和本机档案序列化。改写数据不修改 `baseStories`，原创乐谱与动作时间轴仍复用原作。`examples.mjs` 提供四份有具体观看对象的文案，JSON 文件保存在 `works/`，也随快照保存。

创作台支持标题、场合、四章标题与字幕、结尾、速度、品牌名；预览前校验。保存和导入追加 UUID 与时间戳，不覆盖旧版本。localStorage 无法读取时保留旧数据并停止写入；容量不足时提示导出。切换故事暂存未保存的文案，刷新前仍需保存或导出。

作品导出同时提供 Blob 下载链接与可复制 JSON 文本。当前内置浏览器没有返回文件下载完成事件，复制 API 也受到限制，因此加入自动选中文本和快捷键复制的路径；已验证键盘复制及重新导入。没有把点击下载描述成下载落盘验证通过。

修复 88 BPM 等速度下章节秒数转换的浮点边界：距离整数拍小于 `1e-7` 时归整，确保第 32 拍进入第三章。原配乐恢复保留当前改写作品；下拉框及文本输入使用空格时不会触发播放器快捷键。

本轮没有增加音符检测、自动故事生成、镜头编辑或视频导出。音乐审美与视听感染力仍需要实际听音评审。
