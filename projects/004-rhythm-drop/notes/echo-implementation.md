## 角色标准与实现

以已确认的 [角色概念图](../assets/echo-crew/concept-lineup-v1.png) 为身份参考，用内置 image_gen 生成 [空空正侧背与表演参考图](../assets/echo-crew/kongkong-standard-v1.png)。完整提示词保存在 [kongkong-standard-v1.prompt.txt](../assets/echo-crew/kongkong-standard-v1.prompt.txt)。图中保留贯通空腔、一短一长听声布片、侧边补丁、小手小脚，并展示听完、留白、回应三种动作和表情。图像是制作参考，侧面和背面结构仍需结合模型核对，不能当作已经验证的工程转面图。

四位原创角色已有 Three.js 程序化基础模型，代码为 `src/echo-characters.js`，复用固定比例、结构与材质设定：

- 空空使用有真实孔洞的挤出几何体，洞内可见背景，前后贯通；长短布片、补丁、表情与手臂独立运动。听声时关注空腔，回应时波纹穿过身体。
- 折折使用菱形折面与单侧多层折耳，听声时折耳打开，等待时收拢。
- 咚咚具有三层风箱腹部，低音强拍对应压缩与回弹。
- 簌簌具有细长种荚身体、折瓣和曲线风尾，声音脉冲驱动风尾摆动。

模型使用柔和色板、粗糙表面与程序纤维凹凸纹理。它们是按参考图建立的可运行原型，尚未达到参考图的全部材质、缝线与造型精度，仍需浏览器视觉验收和后续角色美术打磨。没有用一张角色图替代整个实时角色。

页面支持四位人物的正面、侧面、背面查看。选择角色或试听时将视图带回角色舞台，便于观察声音与动作的对应关系。

## 原创声音与十秒试演

四位有不同的原创合成短句：空空为柔和气声与钢琴颗粒，折折为轻响和清脆短音，咚咚为低音与软鼓点，簌簌为轻风与高音。音源由 `src/echo-sound.mjs` 合成，浏览器 AudioBuffer 与本地 WAV 使用同一采样算法。没有真人录音或配音。

已输出四份四秒立体声 WAV 和一份十秒配乐，随页面一起构建。空空短句是哆、来、留白、咪；声音样本尾部保留安静空间。

十秒角色试演：

| 时间 | 声音 | 动作 |
| --- | --- | --- |
| 0–4 秒 | 树洞传出三个短音 | 空空侧身聆听、手靠近空腔 |
| 4–5.25 秒 | 无音符，采样结果为零 | 身体安静，留出回应空间 |
| 5.25–7.7 秒 | 空空回送短句 | 音符脉冲驱动空腔波纹、手臂和小跳 |
| 7.7–10 秒 | 折折接唱，两位共同结束 | 折折出现，形成回应与连接；结束姿态停留 |

音符、视觉事件、故事推进共用 Web Audio 时钟。十秒结束后模型时间钳制，保持结束动作。后台切换和手动暂停会暂停音频时钟。

## 第一集 · 空空的一句问候

先演出一次失败的问候：空空听见树洞的三个音，着急把三个音挤在一起，形成实际可听的密集回应。随后玩家陪它重新听。

1. 点击再听，播放完整的树洞短句。播放期间回应按钮保持锁定。
2. 听完后按住“留一拍”约 0.75 秒，使空腔安静下来。提前松开可以重试，无错误扣分或倒计时。后台暂停会松开当前按住状态，返回后需要重新主动留白。
3. 按哆、来、咪的顺序回应，时间由玩家决定。点到其他音时保留已完成进度，并提示下一音。
4. 折折走出树洞，用自己的音色接唱；两个伙伴共同结束问候。

完成记录仅为本机浏览器的第一集完成布尔值，不保存身份、录音或私人信息。存储不可用时仍可完成流程。人物查看、试听和十秒试演独立于关卡，不会产生完成记录。

第一季选集展示保留固定人物与连续故事。当前只有第一集可玩，第二至五集明确标为“故事规划”，没有虚构可进入的关卡。

## 验证与限制

- 项目共 43 项 Node 测试通过，含原有版本回归、新关卡状态、完整听声与留白、不同音的宽容回应、合成信号、后台暂停、重来取消旧事件、十秒试演结束与人物查看。
- 控制器测试实际读取生产代码与页面元素标识，场景和音源依赖为明确的模拟对象，不是浏览器视觉或听感测试。
- 对真实 Three.js 几何体执行前后射线检查，确认空空的空腔贯通；表演状态的变换与边界有限，折耳确实开合，风箱确实压缩。离线 SVG 只用于结构检查，不支持最终 WebGL 材质、阴影与遮挡，输出不是浏览器截图。
- WAV 检查确认四秒/十秒时长、双声道、有限采样与无削波，十秒配乐的留白区间确实静音。构建和脚本语法检查通过。
- 本地页面、脚本、样式、图像、音频及授权资源的 HTTP 内容检查通过。原故事和旧游戏入口仍在。
- 浏览器预览工具仍报 `windows sandbox failed: helper_unknown_error: setup refresh had errors`，实际浏览器中的视觉、声音与触摸验收尚未完成。

后续先围绕空空与折折打磨第一集的造型、表演和声音体验，再推进《折折没听完》。角色方向固定并不意味着本轮已经完成全部标准模型、动画资产和五集制作。

## 第二轮 · 让第一次问候真正发生

继续围绕同一集和同一组原创角色打磨。新增“先看一个小故事 · 20 秒”，不需要操作即可看完一次失败、重新尝试和被伙伴听见的过程。观看不写入关卡完成记录；看完可以进入原互动流程。原 10 秒声音试演、角色查看、儿童操场及研究版本继续保留。

| 时间 | 情节与声音 | 表演重点 |
| --- | --- | --- |
| 0–3.6 秒 | 树洞传来哆、来、咪 | 空空望向声音来源，一只手靠近长听声布片 |
| 3.6–5.2 秒 | 空空把三个音挤在一起 | 急着举手，随后收手、垂布耳、露出不好意思的表情 |
| 5.2–10 秒 | 决定再试一次，重新听完整句 | 视线回到树洞，音符之间留出空间 |
| 10–11.2 秒 | 乐谱与采样都没有声音 | 空空闭眼，身体安静下来 |
| 11.2–13.9 秒 | 慢慢回送自己音色的三个音 | 每次发声有轻微准备、小跳与落地，波纹从空腔送出 |
| 13.9–19.55 秒 | 折折先出现、走近，再接唱 | 空空从惊讶转为开心，转向折折；最后两种音色共同收束 |
| 19.55–20 秒 | 留住相遇 | 两位伙伴一起挥手，结尾动作停留 |

声音仍由音乐动机主导，无真人配音。树洞声像偏左，出现后的折折声像偏右；浏览器与 WAV 使用相同的声音采样与平移设定。20 秒配乐保存在 `web/echo/kongkong-story.wav`。静音不是字幕说明：10–11.2 秒的两声道采样都为零。

`src/echo-direction.mjs` 集中定义关注对象、角色姿态、出场路径和镜头。镜头先让人看见声音来源，着急与留白时靠近空空，折折到来时跟随两位伙伴。音符对应的跳跃改为准备、起跳、落地与回弹；没有声音时不会持续弹跳。页面尊重减少动态效果的系统偏好，减少运镜、跳跃与传播粒子。

对白移进剧场底部，回应按钮和场景声音石在需要回应时出现。离线投影检查发现并修正了字幕遮挡声音石、手机镜头切掉折折的问题；这些检查验证的是 Three.js 相机投影与射线，不是实际页面排版截图。

第二轮验证：51 项 Node 测试通过，包括完整小故事、真实留白、左右声像、暂停与结束停留、观看后进入互动且不授予完成记录。`npm run check:echo-scene` 对 1116×540、341×430、286×400 三种舞台尺寸执行 2514 项角色/声音石投影检查，并检查空腔前后贯通、角色表情变换有限和声音石实际射线可点。

代码审查另修正四处实际问题：暂停后切换角色保留可继续的暂停状态；折折五块前侧折面的三角形法线朝向正面，防止被背面剔除；空格快捷键不再抢占已聚焦按钮、链接等控件；结尾二重唱时两位角色均依据自己实际发声的脉冲张嘴。原生检查包含折面法线与二重唱口型断言。

离线分镜位于仓库 `build/echo-story-v2-offline.svg` 与对应 PNG，仅用于几何构图观察。SVG 渲染不支持最终 WebGL 材质、阴影和透明遮挡，不能代表最终视觉质量。CUA 再次报 `windows sandbox failed: helper_unknown_error: setup refresh had errors`；因此未宣称完成浏览器视觉、听感或触摸测试，也尚无真实儿童使用反馈。

修改前第一集与完整研究已保存在仓库 `build/echo-crew-20261002-024627.zip`，本次继续保存独立校验快照。没有重写原创角色概念图，也没有制作或发布后续四集。

## 第三轮 · 同一动作里的两种心情

用户指出故事太简单，需要复杂情绪。新增 52 秒《那句没说完的问候》，固定两位角色和一次相遇，把误会建立在双方都想靠近、却没找到进入时机的行动上。入口仍为 `/echo/`，默认按钮为“看这次相遇 · 52 秒”。旧版 20 秒初稿可在当前页观看，也完整保存在 `/echo/versions/v2/`；冻结页只修正了导航链接，其脚本、声音和图像与此前版本一致。

空空想被听见，兴奋抢答时盖住折折刚尝试的第一个音。折折缩耳，空空把这个动作听成拒绝。它赌气走开，身体转走，长耳却仍朝树洞；走完两步后停下，仍期待被叫住。镜头随后切给折折：它也向前，追出一个没唱完的音。这个实际发出的短句成为空空回头的原因。

空空只先送一个小音，后面留着空位。折折主动唱出下一个不同的音，并向前半步；空空接上结尾。末段两人再次同时开口，又同时停住，但这次都没有离开。最终仍保留羞涩、不完全打开的折耳和没到满值的连接，关系只走到愿意继续尝试。

| 时间 | 表层行动 | 同时存在的感受 |
| --- | --- | --- |
| 0–6 秒 | 树洞后的练习、空空小声尝试 | 都想加入，也都不确定对方的意思 |
| 6–11 秒 | 空空抢答，折折声音被覆盖 | 想表现好、又没能接上；缩耳既保护自己，也被误读 |
| 11–16 秒 | 空空举手后慢慢缩回 | 失落、自我怀疑，也想把表情藏起来 |
| 16–24 秒 | 身体走开，长耳留下 | 赌气与期待挽留同时发生 |
| 24–30 秒 | 切到折折，追出半句 | 想叫住，又怕自己的声音没被听见 |
| 30–39 秒 | 空空回头、送出一点、等待 | 有了一点希望，仍没有把握 |
| 39–45 秒 | 折折主动加音并靠近 | 两个人共同改变这一句的走向 |
| 45–52 秒 | 同时开口、停下、仍留下 | 尴尬与安心并存，连接尚未完成 |

`src/echo-emotion.mjs` 定义配乐、分镜、角色移动、视点和台词。音乐包含角色音色、被覆盖的尝试、没唱完的呼唤、两步渐轻的低音脚步与柔和铺底。14–16 秒和 37–39 秒均严格静音，但人物姿态分别表达退缩和主动留位。铺底和脚步不触发人物唱歌口型。没有真人配音，片中语言仍为字幕；没有用心理诊断、成人创伤或连续负面事件代替人物复杂性。

新增表情和手势包括不确定、受伤、逞强、防备、脆弱、松一口气、羞涩、半举的手与收回的手。角色的身体朝向、目光、长耳方向、步伐和折耳开度可以表达不一致的愿望。视角切换时使用明确的镜头切换，其他时刻随音频时钟调整构图；52 秒结束后保持结尾。

本轮 58 项 Node 测试通过，包含双向尝试的实际声音重叠、呼唤先于回头、双方主动缩短距离、两种真实静音、未完全解决的结尾、减少动态效果、暂停与版本切换。三种舞台尺寸完成 9870 项原生几何/投影检查，并核对离开时长布耳仍朝树洞、折面法线、空腔和二重唱口型。离线分镜在仓库 `build/echo-story-v3-offline.svg` 与 PNG，仅供几何构图观察，不代表最终 WebGL 材质或浏览器截图。

仍需在真实浏览器中检验听感、表演辨识度和故事感染力。现阶段证明的是叙事安排及对应行为已实现，尚不能证明观众已经体验到预期的复杂情绪，也没有真实儿童使用验证。
