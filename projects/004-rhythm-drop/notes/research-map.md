# Rhythm Drop · 研究沿革与创作原则

## 归档摘要 · 2026-10-01

**初始目标：研究音乐型声音。** 来源是 [Gorden Sun 的 X 音乐动画效果](https://x.com/Gorden_Sun/status/2105302007896797351)。原网页的 3D 弹跳、随音乐发光和场景变化引出了问题：能否把声音事件转成视觉动作，再让它服务特定的场合与故事？[原效果引导图](../assets/source-effect.jpg)与[原帖上下文](../assets/source-post-context.jpg)分别保留，图片属于原参考作品。Three.js 是我们使用的基础库，不能写成最初的效果来源。

研究路径为：音乐与视觉同步 → 场合与故事 → 声音身份与关系 → 声音种植与创造 → 真实声音与人的表达、漂流和回应。

“有效果却没有故事感”“单纯种植没有意义”“产品效果太差”是这轮持续反馈，应与实现成果一起保留。功能和机制测试证明流程可运行，尚未证明音乐感染力、人物可信度、关系价值或持续使用。当前研究归档，产品价值未验证。

我们的理解有六条：声音先建立情绪，视觉与之配合；具体场合决定故事；稳定的声音与行为赋予角色特点，球形没有默认性格；成长合成应产生可听见的变化；真实声音与作者关联可能产生被听见和回应的价值；功能闭环与情绪体验要分别验证。

公开研究页汇总这些理解，并连接保留的各版静态演示。本机 Python / SQLite 社区源码与运行说明提交远端，私有录音、数据库和身份记录不提交；GitHub Pages 不开放真人社区。42 秒音乐故事为虚构文字场景与原创合成配乐，无真人配音，不充当社区活跃证据。

## 本轮形成的创作原则

讨论从参考帖中的音乐弹跳效果出发，经历了“做出效果”“补充故事与观看场合”“分别演示不同场合”“继续增强感觉”，最终把声音主导的创作作为核心方向。

音乐提供动机、密度、停顿、发展和收束；角色动作与环境变化承接这些事件。先明确这段短片送给谁、在什么时候看、希望留下什么情绪，再选择乐句与场景。灯被点亮、断路被跨过、散光被汇聚、雨停伞收，都需要形成故事结果。

字幕补充关系和背景，画面承担实际变化。四章节应有开场、展开、转折和抵达。当前作品仍是程序化动画与原创合成配乐原型；听音感染力需要真实设备与实际观众反馈，不能由测试通过替代。

## 当前边界与下一阶段

- 自定义音乐只按时长映射剧情；未实现任意歌曲的自动节拍或情绪分析。
- 作品文件保存标题、观看场合、速度、品牌名、四章文案和结尾；不包含音频、镜头参数、几何模型或视频。
- 原始故事元数据保持独立；保存和导入追加新版本，校验失败不覆盖旧记录。
- 如重新启动，先深化一段完整作品的乐句、角色动机与镜头，验证听众完整观看后的感受，再决定是否开放编排与视频导出。社区方向先验证真实表达、回应质量和再次使用意愿。

保存和恢复规则见 [全仓研究保存索引](../../../docs/RESEARCH_ARCHIVE.md)。

品牌试验 B 作为并行版本，先验证角色能否被记住、声部回应能否被理解，再决定是否将相同原则用于其他故事。原品牌片保持 A 版本，不能用新试验的角色表现代替旧版记录。
