# 小小社会 · 借一个节拍给你 · 2026-10-02

在已归档的音乐型声音研究旁新增独立试验，回应“用小孩子的形象映射实际社会，再用蹦蹦跳跳扩展”的方向。没有替换团队、品牌、花园或冻结版本，也没有将本次试验写成前一轮已经完成的成果。

## 一段可以看的故事

入口：`web/children/`，本机 http://127.0.0.1:8940/children/。50 秒，96 BPM，80 拍，五幕各 16 拍。

| 时间 | 实际动作与关系 | 声音发展 |
| --- | --- | --- |
| 0–10 秒 | 小禾与阿麦在操场游戏；新来的木木背着书包站在边缘 | 钟琴的游戏乐句、低音支撑；木木的钢琴动机试探进入 |
| 10–20 秒 | 木木尝试加入，却慢半拍，缩回去；小禾注意到他 | 不规则落音与试探乐句；17.5–20 秒所有声部留白 |
| 20–30 秒 | 小禾走近并伸手，主动留出位置，木木向前一步 | 先完整听见木木的动机，再用钟琴填补留白 |
| 30–40 秒 | 三个孩子按各自声部一起跳 | 钢琴、钟琴与低音共同形成完整乐句，落点对应乐谱事件 |
| 40–50 秒 | 新朋友豆豆抵达；木木主动走回去接他，最后四人留在同一画面 | 新声音发问，木木回应；47.5 秒落下四声部终止和弦，画面保持 |

社会映射是新人融入、接纳差异、协作与善意传递。跳跃表达兴奋与尝试，停顿表达犹豫和等待；回头与伸手表达关系的变化。人物与情节虚构，不将造型或声部作为人格判断。

## 角色与制作

- 木木：橙色上衣、书包与钢琴动机；慢热，想认真参与。
- 小禾：双发髻、珊瑚色背带装与钟琴回应；先看见别人，再留出空间。
- 阿麦：绿色服装、低音与稳定跳步；给大家支撑。
- 豆豆：黄色帽子、书包与新的短乐句；把结尾变成下一次开始。

Three.js 角色具有独立头部、耳朵、眼睛、眉毛、嘴、手臂与腿部关节，使用确定性表情、招手、蹲缩、摆臂与跳步。操场、跳房子格、树、长椅与栏杆均为代码建模。音乐为原创 Web Audio 合成配乐，无人声或歌词；没有声称使用真实录制乐器、完整演员表演或专业动画制作。

人物动作与音乐共用 AudioContext 时钟，支持暂停续播、从头重播、跳章节、进度、音量与全屏；离开页面会停声。启动声音需用户点击。

## 验收与边界

新增三项测试核对真正的乐谱留白、先听后回应、接纳向下一位传递、音乐落点、任意跳转及结尾保持；合计 29 项音乐与机制测试通过。页面、脚本、样式和许可证已通过本机 HTTP 200 校验。

本轮浏览器操作工具因本地执行环境初始化错误未能启动，未完成浏览器截图或完整视听验收。另用相同场景几何生成三张离线 SVG 预览，检查人物与构图；它们不代表浏览器截图。SVG 预览不支持 Canvas 纹理与 WebGL 阴影，网页以实际 WebGL 渲染为准。公开站点本轮未重新部署。
