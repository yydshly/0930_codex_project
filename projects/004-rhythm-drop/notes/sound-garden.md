# v0.8 · 声音花园

## 体验方向

花园让用户自己产生声音与视觉关系。没有预设工作任务或人物对白；每次触碰是一段新的乐句，松开后留下一株植物，之后触碰重听，整个空间可以从左到右依次合奏。

三个声音种子：水边（水滴钟琴、莲花与涟漪）、草地（柔和琴音、枝叶与花）、风铃（透亮泛音、悬垂光点）。植物形态、乐句长度由位置、停留时长和选择的声音决定。音阶预先编写，轻量合成音色、立体声和混响均为本地 Web Audio；没有使用远程歌曲、字体或图像。

## 已实现

- 独立入口 `web/garden/`，原故事剧场仍可播放；完整 v0.7 五文件冻结在 `web/versions/v0.7/`，先前 v0.5/v0.6 继续保留。
- 点击进入开启声音，指针点击或按住空白处种植。最多停留三秒，每株留下 2–6 个音；松开完成尾句。顶部位置音高较高，低处较低，左右位置映射声像。
- 点击已有植物重听同一音序；“听听这座花园”从左到右编排各株，声部轻微重叠，播放结束回到安静状态。停止按钮与切到后台会取消后续事件。
- 音符触发与扩散圈共用事件；植物按声部生长，风吹与萤火虫作为低速环境动作。系统减少动态设置下冻结环境摆动，保留必要的反馈。
- 键盘方向键移动位置，空格种植，Escape 停止。“种一束声音”提供无需点击画布的替代入口。
- 当前花园自动保存在本机，撤回后可恢复上一株。开始新花园和打开其他花园前，先追加保存当前页；失败时保留原页并提示导出。
- 花园 JSON 导出文本与下载链接、导入校验、本机花园档案。格式为 `sound-garden` / version 1，保存植物位置、音色、时长、音序，每页最多 24 株。旧故事作品格式保持独立。

## 产品边界与下一步

这是一段声音与视觉共创体验，不推断用户情绪。当前没有录音、音乐文件或视频导出，也没有跨设备同步、实时多人合奏。文件下载是否落盘需要实际下载确认；页面准备好 JSON 不等同于下载验收。

“重听”保持音序与音色，节奏采用每种音色固定的间距，没有逐次记录实际触碰间隔。触碰期间每 0.65 秒增加一个音，释放后完成尾句；每种植物的重听略有自己的节奏。背景景物本身安静，只有操作或主动播放时发声。

先验证用户是否愿意停留、是否愿意重听自己的花园、能否分辨三种声音。后续优先优化音色、空间层次、声部间的音乐关系；再尝试“保存今天的一页”与赠送花园。审美与情绪效果要通过真人试听和体验检验。
